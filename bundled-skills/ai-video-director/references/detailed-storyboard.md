# 视频详细分镜创作

用户要求详细分镜、导演分镜、制作级镜头说明，或需要把内容交给拍摄、动画、CG、AI图片/视频流程执行时读取。目标是把已批准的创意或脚本转化为清楚、连贯、可执行的画面说明书，而不是直接把故事梗概改写成生成提示词。

## 目标

详细分镜应具备：

- 清楚的叙事逻辑。
- 明确的画面、主体动作和摄影机运动。
- 与动作量匹配的时长和有变化的节奏。
- 连贯的角色、产品、场景、光线和空间状态。
- 有具体依据的转场。
- 统一且可执行的视觉风格。

## 工作流程

### 1. 锁定脚本核心

先确认或归纳：

- 视频目的、核心表达、目标观众和发布平台。
- 成片时长、画幅和故事主线。
- 已经确定的开头、高潮和结尾。
- 角色、产品、场景、视觉风格、主色调和参考画面。
- 画面与声音的分工；视觉母题、色彩变化、灯光来源和关键声音节点。
- 人物关系对应的视觉权重、视线方向、空间距离和构图倾向。
- 必须保留、禁止出现和需要验证的内容。

用户已经确定的设定必须延续，不得在拆镜时擅自改写脚本。缺少的次要信息可做可逆补充并标记为暂定；会改变核心表达、因果、产品事实、角色身份、开头/高潮/结尾、视觉方向或制作成本的选择才需要确认。

发现原脚本存在逻辑、时长或执行问题时，先单列：`问题 → 对观众/时长/制作的影响 → 最小调整建议`。在用户未授权改写时，保持原脚本版本，并把调整方案标为建议，不静默写进分镜。

### 2. 划分叙事段落

按内容需要组织：

`建立状态 → 出现问题或目标 → 采取行动 → 发生变化 → 到达高潮 → 完成收束`

每个 `SEQ` 只承担一个主要作用，例如建立环境、提出问题、发现目标、采取行动、展示功能、发生变化、到达高潮或完成收束。先确定每段要让观众理解什么，再拆具体镜头，不逐句翻译脚本。

不强套固定结构，但相邻段落必须存在因果、信息、情绪或视觉关系。高潮应对应全片最重要的状态变化，而不是单纯增加特效和运镜强度。

### 3. 根据画面变化形成候选镜头

脚本中的一句话不等于一个镜头。出现下列实质变化时，**考虑**建立新镜头，而不是机械切镜：

- 时间或空间改变。
- 观察对象或视觉焦点改变。
- 景别、拍摄角度、机位或主观视点必须改变，原机位无法清楚表达新信息。
- 角色进入新的行动阶段，行动目标或结果发生改变。
- 产品功能、形态或关键状态改变。
- 出现必须单独读取的新信息或细节。
- 情绪、节奏或人物关系发生明显转折。
- 当前连续镜头无法在可读、可拍/可做的条件下完成动作。

若主体、空间、视点和核心行动没有变化，并能通过固定机位或一次有目的的连续运镜清楚呈现，就保留为一个镜头。不要仅因为脚本换句、角色多做了一个小动作、想增加景别变化或预计AI可能困难而立即拆镜。

### 4. 合并检查与“一镜一个主要任务”

候选镜头完成后再检查相邻镜头能否合并：

- 两镜承担同一叙事任务，后镜没有新增关键观察对象或状态。
- 只是为了从中景切近景，信息和情绪并未升级。
- 简单动作属于同一目标下的连续因果链，并能在一次观察中读懂。
- 合并后不会造成时间跳跃、方向混乱、动作过载或生成不可控。

“一个主要任务”允许一条短而连贯的动作链，例如“角色走近产品→停下→伸手确认”，前提是同一主体、同一空间、同一目标，摄影机无需隐藏切镜，观众能够跟上。动作目标、产品状态、观察重点或叙事功能改变时再拆。

避免在一个短镜头中同时堆叠多个独立角色动作、产品结构变化、复杂运镜、大量特效、字幕和品牌信息。此时拆分的原因是信息与执行负荷冲突，而不是追求固定镜头数量。

### 5. 建立镜头层次

根据内容灵活选择：

`环境建立 → 主体出现 → 关系确认 → 关键动作 → 局部细节 → 动作结果`

不必使用全部层次。只要观众能理解主体在哪里、彼此什么关系、谁做了什么以及造成什么变化，就可以压缩或合并。相邻镜头的景别、角度、构图或运动应因新信息而变化；匹配转场或刻意强调时可以连续使用相似镜头。

镜头编号保持稳定唯一，默认使用 `SEQ01-SH001`；同一镜头组内补充景别或动作时可用 `SH002A/SH002B`，避免整表重编号。

## 单镜头内容与写法

以下内容是设计镜头时的检查维度，不是默认输出栏目。写作时按观众实际看到和听到的先后顺序，把需要的信息整合成一段连贯的导演描述：先建立起幅和视觉焦点，再写主体动作与摄影机关系，随后说明关键视觉/声音变化，最后交代落幅以及怎样接入下一镜。不要连续使用“镜头任务：”“起始画面：”“主体动作：”等标签把同一个镜头切成多条孤立句子。

镜头标题使用 `镜头编号｜时间/时长｜主要任务`。正文通常为一个自然段；信息较多时可以分成两个有明确阅读逻辑的段落，但不能退回逐项填表。只有产品精度、文字合成、复杂转场或生成风险确实需要单独提醒时，才在段末增加一条简短的“执行备注”。

### 镜头编号与时长

标明镜头编号、建议时长；需要精确时间线时补充最终时间范围。时长必须能容纳观众识别、动作执行、结果确认、字幕阅读和必要停顿。

先按叙事重要性分配段落时长，再估算单镜。以下只用于发现明显过短或拖沓，不是硬性标准：环境建立约1.5—3秒；简单动作约1—2.5秒；观察/反应约1.5—3秒；产品功能约2—4秒；复杂结构变化约3—5秒；字幕或品牌收束约2—3秒。平台节奏、动作复杂度、阅读量和情绪意图可以覆盖这些参考值。

### 镜头任务

用一句话说明主要作用，例如建立环境、展示产品、推动角色行动、呈现功能、制造高潮、完成转场或收束主题。若说不出镜头存在的原因，删除、合并或重新赋予任务。

### 起始画面

根据需要写清：

- 场景、时间、天气和延续状态。
- 景别、拍摄角度和摄影机初始位置。
- 主体位置、朝向、画面占比和产品状态。
- 前景、中景、背景、画面重心和必要安全区。
- 视觉焦点与人物关系：谁更大/更亮/更靠中心，人物看向哪里，留白或遮挡传达什么。

起始画面必须与上一镜落幅或已批准连续性状态相容。

### 主体动作

使用 `起始状态 → 动作过程 → 结束状态`。必要时明确方向、路径、速度、左右手、接触点、产品响应时刻和最终姿势。角色动作必须符合其体型、肢体结构和力量范围。

### 摄影机运动

与主体动作分开写。先说明叙事目的，再说明固定、推进、后拉、横移、跟拍、领拍、环绕、升降、摇镜、俯仰、变焦或焦点转移，并给出方向、速度、起点和终点。若静止更能突出表演、构图、环境或停顿，就不增加运镜。

避免只写“镜头环绕”“角色走过去”“产品展开”等模糊描述。优先一个主要运镜，最多增加一个相容的小调整。

### 视觉变化

根据镜头需要说明：

- 光线方向、冷暖、明暗和主色调。
- 色彩此刻负责营造情绪、引导焦点、区分人物/时空、强化类型，还是表现状态变化。
- 灯光的可解释来源、软硬、明暗和造型目的；顶光、侧光、逆光、硬光或环境反射光不得只作为风格标签。
- 产品材质、反射、阴影与不可改变结构。
- 特效从哪里出现、沿什么路径、以什么形态存在、如何消失或停留。
- 哪些内容运动、哪些内容必须保持静止。
- 角色、产品、环境的比例和必要参照关系。

把“科技感、能量涌现、灵感爆发”等抽象词转换为具体可见的状态变化。特效必须服务信息和情绪，不遮挡主体，不擅自增加密集粒子、杂乱HUD、无来源光线或大面积色彩污染。

### 落幅与转场

写清镜头结束时的构图、主体和产品状态、摄影机停点及必要保留时间，并说明怎样连接下一镜。

转场优先利用：运动方向、运动速度、动作时刻、主体位置、相似形状、色彩/光线、前景遮挡、构图匹配或声音先行。标明动接动/静接静、动作如何在下一镜继续，以及轴线和屏幕方向如何保持；有意反向、越轴、跳切或动静突变时写明叙事目的和空间重建办法。不得只写“自然转场”“无缝衔接”或“炫酷转场”。

### 声音与文字

必要时标明本镜主声音、环境声、画外声、动作音效、产品操作声、配乐开始/停止/抽空、旁白、留白，以及字幕内容、位置、时机、停留和进出方式。使用 J-cut 时明确哪一声音在何时先行，以及它预告的下一空间或事件。

画面展示事实，旁白解释意义，字幕提炼信息；三者不要重复表达同一内容，也不要为每个视觉动作叠加夸张音效。

### 特别限制

只列出对执行有帮助的保持项和禁止项，例如产品真实结构、开合状态、Logo、人物身份、场景结构、轴线、光源、比例、静止内容、参考需求和失败备用方案。

区分全片统一规范与本镜特有状态，避免每镜重复整套设定。

## 核心规则

### 叙事与连续性

- 每镜推动故事、展示功能、塑造必要情绪或完成衔接，不能只是素材排列。
- 保持角色位置、朝向、视线、动作接点，产品形态/比例/开合，场景和道具，光源和色调，摄影机轴线，以及上一镜落幅与下一镜起幅。
- 保持视觉权重和人物关系可读；色彩、灯光、构图、人物距离或位置变化必须由剧情、时间或心理变化触发。
- 产品功能应由故事需要触发并影响结果，不按功能清单逐项展示。

### 镜头差异

相邻镜头避免无意义地重复景别、构图、角度、运镜方向、速度和主体位置。也避免为变化而机械执行远景→中景→近景→中景→远景。只有匹配转场、建立刻意重复或新信息确实需要时才使用相似镜头。

不要为“丰富”随意切换景别或越轴。角色从左向右运动时，下一镜的反向必须由剧情转向、过轴镜头或新的空间建立解释。

### 产品、角色与特效

- 尊重产品真实结构、功能、材质、Logo和状态，不为视觉效果擅自变形、增生或增加功能。
- 用参照关系保持角色、产品和环境尺度，确保角色能可信完成动作。
- 特效少量、清楚、有路径、有边界；不遮挡关键信息或破坏统一风格。

## AI视频特别要求

- 先按叙事和画面变化完成镜头草案，再进行AI可行性复核，不让平台限制先行决定故事节奏。
- 一个镜头保持一个核心行动目标；可包含少量同方向、同目的的简单动作，视频提示词仍应突出主动作和起止状态。
- 明确运动内容与静止内容。
- 检查动作、机位、视角和稳定性指令是否相互矛盾。
- 减少复杂连续形变；精确产品变化可用切镜、遮挡、特写或独立状态完成。
- 遇到高风险镜头时依次考虑：简化动作链 → 减少运镜 → 移动到自然动作切点 → 使用前景遮挡/特写隐藏转换 → 拆成独立状态和镜头。只在确有可读或执行收益时增加切镜。
- 为折叠、半展开、完全展开等关键状态准备独立参考。
- 明确禁止变形、增生、比例错误、多余元素、错误文字和身份漂移。
- 分镜脚本与生成提示词分开编写；用户需要时，再从批准的 `SH` 派生 `PTI/PTV`。
- 先建立角色、产品、核心场景和关键状态的少量权威参考，再扩展逐镜画面；提示词描述本镜动作，参考资产负责身份、结构和视觉基线。

## 默认输出格式

默认依次输出：

1. 脚本锁定摘要；如有问题，先列问题、影响和最小调整建议。
2. 叙事段落、段落任务和建议时间分配。
3. 经过候选拆分与合并检查的逐镜头详细分镜。
4. 必要的全片统一执行规范。

单镜头默认格式：

```text
### SEQ01-SH001｜00:00—00:02.5｜建立环境与危机

从[场景、景别、机位和主体初始状态]开始，摄影机[运动方式、方向和速度]，同时[主体动作及其过程]。随着[触发事件]发生，[光线、色彩、材质、产品或特效]出现具体变化，[环境声、动作音、音乐、对白或文字]在相应节点进入或退出。镜头最终停在[结束构图和状态]，并通过[动作、方向、构图、遮挡、光线或声音关系]接入下一镜。需要特别控制的稳定性、官方素材或生成风险直接在段末说明。
```

示例中的顺序可按镜头实际节奏调整，不要求每段照抄句式，也不要求把所有信息塞满。重点是让描述像一次连续发生的镜头，而不是八个栏目各写一句。没有必要的内容直接省略；用户要求便于复制时，去掉解释和多余标题，按镜头编号连续输出。

## 输出前内部自检

在内部检查并直接修正，不默认展示检查过程：

- 故事清楚，镜头之间有因果或具体视觉关系。
- 镜头完整覆盖原脚本，任何脚本调整都已单列说明，没有在拆镜时静默改写。
- 候选镜头已经过合并检查：没有逐句翻译、为景别变化而切镜或把简单连续动作过度拆碎。
- 总时长合理，动作量与镜头时长匹配，并为字幕、转场、Logo和情绪停顿留出空间。
- 角色、产品、场景、道具、光线、状态和轴线连续。
- 相邻镜头没有无意义重复。
- 每镜的视觉焦点清楚，构图、色彩、灯光和声音各有功能且不重复传达。
- 运动方向、速度和动作接点可剪；跳切、空镜、交叉剪辑、声音先行或越轴均有明确意图。
- 每个镜头能够实际拍摄、制作或生成；复杂动作和结构变化有拆分或替代方案。

最终标准：未参与前期讨论的执行人员，只看分镜就能知道镜头为什么存在、从什么画面开始、发生什么、怎样呈现、最终停在哪里，并顺利接入下一镜。
