# 镜头拆分、运动与剪辑节奏

在把脚本拆成镜头、描述摄影机/主体运动、分配时长或设计剪辑接口时读取。

本文件用于镜头结构和节奏设计。用户要求能直接交给导演、摄影、动画、CG或AI视频执行的详细分镜时，同时读取 [detailed-storyboard.md](detailed-storyboard.md)。

## 故事段落与镜头

故事节拍是叙事单位；`SH` 是最终剪辑中一次连续、可理解的观察。先划分段落和镜头任务，再根据画面变化形成候选切点。出现以下变化时考虑切镜：

- 时间、地点或连续空间改变。
- 主要观察对象、视觉焦点或传播目的改变。
- 视点、机位、角度或景别必须改变才能读清新信息。
- 行动目标、动作阶段、产品状态、情绪或节奏发生实质转折。
- 当前镜头无法清楚、连续、可执行地容纳全部内容。

变化只是切镜候选，不是自动切镜命令。若主体、空间、视点和核心行动保持一致，简单连续动作可在同一镜头完成。候选拆分后再反向检查能否合并：后镜是否提供新信息、状态或节奏价值；若只是换个景别重复同一内容，优先合并。

先做内容驱动拆镜，再做生成可行性复核。生成风险不应直接制造碎镜；优先简化动作、减少运镜、移动切点、使用遮挡/特写或把结构变化设计成清楚的独立状态。

## 单镜头规格

描述摄影机和主体，而不是只堆砌电影术语：

1. 景别与视角。
2. 摄影机起始位置、距离和高度。
3. 一个主要路径：固定、摇、俯仰、推、拉、跟、横移、升降、手持、FPV或有动机的组合。
4. 运动速度，以及摄影机领先、跟随、接近还是远离主体。
5. 主体的起点、动作路径和终点。
6. 前景、中景、背景的遮挡、视差或揭示。
7. 重量、惯性、接触、风、粒子、反射、液体、形变或冲击反馈。
8. 因动作而产生的光线或色彩变化。
9. 定义动作时刻的声音提示。
10. 稳定结束构图和下一镜头接口。

优先一个主要运镜，最多增加一个相容的小调整。静态镜头完全有效；运动必须服务信息、情绪、空间或因果。

## 先选目的，再选导演手段

- 建立空间、尺度和行动路线：优先远景/全景、稳定观察或有目的的揭示。
- 观察行动、交流和产品使用：优先全景/中景与清楚的动作路径。
- 强调反应、关系或关键操作：使用近景或特写，但必须提供新信息。
- 集中注意或进入心理：可推进；揭示后果、关系或疏离：可后拉。
- 陪伴行动和展示路径：可跟拍/横移；强调目标压力：可领拍。
- 重新分配注意、揭示关联：可摇镜、俯仰或焦点转移。
- 强调关系、困境或仪式：可环绕；没有这些目的时不要无故绕行。

避免机械地按远景、中景、近景再返回的“手风琴式”景别变化。切换景别必须因为信息、情绪或视点变化，而不是为了表面丰富。

## 动作因果链

使用：

`触发 → 人物/物体动作 → 力或接触 → 环境反馈 → 可见结果 → 反应`

不要用形容词替代物理过程。产品、功能或性能只能使用已确认事实。

一条短动作链可以留在同一 `SH`，只要所有动作服务同一目标、发生在同一空间和视点下，并能通过一次连续观察读懂。动作目标、观察重点、产品状态或叙事功能改变时再切镜。

## 剪辑节奏前置

主镜头表必须同时记录：

- 最终使用时长。
- 建议源素材时长。
- 镜头进入点、主要动作点、离开点。
- 前后需要的稳定剪辑余量。
- 与相邻镜头的动作、方向、构图、景别或声音关系。

节奏来自对比：建立、进入、加速、停顿、冲击、反应、收束。不要让所有镜头同样长，也不要让所有镜头都移动。

以下时长仅是检查启发，不是固定规则：

- 极短插入适合由较长稳定素材后期截取，不要求模型内部完成精确碎切。
- 信息、动作和反应必须保留人眼理解时间。
- 情绪或结尾镜头通常需要稳定停留，除非创意明确要求突然中断。
- 可用环境建立1.5—3秒、简单动作1—2.5秒、观察/反应1.5—3秒、产品功能2—4秒、复杂结构变化3—5秒、字幕/品牌收束2—3秒作为初始估算；内容、平台和情绪需要优先。

## 剪辑接口

每个 `SH` 至少选择一个主要接口：

- 动作匹配：前镜头动作在后镜头继续或完成。
- 方向匹配：主体和摄影机保持可理解的屏幕方向。
- 构图匹配：形状、位置、色块或视觉重心呼应。
- 视线匹配：人物看向的对象在后镜头揭示。
- 声音桥：下一镜头声音提前进入或上一镜头声音延续。
- 对比切：景别、声音、运动或情绪有意突变。

如果无法说明前后如何连接，镜头可能还没有被设计成可剪辑素材。

## 运动匹配与轴线

- 动接动、静接静是连续性基础；动静相撞用于冲击、迟滞或状态改变。
- 匹配主体/摄影机的屏幕方向、速度和动作阶段，使跨镜动作保持同一动力。
- 动作切换优先发生在动作最清楚、最有惯性的节点，后一镜继续或完成动作。
- 以人物关系线、视线或运动路线建立180度轴线；连续空间默认不越轴。
- 若有意反向或越轴，写明要表达的对抗、逆行、失衡或关系改变，并用轴上镜头、摄影机过轴运动、中性镜头或空间重建避免误读。

## 跳切、空镜、交叉剪辑与声音先行

- **跳切**：用于省略时间、加速重复动作、塑造焦虑/个性或制造刻意断裂。保持主体位置、动作阶段或声音连续，让省略可读。
- **空镜**：用于建立环境、提示时间/空间、承接情绪、形成对比或留出呼吸。不能仅因“画面漂亮”占用时长。
- **交叉剪辑**：交替呈现同时或相互影响的行动；每次切换都要增加信息、压力、对比或逼近汇合点。
- **J-cut/声音先行**：下一场声音先于画面进入，用于预告空间、制造悬念、引导注意或软化切换。
- **声音延续**：上一场声音跨越画面切点维持情绪或因果，但不能遮住新场景主信息。

这些不是默认转场套餐。只有当它比硬切更清楚地完成叙事任务时才使用。

## 平台无关镜头规格

```text
SH / 最终使用时长：
叙事目的：
景别与视角：
摄影机起点、主要路径、速度和终点：
主体起点、动作路径和终点：
前景/中景/背景：
物理因果、接触、反馈和结果：
光线/色彩响应：
声音时刻：
开始状态 → 结束状态：
下一镜头接口和剪辑余量：
必须保持 / 禁止变化：
通过标准：
```

## 文字质量检查

- 每次实际切镜都有 `SH`，且没有隐藏多个机位。
- 每个镜头只有一个主要目的和一条连贯行动线；简单因果动作没有被机械拆成原子镜头。
- 候选切点经过合并检查，切镜来自新信息、状态、视点、节奏或执行需要，而不是来自脚本换句或景别装饰。
- 总时长与目标一致，重要信息和反应可读。
- 景别、时长、运动和静止具有有意变化。
- 空间轴线、视线、运动方向和连续性状态自洽。
- 景别变化提供新信息，没有机械远中近往返；跳切、空镜、交叉剪辑和声音先行都有明确功能。
- 动作、方向和速度在跨镜时可读；任何反向、越轴或动静突变均为有意设计。
- 结束构图稳定，能支持预计切点。
- 相邻镜头的景别、角度、构图或速度变化来自新信息需要，而不是为了表面丰富。
- 除非故事明确转向，角色、视线和主体运动没有无意越轴。
