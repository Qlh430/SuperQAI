# 外部生成结果复盘与剪辑蓝图

在用户提供生成图片、关键帧、视频截图、时间码或粗剪证据，或需要剪辑/声音节奏设计时读取。

## 证据边界

- 只依据用户提供且可检查的内容下结论。
- 无法直接读取完整视频时，请用户提供关键帧、问题片段时间码或简短时间线描述。
- 不把模型、平台或剪辑软件的能力当成已知事实；不声称执行了生成、播放、剪辑或导出。

## 图片分镜复盘

逐张检查：

1. 叙事信息是否一眼可读。
2. 人物身份、服装、道具和场景布局是否连续。
3. 构图、视觉层级和景别是否服务当前镜头目的。
4. 光线方向、色彩和材质是否符合已批准视觉设定。
5. 姿势、接触、比例、遮挡和物理关系是否可信。
6. 与前后镜头的方向、视线、动作和构图是否能连接。
7. 是否适合作为视频首帧、尾帧或关键参考。
8. 视觉焦点是否明确；人物大小、留白、遮挡、色彩和灯光是否表达正确关系与情绪。

输出格式：

```text
镜头 / 结论：通过 / 小改 / 重做
可见问题：
问题原因：脚本 / 镜头设计 / 连续性 / 提示词 / 外部生成
保留项：
具体修改：
修订后的核心提示词：
下一轮通过标准：
```

优先指出少量高影响问题，不用泛化形容词堆砌意见。明确哪些部分可以保留，以及需要重做的最小区域、状态或镜头。

## 视频素材或截图复盘

检查：

- 摄影机路径是否清晰且只有一个主要运动。
- 主体动作是否有明确开始、因果和结束。
- 身份、几何、空间、左右方向和状态是否漂移。
- 接触、重量、惯性和环境反馈是否可信。
- 结束画面是否稳定并保留可用剪辑余量。
- 素材是否能在预计时长内截取，而不依赖模型内部精确切镜。

修改建议优先按以下顺序：简化动作、减少运镜、锁定参考、拆成两个素材任务、调整剪辑方案、采用非生成方法。

当素材只有局部错误时，先保留可用时间段，定位错误开始与结束点，再选择补生成连接段、插入特写/空镜、遮挡切换、动作匹配或声音桥。只有角色身份、产品结构、空间逻辑或核心动作从头到尾均失效时，才建议整镜重做。

## 剪辑节奏蓝图

蓝图必须引用 `SH/PT`，至少包含：

- 最终时间范围和使用时长。
- 预期素材与截取范围。
- 入点、动作点、出点和速度意图。
- 硬切、动作匹配、构图匹配、叠化、声音桥或其他转场目的。
- 对白、环境音、动作音、音乐、留白、字幕、图形和安全区。
- 与前后镜头的依赖和备用剪法。

声音不只是装饰：可以提前引出空间、连接跳切、强化动作、制造停顿或在画面切换后延续情绪。为每段确定主声音，区分对白/旁白、环境、拟音、设计音效和音乐；标明画外声、J-cut、声音延续以及音乐开始、停止或抽空的节点。不要让每个切点都机械追随音乐重拍。

## 粗剪复盘

按时间段输出证据和动作建议：

```text
00:00–00:03
观察：
影响：
建议：保留 / 缩短 / 删除 / 换序 / 替换 / 补素材
建议切点或目标时长：
声音或字幕调整：
优先级：高 / 中 / 低
```

重点检查：

- 开场是否及时建立问题、人物或视觉吸引力。
- 相邻镜头是否重复同一信息、景别或运动。
- 加速段是否仍可理解，停顿是否有情绪或信息价值。
- 动作切点、运动速度、视线、屏幕方向和空间轴线是否顺畅；越轴或反向是否有意。
- 景别是否机械远中近往返；跳切、空镜和交叉剪辑是否各自推动时间、情绪或因果。
- 音乐、音效、对白和留白是否形成层次。
- 结尾是否有明确落点和必要停留。

## 复盘优先级

先修复会让观众看不懂或无法剪辑的问题，再处理连续性和物理错误，最后才是风格微调。先保护可用素材，再采用最小重做单元。若问题源于上游脚本或镜头设计，明确指出需要重新打开的阶段，不用无限修改同一提示词。

每轮复盘末尾必须说明本轮结论、保留项、下一轮最小动作和通过标准，再用一个问题询问用户是否接受当前修改方向。若接受，明确引导其继续外部测试或进入下一阶段；若不满意，请用户指出最需要调整的一个方面。
