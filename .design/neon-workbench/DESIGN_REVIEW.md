# Neon 工作台 UI 与问题修复验收

日期：2026 年 9 月 30 日。

## 结论

本轮修复已构建并部署，模拟接口与模拟宿主验收通过。八个主页面的常规响应式及放大布局检查通过。真实登录后的业务验收、完整画布节点视觉迁移及 Better Design 正式审查尚未完成。

## 已发现并修复

| 问题 | 修复 | 复验依据 |
| --- | --- | --- |
| 刷新及切换页面重置搜索、筛选与设置子页 | 保留已访问页面实例，首次加载与后续刷新分开处理 | 搜索、项目筛选、设置技能页签刷新及往返保留 |
| 刷新重置当前阅读位置 | 仅进入页面或首次准备完成时恢复滚动位置 | 代码检查；未单列滚动位置自动断言 |
| 单个资源接口失败阻止使用其他页面 | 分别检查接口结果，按页面展示错误 | 素材 500 时设置及账户可用，素材重试恢复 |
| 修改模型连接后生图模型仍旧 | 保存、启停、删除连接后通知模型列表刷新，失效选择回自动模式 | 模拟配置保存后新模型显示，草稿保留，旧选择复位 |
| 历史详情仅显示对话标题且遗漏生图结果 | 展示完整角色消息与生成图片 | 对话助手内容和生成结果图片检查 |
| 保存页面实例后弹窗跨页面残留 | 弹窗记录打开时路由，路由改变时隐藏并关闭 | 历史详情打开后切换到项目，弹窗消失 |
| 移动导航缺少焦点约束与 Escape 关闭 | 使用 Base UI Dialog 导航抽屉 | 连续 Tab 保持内部，Escape 关闭后返回菜单按钮 |
| 点击停止对话后意外再次提交，草稿再次清空 | 阻止停止按钮点击的默认提交行为 | 专项复现后修复；停止时草稿保留且请求仅增加一次 |
| 375px、175% 缩放下对话工具栏溢出 | 工具组允许换行 | 八页两种宽度的放大检查通过 |
| 生图说明只描述桌面左右位置 | 改为描述输入、参考图与生成步骤 | 移动端截图检查 |
| 会话切换期间旧异步操作仍可能显示画布 | 会话版本校验，清理时保留画布引擎 DOM | 加载中换账户、保存中退出及重新进入模拟测试 |

## 人工视觉审查

已查看 1280 与 375 八页拼图、1280 首页、375 生图、390 模型设置、390 导航焦点与 375 放大对话截图。

- 管理页主导航、标题、筛选及内容区层级一致，创作页使用独立全屏区域。
- 主行动、输入、表面和边框保持官方组件体系。没有在此次页面及业务组件扫描中发现直接写入的十六进制颜色或紫色品牌类名；这不代表整个旧运行时已无旧样式。
- 移动导航当前页与键盘焦点分别可见；模型设置页签在窄宽度下换行。
- 窄屏生图是上下顺序，提示文案已匹配操作过程。
- 放大短视口会增加纵向滚动，对话输入区域保留；未把此检查当作完整无障碍合规认证。

## 限制与剩余事项

本轮使用模拟 API，不代表真实服务商请求、权限、持久化与画布保存已通过。没有真实认证会话或计费生成，也未修改用户真实画布。

长内容、屏幕阅读器、所有权限角色、所有高级设置及完整画布手势仍需追加独立验收。当前画布使用既有引擎和节点视图；登录、首次改密仍是旧认证界面。

Better Design MCP 未连接，没有执行 `inspect-spacing`、`check-comprehension` 或公开 HTTPS 的 `finalize-dashboard-review`，不得标记其结果为 VALID。
