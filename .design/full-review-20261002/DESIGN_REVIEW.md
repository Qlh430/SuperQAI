## 已修正问题

| 问题 | 修正结果 |
| --- | --- |
| 素材出现无后端数据模型的“当前项目”和“我的收藏”筛选 | 移除占位筛选，保留有真实资源权限依据的 3 种范围 |
| 素材与生成图被固定比例限制 | 素材保持媒体原始比例；生成结果使用自然图片比例；极高素材缩略图使用最大高度和 contain 保持整图 |
| 窄屏素材标题截断 | 标题允许换行 |
| 项目目录按钮不足 44px，768px 下名称被挤压 | 设置最小触控高度、项目名称换行，并延后项目目录多列布局断点 |
| 登录输入框高度为 43px | 登录表单输入至少 44px，不改变认证流程 |
| 长错误文案挤压布局 | 错误正文允许换行并保留重试入口 |
| 对话等待期间不能继续输入 | 等待时输入保持可用；停止后保留当前请求内容及下一条草稿；不重复提交 |
| 生成历史保存行为可能被误改 | 保留现有自动保存契约，并在创作说明中写明 |
| 协议验证、模型拉取忽略当前输入密钥 | 请求携带当前密钥；空值保留已保存密钥契约 |
| OpenAI 协议出现重复选项 | 排除目录中与内置选项重复的 ID |
| 主机更新状态没有随宿主推送更新 | 订阅 `onUpdateStatus`，并正确释放订阅 |
| 更新器真实 `up-to-date` 和 `unpublished` 状态未翻译 | 补齐中文映射，未知状态显示“状态待确认” |
| 主机异常、网络中断可能直接显示英文错误 | 提供中文失败提示；保留已有中文服务错误 |
| 成功响应 JSON 损坏可能被视为空数据 | 明确报错，不伪造成空列表 |
| 模型下载进度读取失败缺少反馈 | 显示中文进度读取错误 |
| 协议能力仅用 Unicode 勾/横线表达 | 改用 lucide 图标与文字说明 |
| 开关、按钮、输入、导航触控范围不足 | 常规尺寸达到 44px；开关可见轨道保持紧凑，交互根元素达到 44×44 |
| 部分页面颜色与尺寸不使用统一体系 | 采用语义颜色，固定尺寸转为 rem，适配界面缩放 |
| 设置文案暴露组件和令牌实现细节 | 改为调整阅读大小与动效的用户说明 |
| 上传限制使用未解释缩写 MB | 生图页面及其上传失败提示改为中文“兆字节” |

## Better Design 结果与判读

本轮确实调用了 Better Design MCP。已获取通用规则、Accessibility、Visual Design、Content、AI Features 规则以及 Navigation、Dialogs 原则。规则证据在 `better-design-rules.md`。

`check_comprehension` 读取可见文本，不理解截图层级。本轮最终复查 25 个主页面、设置与弹窗状态：4 个 PASS，0 critical，39 serious，0 minor。通过的是新建项目、修改密码、新增账户和普通账户设置；其余主要为操作数量和解释时长。原始结果见 `better-design-comprehension-final.json`。

人工判读：导航、筛选和数据记录与当前主行动已有视觉分组，不为满足单一行动提示而删除项目管理或素材筛选功能。创作页保留主提交行动与次操作；MB 提示已修正。中文解释时长也只是启发式估计，不能替代用户理解测试。完整文案提取另存在官方 CardTitle 使用 div、部分表单选项与标签拼接的限制。

`inspect_spacing` 已读取真实浏览器 DOM 捕获。先复查 6 个重点状态，随后分 21 批检查全部 122 个状态；每批最多 6 个状态是工具实际限制。修正项目目录按钮、项目标题布局和登录输入框后，合并的最终结果为 0 critical、639 serious、133 moderate，总计 772 条；此前第一轮是 647 serious、149 moderate。条目会按宽度和弹窗背景重复计算，不等于 772 个独立产品问题。

完整第一轮工具结果保留在 `better-design-spacing-final-1.json` 至 `better-design-spacing-final-21.json`，修正后重点状态保留在 `better-design-spacing-postfix-1.json`、`better-design-spacing-postfix-2.json`，汇总在 `better-design-spacing-summary.json`。其中发现项目按钮高度/标题截断、登录输入高度是真实问题，已经继续修正，并在最终部署及专项复查中验证。不能将几何检查描述为截图视觉批准。

| 提示类别 | 人工判读与处置 |
| --- | --- |
| 1×1 触控或裁切元素 | Base UI 隐藏表单输入、Dialog focus guard 与辅助说明节点；可见开关及关闭按钮交互根元素已扩大。保留内部无障碍机制，不扩大隐藏节点 |
| sibling-gap drift | 主导航组标题与条目使用不同层级间距；开关旁隐藏输入也影响相邻计算。保留语义分组，不把所有子元素机械拉成等距 |
| 下拉框左右 padding 不同 | 官方 NativeSelect 使用自定义 ChevronDown，右侧为图标预留空间，并非浏览器内置箭头。属于有意不对称，保留可读性 |
| 素材卡片非同心圆角 | 官方 Card 通过 overflow-hidden 裁切内部媒体，预览按钮本身为直角。人工截图未见媒体越出卡片，保留官方裁切结构；工具仍报告该项 |
| off-scale spacing | 默认工具量表不包含官方组件中的 2、6、10、20、36px 等间距；官方组件现有密度与项目通用 4px 规则存在细节差异。记录例外，不把工具默认量表当成新增样式的依据 |

上述判读是人工处置，不代表 Better Design 撤销了原始 finding。未对所有角色、所有交互状态或完整画布作无障碍合规认证。

`finalize_dashboard_review` 未执行：此项目为本机桌面工作台，没有可供该工具访问的公开 HTTPS 部署地址。因此没有最终 dashboard receipt 或 VALID 结论。
