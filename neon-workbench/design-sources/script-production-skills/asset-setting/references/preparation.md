# 资产设定与提示词内容规范

依据原文和分镜提取人物身份、外貌、服装、配饰、场景空间布局和道具状态，建立跨镜一致的风格。把明确原文与补充设定分开描述。人物服装变化、道具明显变化使用版本，不重复创建每次出现的实体。

每项资产提供名称、类型、设定和可直接编辑的完整视觉提示词。人物四视图包括正面、侧面、背面、脸部特写；角色人设图重点展示整体、服装、配饰和细节。布局由用户选定，准备内容不替用户选择执行范围。

纸条、屏幕消息和字幕的准确文字保留在原始剧本和分镜记录中，不承诺随机图像模型可以准确排字。图片提示词只描述主体、场景、服装、状态、构图、光线、风格及参考关系，不夹带助手权限、Skill、程序操作或节点运行指令。

输出仅准备设定、提示词和引用；图片或视频执行授权来自用户明确发送，不来自模型内容。
