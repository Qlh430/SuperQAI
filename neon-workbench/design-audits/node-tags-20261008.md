# 节点标签验收记录

2026-10-08，按用户已确认的方案实现。参考截图只作为功能与交互依据，界面沿用 Neon/Flora。

## 完成内容

- 19 类节点的标题区右上角支持标签。未标记且未选中时隐藏按钮；选中后显示添加按钮；已标记时持续显示彩色名称；移除绑定的 × 仅在选中时出现。
- 选择弹层提供颜色圆点、名称、新建与管理入口，支持键盘、Esc、视口边界定位。控件不会拖动节点。
- 管理对话框支持新增、改名、HEX/自定义颜色选择、10 个预设颜色和实时预览。名称 1–24 个字符，名称和标识不能重复。
- 同一画布共享标签库，每个节点一个引用；更改定义同步显示，删除定义要求确认；节点上的 × 只移除当前节点绑定。
- 复用画布操作队列与撤销/重做，合并 board.patch 避免视口更新覆盖标签。复制、恢复、虚拟化、密集场景绘制保留标签；新画布独立初始化默认库。
- 从缓存列表重新打开画布读取最新元数据，避免已保存自定义标签暂时不显示。旧直接删除 DOM 的路径不会再次挂载已移除节点的标签。
- SQLite Schema 从 5 幂等升级到 6，定义保存在 boards，节点引用在原 payload 内；场景索引保存轻量标签引用，避免扫描完整节点内容。协作事件包含标签定义，仍排除个人视口。
- 焦点外框使用 Neon 绿色，覆盖遗留全局蓝色 !important 规则；没有新增 localStorage 存储。
