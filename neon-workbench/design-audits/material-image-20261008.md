# 添加素材的图片比例与工具栏修复

2026-10-08，用户反馈通过操作区添加素材后图片节点上下留白，选中后的工具栏为空。

## 根因与修复

- 操作区上传创建普通 image 素材节点，但自适应媒体判定只接受 uploadOnly 或单素材合集。这类带 imageSrc 的节点仍使用 400×400 主体，横图以 contain 显示，形成上下空白。
- Flora 与宿主尺寸判定都纳入带图片内容的非生成 image 节点，复用现有自适应尺寸、单层圆角和贴边布局；节点按原图比例显示，保留完整图片。原有图片素材恢复也经过相同判定。
- shell 在节点插入 document 前生成工具栏，Lucide 扫描时尚未找到按钮。工具栏不是没有动作，而是图标占位尚未转成 SVG，文字又按原规范隐藏。现将新动作图标刷新合并到微任务，在节点挂载后完成渲染；重建和替换素材也使用该流程。
- 对已解码的缓存图片，尺寸测量同样延迟到节点挂载后，避免宿主忽略未连接 DOM 的尺寸事件。
- 沿用 Neon/Flora 组件和语义令牌；放大、下载、替换、删除仍使用原动作处理。宿主与 flora-node-shell.js 均更新缓存版本，已有节点刷新后可加载修复。
