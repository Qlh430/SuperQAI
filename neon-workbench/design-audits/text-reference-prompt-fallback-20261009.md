# 连接文字节点后的提示词校验修复

日期：2026-10-09。

## 根因与修复

图片生成节点的提交校验通过连接输出快照获取文字。画布虚拟节点刷新期间，该快照可能暂时没有文本，即使连接源节点当前有内容，也会被误判为“请输入提示词”。

此前的实时读取兜底仍依赖来源节点已挂载；来源节点被虚拟化卸载后，连接线仍在，但素材卡片和提示词会为空。现在生成前优先使用连接输出快照，同时从已连接的文字/语言模型节点读取最新正文；来源暂未挂载时改读虚拟节点保存模型，并去重后合并手动要求。因此连接了有内容的文字节点即可提交，手动输入仍可继续补充。

- 新增来源节点卸载后的回归：虚拟节点仍能恢复文字素材卡片与完整正文。
