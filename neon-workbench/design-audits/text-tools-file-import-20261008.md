# 文字工具与文件导入验收

2026-10-08。用户确认支持 TXT、MD、DOCX、PDF 四类文档后实施。参考图片只用于功能交互，控件、模态界面、颜色和描边沿用 Neon/Flora 体系。

## 实现结果

- 文字节点工具栏增加背景色、放大编辑和 Markdown 下载。六种背景使用既有默认表面及标签色，正文背景采用语义表面的色彩混合，保持文字可读；textBackground 经宿主节点操作保存，撤销、重做、恢复、内部复制均保留。
- 放大界面使用原来的编辑 DOM 与格式按钮，避免重复正文状态。编辑完成关闭后同步到节点，Escape 关闭、原位置恢复；原生 dialog 管理模态焦点。标题显示节点名称，节点与放大界面均可下载当前正文为 UTF-8 .md；粗体、斜体、标题、列表和下划线语义保留。编辑面没有绿色内框，按钮键盘焦点仍保留。
- 画布拖放和粘贴按文件分类：图片、视频、音频各为独立媒体节点，TXT/MD/DOCX/PDF 各为独立文字节点。空 MIME 的常见媒体文件按扩展名补全上传类型。图片和视频读取实际尺寸后，再按实际宽度排列下一个节点，避免横图展开后覆盖后续节点。
- TXT 支持 UTF-8、带 BOM 的 UTF-16 与 GB18030 回退，按纯文本显示；MD 保留 Markdown。DOCX 用 Mammoth 提取正文，PDF 用 PDF.js 提取文字层，中文 CMap/字体/worker 均由运行时同源提供。复杂文档解析包仅首次导入 DOCX/PDF 时加载。文档最多 50 MB，正文最多 200 万字符，PDF 最多 300 页。扫描 PDF 不含可提取正文时显示中文提示，不做 OCR，不复刻复杂分页排版。
- 解析/预览失败显示中文节点错误，一个文件失败不会阻止后续文件；画布切换后，旧解析结果不写入新画布。编辑正文时不会抢走文件粘贴。原先 Ctrl+V 抢用旧内部节点复制的问题通过系统剪贴板标记与 paste 事件分类修复：内部复制可继续粘贴，外部剪贴板覆盖后可正确导入。
- 自适应媒体原本清除外壳边框且预览覆盖卡片，导致选中绿边消失。新增不接收指针事件的主体描边覆层，位于媒体之上；取消选中隐藏，不改变图片/视频内容比例和交互。
