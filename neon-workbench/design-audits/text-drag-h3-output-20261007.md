# 文字节点拖动与 H3 视频输出验收

日期：2026-10-07。运行入口为 3199，目标来自运行时诊断：`AI-OS-Portable-1.0.5-win-x64/.ai-runtime/versions/1.0.5-win-x64/resources/app`。

## 修改与原因

- 文字区域不再在 pointerdown 时进入编辑或截断预览拖动事件；单击选中，按住主体移动，双击编辑。编辑中的 pointerdown 保留文本选择，失焦或 Escape 提交。新拖动复用宿主的坐标、撤销和保存路径。
- 移除文字工具栏入口与空参考区常驻说明，上传按钮和真实素材仍可用。
- 文字模型使用现有 Flora 模型选择器，沿用相同令牌、圆角、间距、焦点、分组与浮层定位。实际 select 保存模型值并发出 change，增强后隐藏，模型菜单不受节点与操作区滚动裁切。菜单关闭保持类变更幂等，避免观察器回路。
- H3 参数注入早已适配新节点编号，但任务服务的输出读取仍写死旧节点 230，因此当前保存节点 375 返回结果后被误报失败。改为从提交的工作流识别 SaveVideo。缺少保存节点在提交前报错，完成但没有视频时给出中文诊断。
- `minimax-h3-task-service.js` 纳入规范源与部署管理。部署前备份旧文件，最终备份：`.design/deploy-backups/2026-10-07T11-56-54-748Z`。规范源与部署后任务服务 SHA256 相同。

## 生效与业务边界

浏览器检查使用隔离的模拟 API，没有修改用户真实画布或调用外部付费服务。H3 后端测试加载真实部署模块并模拟 ComfyUI 的完成历史，未向真实 ComfyUI 提交生成；真实登录、真实视频下载及用户画布保存仍需要现有登录会话验收。Better Design MCP 当前未连接，本报告没有动态审查结果。

本轮保留当前 3199 桌面服务。后端模块由应用启动时 require，**必须从托盘彻底退出并重新打开应用一次，视频后端修复才会生效**；单纯刷新页面不会重载服务端模块。
