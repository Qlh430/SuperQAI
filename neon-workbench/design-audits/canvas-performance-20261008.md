# 画布流畅度优化验收（2026-10-08）

用户已确认：优化流畅度，保留当前功能、交互、样式及媒体质量。工作对象为 Neon 独立工作台和 Flora 节点；保留工作区原有改动，未操作用户画布或生成数据。

## 根因与实现

1. 平移缩放时，`--collab-inverse-scale` 从 canvasPlane 向全部节点后代继承，触发大量样式重算。CDP 追踪显示旧实现 45 次缩放约 3.86 秒用于 UpdateLayoutTree；隔离诊断冻结该值后约 16 毫秒一帧。冻结仅用于诊断，未用于生产。
2. 注册该数值属性为非继承属性，使用一条共享 CSSOM 规则，仅向实际使用它的工具栏、运行按钮、连接点、标题点击区域、分辨率、历史角标、SVG 路径、协作光标及素材选中伪元素提供原数值。不重复写入相同值；后创建和恢复的节点、结果、路径及光标自动匹配。原有 CSS、视觉数值和动画保持不变。
3. `FloraGeneratorComposer.sync(node)` 仅同步目标节点；选择切换和全局事件仍同步全部节点。隐藏操作区不再安排必然空跑的定位帧。保留原 getBoundingClientRect 定位公式，移除诊断期间尝试的坐标缓存及 ResizeObserver，避免祖先位置变化造成漂移。
4. `collectCanvasDirtyOperations` 每批仅获取一次 pending 快照，用 Map 查找已有操作并即时更新。保留全部节点扫描、序列化、保存计时、操作标识、最初 before、撤销条件和 board.patch 合并；遇到重复记录时保留原 find() 的首条语义，没有丢弃重复记录或跳过保存。

## 性能实测

在同一台机器、同一 1440×1050 宿主画布上，以隔离 API 创建并固定挂载 36 个节点（30 个图片生成、6 个 H3 视频生成）及连接。使用 Edge/CDP，分别记录空闲、平移、平移缩放、拖动和输入。基线取部署前实际宿主，最终值取部署后宿主，性能测量期间不同时运行其他浏览器回归。

| 指标 | 部署前 | 最终部署 | 变化 |
| --- | ---: | ---: | --- |
| 平移缩放帧耗时中位数 | 101.2 ms | 48.7 ms | 约减少 52% |
| 平移缩放帧耗时 P95 | 119.3 ms | 58.5 ms | 约减少 51% |
| 平移缩放长任务数量 | 44 | 13 | 减少 31 次 |
| 普通平移帧耗时中位数 | 16.7 ms | 16.7 ms | 维持原水平 |
| 20 次输入的保存扫描总耗时 | 280.6 ms | 87.1 ms | 约减少 69% |
| 输入阶段序列化调用 | 720 | 720 | 完整扫描未删减 |
| 单节点同步扫描无关操作区 | 49 次 | 0 次 | 消除无关扫描 |
| 8 节点保存批次读取 pending 列表 | 16 次 | 1 次 | 消除逐节点整表复制 |

普通平移、拖动、输入阶段均未记录到长任务。完整报告在 `.design/canvas-performance/before-final.json` 和 `after.json`；多次候选测量约 46–49 ms/帧，数值存在正常波动。这是固定夹具的机器实测，不是用户实际画布的全面采样，也不承诺所有硬件固定帧率。
