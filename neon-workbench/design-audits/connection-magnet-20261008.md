2026-10-08，用户确认执行；参考视频仅用于功能与交互，视觉沿用 Neon/Flora。

## 实现

- 所有实际连接端口共用 Flora 连接交互模块。感应半径为 34 屏幕像素，端口向鼠标轻微跟随，最大位移 8 屏幕像素；移出范围后归位。不移动系统鼠标。
- 感应范围内可以开始拖线；正向和反向拖线均优先吸附最近兼容端口，预览线端点对齐真实端口，松开完成连接。素材合集保留实际成员端口标识；不兼容端口不吸附。
- 避让编辑区、操作区、标签、工具栏、缩放把手和其他按钮，保留节点拖动与文字双击编辑。拖线结束后抑制后续鼠标 click，避免再次进入待连接状态；Esc、pointercancel 和窗口失焦均清理拖线。
- 已有连线改为清晰实线，使用 Neon muted 令牌；鼠标悬停或选中相关节点时使用 primary 高亮。拖线预览使用 primary 虚线；扩大透明连线命中范围。
- 修复场景层启用时旧 CSS 隐藏 SVG 的问题，预览和交互连线持续可见。SVG 使用 non-scaling-stroke，并抵消外层画布 CSS 缩放，使普通线保持约 2.5 屏幕像素、高亮线保持约 3 屏幕像素。缩略场景也使用同一语义颜色。
- 鼠标感应不保存业务数据；连接仍通过既有兼容校验、连接操作、撤销和宿主保存机制处理。
