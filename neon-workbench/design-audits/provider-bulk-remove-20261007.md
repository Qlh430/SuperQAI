# 可用模型批量移除验收（2026-10-07）

## 实现

- 在 API 模型服务编辑器的可用模型卡片前增加独立勾选控件，勾选不展开配置。上方提供全选、已选数量及移除所选。
- 全选覆盖全部当前草稿模型，部分选择显示中间态；全部选中后再次点击清空选择。排序保持模型ID选择，新加入模型默认不选。
- 单项和批量移除共用状态清理，删除后不残留选择、展开状态和参数错误。移除只改草稿，取消放弃；保存连接后沿用已有目录同步，支持保存空模型列表。
- 复用当前独立工作台的官方 Neon Button/Card、语义令牌和 lucide 图标。按钮44px，桌面同排，窄屏自动换行；没有引入新颜色、圆角、边框或阴影体系。
