# 文字节点所见即所得编辑

按用户确认的范围，空态显示「双击开始编辑…」，编辑空态显示「请输入文字内容…」。已有内容有「双击编辑」悬停提示。预览和编辑保留相同的富文本 DOM 与排版，移除内部焦点绿框，只保留 Flora 外层选中边框。

现有节点工具栏在编辑时显示粗体、斜体、下划线、正文、一级/二级/三级标题；使用官方节点操作按钮、Lucide 图标及 Neon 语义令牌，中文提示、状态与选区保持。按钮格式化使用浏览器编辑事务，支持编辑中撤销/重做；离开编辑后可从画布撤销整次编辑。失焦和 Escape 提交。预览仍可单击选中、按住文字或空白处拖动。

`text` 保留兼容模型和连接的 Markdown。新增 `textRichHtml` 保存清理后的语义格式，并接入节点序列化、恢复、复制、画布操作撤销和生成历史的 `richHtml`。历史为空的普通文字节点恢复时不再被空历史清空。粘贴剥离外部字体、背景、颜色、事件、主动内容及危险链接，仅保留语义格式。
