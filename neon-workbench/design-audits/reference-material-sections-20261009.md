# 参考素材分区验收（2026-10-09）

## 结论

生成操作区现在按实际连接的素材类型显示参考卡片。单一类型直接显示卡片；出现多种类型时按图片、视频、音频、文本连续分区，空类型不会占位。参考区始终只有一个加号，并在最后一个已显示分区后面。每张卡片右上角的关闭按钮会断开对应来源连接，删除后分区和同类型序号立即重排。

加号支持图片、视频、音频以及 TXT、MD、DOCX、PDF。媒体文件会创建对应的画布素材节点，文档会创建文字节点并连接到当前生成节点。

API 视频模型列表过滤本机 ComfyUI 传输项；本机 MiniMax H3 节点在参数中显示本机模型选择，并把选择作为 `model` 发送给任务服务。
