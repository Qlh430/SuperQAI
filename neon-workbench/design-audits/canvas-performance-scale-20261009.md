# 画布规模压测与离屏绘制优化（2026-10-09）

本轮承接 2026-10-08 的 36 节点优化，目标是验证 100、300、1000、2000 个节点在离屏、同时可见和图片/视频混合场景下的场景层开销。测试使用同一台机器、1440×1050 视口和隔离的 Node 场景层夹具，未连接真实业务 API，也未读取或修改用户画布。

## 根因与改动

场景层收到分页后的视觉节点后，原实现会对全部节点和连接线排序、绘制并建立命中区域，即使它们完全在当前视口和缓冲区之外。节点越多，绘制调用和命中区域就线性增长。

`design-sources/canvas-scene-layer.js` 现在使用带 32px 安全边界的场景绘制范围：超出范围的节点和贝塞尔连接线直接跳过，命中区域与诊断计数只保留实际绘制项。缓冲区边界、排序、纹理请求、连接路径形状和选中描边规则保持不变；下一次视口移动或缩放触发重绘后，进入范围的节点会正常出现。

## 压测结果

`canvas-performance-scale.cjs` 运行 8 次绘制并取中位数/P95；`drawCalls` 是隔离 Canvas 夹具的调用计数，用于比较工作量，不等同于浏览器帧率。

| --- | ---: | ---: | ---: | ---: |
| 离屏 | 100 | 14,141 → 701 | 1.182 → 1.128 | 0 |
| 离屏 | 300 | 42,141 → 1,037 | 0.528 → 0.142 | 0 |
| 离屏 | 1,000 | 140,141 → 1,037 | 0.666 → 0.530 | 0 |
| 离屏 | 2,000 | 280,141 → 1,037 | 0.532 → 0.479 | 0 |
| 同时可见 | 100 | 14,141 → 2,101 | 0.272 → 0.424 | 14 |
| 同时可见 | 300 | 42,141 → 5,097 | 0.179 → 0.315 | 35 |
| 同时可见 | 1,000 | 140,141 → 5,097 | 0.570 → 0.380 | 35 |
| 同时可见 | 2,000 | 280,141 → 5,097 | 0.757 → 0.278 | 35 |
| 图片/视频混合 | 100 | 11,369 → 1,765 | 0.280 → 0.258 | 14 |

同一夹具还记录了平移、缩放、拖动、输入和保存操作。场景层重投影的平移/缩放中位数均低于 0.003ms；2000 节点时拖动中位数约 0.19ms，输入序列化约 0.90ms，保存快照约 1.08ms（混合媒体场景输入约 0.85ms、保存约 1.42ms）。夹具未产生超过 50ms 的长任务；这些是 Node 隔离数据，不能替代浏览器真实帧和网络加载测量。
