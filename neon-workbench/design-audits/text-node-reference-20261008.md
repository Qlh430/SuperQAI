# 文字节点参考图片连接修复

2026-10-08，用户授权修复“参考图已上传，但当前模型无法接收该连接”。

## 根因与修复

- 原连接规则允许图片进入旧 LLM 节点，却遗漏当前文字节点；上传实际已成功，建立连接失败后又被统一显示成上传失败。此时没有调用模型，错误信息不能说明模型不支持识图。
- 图片、图片合集以及空上传节点的预连接规则加入文字节点。素材合集仍只接受图片，不放行视频/音频；沿用已有连接、保存与撤销机制。
- 文字节点连接更新时复用 LLM 参考图渲染，连接/重连显示缩略图，断开后移除。正文保持不变。
- 上传处理区分上传阶段和添加阶段，连接失败显示实际连接兼容原因，输入端口异常显示检查端口提示，不再无依据归因于模型。
- 原请求构造保留：参考图片通过 image_url 与完整当前正文、本次要求一起发送；模型服务实际报错仍显示原接口错误。
- 无样式或设计体系变更，继续使用 Neon/Flora 操作区、参考图和状态组件。宿主缓存版本更新为 `20261008-text-node-reference`。
