# Qwen-image2.1 接线与部署验收

日期：2026-10-10

## 结果

- `comfy-workflow-task-service.js` 已支持 Qwen-image2.1 图像编辑与生图双模板：有参考图走 edit，无参考图走 generate。
- 请求注入已覆盖提示词、最多 8 张参考图、`ResolutionSelector` 的比例与像素档、`Seed (rgthree)`、`SaveImage.filename_prefix`；两组提示词增强器保留。
- `deploy.mjs` 已复制三个运行时模块、同步两份模板到运行时和 `data/workflows`，并显式补齐 composition 的 `qwenImage21Edit/qwenImage21Generate` 映射。
- 客户端 ComfyUI 模型下拉只保留「Qwen-image2.1」；换鞋、Flux2 Klein 图片编辑、抠图·ComfyUI 不再暴露为模型入口。

## 验证

- `npm run build`：通过。
- `node deploy.mjs`：通过，部署脚本完成目标文件备份。
- `node qwen-image21-service-regression.cjs`：通过，模板结构、槽位裁剪、种子、分辨率、模式路由、8 张上限和显式路径均通过。
- `node qwen-image21-node-regression.cjs`：通过，模型列表、参数、工具面板、无参考图 `images=[]` 和有参考图 `images.length=1` 均通过。
- `node acceptance.cjs`：通过，390/768/1440/1728 四种宽度共 48 张截图，`errors=[]`、`overflow=[]`。

## 边界

回归使用隔离模拟 API 和测试画布，验证的是请求结构、界面状态和部署文件一致性。当前运行中的 3199 桌面服务未停止，新的服务模块需重启工作台后加载；真实登录后的 ComfyUI 连接、模型可用性、权限、持久化和真实出片质量仍需用户会话验收。Better Design MCP 当前未连接。
