# Midjourney 单入口与齿轮版本验收

日期：2026-10-09。用户确认后实施；仅修改现有统一图片生成节点的模型展示与设置映射。

## 结果

- 每个服务商在外部模型列表仅显示一个「Midjourney」入口，触发按钮也只显示 Midjourney；不同服务商仍独立分组。版本选择集中在原齿轮「模型版本」中。
- 单一模型接入保留真实目录 ID，按版本提交 version / niji；目录提供独立版本 ID 时，齿轮选择映射到该服务商的真实 ID。展示聚合不删原目录或修改旧节点。
- 同一服务商泛模型与独立版本并存时，优先保留当前实际模型；重新选择当前外部入口不重置版本。已保存独立版本节点恢复后不擅自换成泛模型。
- 继续使用现有接入与版本能力交集、中文控件、严格类型与格式规则。未知接入不冒用 APIMart 参数；兼容参数随齿轮版本变化，原保存、复制、目录迟到与历史快照路径保留。
- 沿用 Neon/Flora 弹层、颜色、尺寸、间距和焦点样式，本轮未改 CSS。
