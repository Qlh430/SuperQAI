# 图片生成节点下方操作区验收

用户已确认上方预览、选中后下方展开操作区、取消选中保留输入的结构。此次只调整 generator 节点，使用当前 Neon 语义令牌、Lucide 图标和 Flora 壳体规则，未将参考图的视觉体系引入项目。

## 实现

上方保留 400×400 主体和 48px 标题带，显示图片占位或真实结果。下方操作区桌面最大 960px，与主体相隔 16px；宽度随视口收窄，控件通过反向缩放保持屏幕尺寸。节点接近底边时，初次选中会平移画布留出操作空间，面板内部可以滚动。收益是预览与编辑层次明确；代价是选中时需要更多下方画布空间。

提示词、参考图、模型、尺寸、清晰度、高级参数和原生成按钮仍是原节点中的实际 DOM，原查询、序列化、事件和价格来源继续有效。添加参考图调用宿主上传、创建素材节点并连接到当前生成节点，错误显示中文。结果更新保留在上方，不移动到参考区。面板折叠不清空草稿或停止任务；多选隐藏操作区。

修正了状态观察器的重复属性写入、挂载早于画布追加时的变换监听、真实宿主卸载/切板以及同帧创建删除的清理路径。面板内部交互不拖动节点，预览主体可以拖动。

原有线上 API / 线下 ComfyUI 引擎选择一并迁入操作区，来回切换保留提示词。补测发现宿主原先在 ComfyUI 插件加载前就捕获辅助组件为 undefined；现改为使用时读取。引擎重渲染时丢弃旧壳体的控件，避免旧 API 选项被恢复进新 ComfyUI 节点。独立复审确认这些修正没有剩余实质问题。

## 边界

浏览器测试拦截了业务 API，参考图上传使用实际宿主上传函数但响应模拟，生成按钮使用模拟生成回调；序列化使用实际宿主函数。没有写入用户真实画布或触发付费生成。真实登录后的服务商与模型、高级参数、权限、生成结果和持久化保存仍需在用户已有会话验收。现有视频 Range 服务端模块仍需应用完整重启后，在原视频上验证，不能将隔离媒体服务结果代替该边界。
