# API 模型服务设置验收记录（2026-10-07）

## 已确认功能

- 服务编辑使用独立 Neon 工作台的官方 Dialog、Input、NativeSelect、Button 和语义令牌。顺序为名称、同排的平台协议与网络线路、URL、密钥；移动端堆叠并允许弹窗内部滚动。
- 拉取模型只返回候选列表，支持搜索、分类、多选和计数。确认加入才进入当前草稿，保存连接才写入服务。重复模型不会覆盖既有配置。
- 可用模型支持手动添加、配置能力/模型协议/分辨率/默认参数、排序、测试与移除。错误和空态使用简体中文。模型测试只有明确点击才调用上游。
- 没有密钥时为空；已有密钥以真实值的密码掩码展示，可显示、隐藏、复制和编辑。清空后保存删除密钥。读取失败阻止保存并提供重试，避免误删。
- 保存、删除或启用成功后，刷新现有生图、对话、视觉、视频和 Agent 模型选择器，并通过同源宿主桥接更新已经打开的画布。按能力筛选、保留有效选择与提示词，同名模型保持服务商身份；失效选择显示中文重选提示并阻止提交，不静默切换模型。当前没有独立的音频生成模型选择器，音频素材节点保持原播放交互。
- 模型目录读取失败保留原列表并显示中文错误，重试成功清除错误。旧请求不能覆盖新目录。

## 审查与视觉记录

独立代码复审发现并修复了分辨率输入分隔符被过早移除、模型标题点击区域不足、对话与视觉目录刷新竞态，以及失败后的重复刷新清除错误提示问题。模型名称按钮最小点击高度补为44px。

Better Design 本轮实际连接并读取表单原则，执行文案与 DOM 间距检查，没有虚构动态审查结果：

- 编辑服务和选择发现模型两个实际操作状态的文案检查均通过，原始结果分别为 `provider-copy-editor-20261007.json`、`provider-copy-candidates-20261007.json`。该检查只评估传入文本，不代表真实用户研究。
- 修正44px后，390与1440的最终间距检查各有0项 critical、3项 serious、1项 moderate；没有触控目标不足提示。原始结果为 `providerFinalSpacing0-20261007.json`、`providerFinalSpacing2-20261007.json`。
- serious 分别来自官方 NativeSelect 左12px/右36px为箭头预留空间，以及官方 Dialog 的1px屏幕阅读器关闭文本。人工核对为组件预期结构，不调整官方组件。
- moderate 涉及官方控件6/36px留白、表单20px间距及移动端自动右对齐产生的浮点距离；保留现有组件与令牌，不为满足启发式规则引入另一套样式。
- 四宽度默认/悬停/焦点截图和选中状态交互已验证。现有生成节点浮层、全屏及不同画布缩放回归通过。
