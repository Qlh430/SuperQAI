# 全部画布页面修复验收

日期：2026-10-01

## 本次修复

- 将画布库整理为独立的 Neon 页面表面：标题区、范围导航、项目筛选、搜索、画布卡片网格。
- 删除重复的 v2 CSS，统一使用 `neon-page-canvas` / `#canvasView` 作用域和 Neon 语义令牌。
- 修复列表与编辑器的隐藏状态冲突：`hidden` 元素不会被强制 `display:block`。
- 保留移动端项目筛选，以横向滚动承载项目项。
- 修复项目激活态选择器，卡片操作按钮尊重权限隐藏。
- 画布卡片改为可聚焦语义卡片，分享、删除、恢复使用真实按钮；空预览显示 Lucide 图标和“暂无预览”。
- `deploy.mjs` 现在会先备份运行时，并从 `design-sources` 同步画布脚本和页面 CSS，保证修改可重复部署。

## 已执行验证

- `npm run build`：通过。
- `node deploy.mjs`：通过。
- `acceptance.cjs`：通过，`errors=[]`、`overflow=[]`，48 张常规页面截图。
- `bridge-acceptance.cjs`：通过，覆盖来源验证、画布标识转换、保存失败阻止返回、成功返回、退出会话清理和异步竞态。
- 目标页截图：`screenshots/live-1440.png`。
