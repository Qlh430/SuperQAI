# 风格测试与图片/视频提示词

在设计代表性风格测试、图片分镜提示词、视频提示词或外部平台适配时读取。

## 提示词层级

始终保留三层：

1. **平台无关镜头规格**：批准的故事、构图、动作、连续性和起止状态。
2. **核心提示词**：适合人工阅读和跨平台迁移的自然语言版本。
3. **平台适配**：只在用户明确平台后添加语法、长度、参考槽、时长、首尾帧或负面提示格式。

平台适配不得改写故事事实或镜头设计。若平台能力不确定，标记待确认，不虚构参数或功能。

## 代表性风格测试

测试任务由项目风险决定，通常覆盖：

- 场景空间和整体色彩。
- 人物身份、服装和表情。
- 人物与场景/产品共同出现的比例和接触。
- 复杂材质、手部、反射、透明、液体或关键动作。
- 最能体现作品气质的核心构图。

每项明确：测试目的、保持项、允许变化、通过标准、常见失败和下一轮修改方向。未经用户提供结果，不声称测试已完成。

先建立少量权威参考，再批量扩展：人物身份/服装/比例、产品结构、核心场景、主色与材质、关键状态。情绪板负责统一色彩、构图、质感和灯光；角色多视图或稳定角度负责身份；关键场景锚点负责空间。不要在这些基线未锁定前一次性生成完整分镜。

## 图片提示词设计

复杂项目先分开建立：人物身份、人物状态、空场景、产品/道具状态、接触参考、逐镜头关键帧。只有在控制力不受损时才合并。

核心结构：

```text
[已批准的人物/主体与权威参考]，处于[场景和连续性状态]。
[景别、视角、构图、主体位置、前景/中景/背景关系]。
[视觉焦点、人物视线、留白/遮挡和空间关系；色彩与灯光在本镜的具体叙事功能]。
[道具/产品的几何、比例、状态、位置和接触关系]。
[光线方向、色彩关系、材质和纹理表现]。
[表情、姿势、动作瞬间和本镜头要传递的信息]。
保持：[身份、服装、场景布局、关键事实和连续性锚点]。
文字/Logo/UI：[使用官方素材、留空占位或后期合成方案]。
避免：[具体的解剖、重复、变形、错误文字、空间和风格问题]。
```

每条 `PTI` 还要包含：关联 `SH/状态`、用途、参考、风险、备用方案和可观察通过标准。

## 视频提示词设计

从已批准 `SH` 和关键帧派生：

```text
[景别和视角]，摄影机从[位置]开始，以[一个主要路径和速度]与主体形成[跟随/领先/接近/分离]关系。
[主体]从[状态/位置]开始，完成[一条清晰动作因果链]，结束于[状态/位置]。
[前景、中景、背景的运动、遮挡和视差]。
[接触、重量、惯性、环境反馈和可见结果]。
[由动作引起的光线或色彩变化]。
保持：[身份、几何、比例、空间布局、状态和连续性锚点]。
结束于[稳定构图]，保留[剪辑余量]。
避免：[隐藏切镜、不相容运动、形体漂移和不支持的变化]。
```

每条 `PTV` 同时记录：最终使用时长、建议源时长、输入参考、声音时刻、下一镜头接口、验收标准、风险和简化方案。

## 风险与备用方案

- **低风险**：单一主体、简单动作、稳定环境、非关键细节。
- **中风险**：人物一致性、轻度接触、摄影机和主体协调运动。
- **高风险**：精确产品/文字/UI、复杂手部、多人物接触、反射透明液体、遮挡、形变、多状态转换或复杂旋转路径。

高风险任务优先拆分、减少状态变化、使用更稳定的首尾帧或建议外部合成/实拍/3D/屏幕录制。这里只提供方法建议，不执行媒体操作。

## 验收标准

标准必须能通过画面观察，例如：

- 人物身份、服装和发型与批准参考一致。
- 主体和摄影机都向画面右侧移动，速度关系清楚。
- 右手接触指定位置，手指不穿插物体。
- 门框快速越过前景，背景移动更慢，形成明确视差。
- 结束画面稳定，主体位置适合下一镜头切入。

避免只写“电影感、高级、唯美”。把这些目标翻译为光线方向、色彩对比、构图、材质、镜头运动和节奏。

参考图负责“保持什么样”，提示词负责“本镜发生什么”。当输出局部错误时，先判断能否保留可用主体、背景或动作阶段，再只改问题状态或连接段；不要默认通过叠加更多负面词或整批重跑解决。
