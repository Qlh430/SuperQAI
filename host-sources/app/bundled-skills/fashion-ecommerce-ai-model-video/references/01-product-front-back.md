# 阶段一｜服装产品正反面标准参考图

## 输入和结果

输入：**当前一件商品**的原始商品图，可含正面、背面、多视角、模特或生活背景。将多个视角视作同一件衣服的信息，不得当作多件不同商品。

输出：**一张**高清专业电商商品图，纯平白 `#FFFFFF` 背景；**左边完整正面，右边完整背面**。两视角互不重叠，比例、长度、材质、颜色、照明与对齐一致；产品完整位于画面内。不得输出分开的两张图、多套变化方案或其他角度。

## Agent 的产品分析清单

先识别品类、面料外观、颜色、印花/图案、Logo/文字、领口/领型、袖口/袖长、肩部、腰线、下摆、裙摆/裤腿、前后开合方式、纽扣、拉链、搭扣、绑带、肩带、五金、口袋（数量/大小/位置）、裁片、褶皱、接缝、明线/暗线、比例、廓形、长度、松紧、层次、局部纹理。以实际可见内容为最高依据，禁止凭空补造细节。

判断已提供：`仅正面` / `仅背面` / `正反面都有` / `方向不确定`。

- 已提供的视角：必须逐项忠实保留，不能因为生成另一侧而改变已有一侧。
- 未提供的视角：根据同一服装品类、版型、材料、接缝、领口和可见结构**保守推断**。缺失的图案、文字、Logo、口袋、装饰、五金等不得无根据添加。
- 原图如果已有可信的背面：以实际背面为准，不可用想象的“标准背面”覆盖真实信息。
- 若方向不能可靠判断，先确认或报告不确定，不假装已知道正反。
- 背面缺失时，在 Agent 结果说明中注明“背面为 AI 推断，仅供视觉策划参考”；展示图本身不加文字水印或标签。

## 节点完整中文提示词写法

生成时把方括号字段替换为**该商品实际观察到的内容**，不可将这些字段原样留下：

> 基于我提供的【当前单件服装原图】制作一张写实的专业电商服装商品参考图。该商品是【品类】，原图可见【颜色、版型、材质表现、领口袖型、衣长、结构、口袋/纽扣/拉链/印花等真实细节】，这些可见细节是唯一可信的产品外观依据，必须逐项精确保留。分析提供了哪些视角：【正面/背面/正反面】。输出画面中恰好两个完整独立的视图：左侧正面、右侧背面，两者属于同一件真实商品，比例、造型、颜色、面料、长度和结构完全一致。对于已经提供的视角忠实再现；仅在参考图缺失的一侧，根据该服装真实可见结构、品类和材料做最保守的合理推断，绝不凭空添加图案、Logo、文字、口袋、纽扣、拉链、装饰或不可信结构。移除模特、人体、衣架、道具、家具及原背景，只保留整件服装产品。纯平白色背景 #FFFFFF，均匀专业电商摄影棚光线，真实布料纹理和厚度，边缘清晰、自然垂坠、透视准确。左右两视图等比例、对齐且间隔舒适，留足白边，绝不裁切衣领、袖口、腰部、裤腿、下摆、肩带或其他部位。画面中不出现第三视角、附加单品、模特、人台、分屏装饰、阴影背景、渐变、标签、注释、箭头、水印或文字。输出一张可供后续模特穿搭参考的真实高清正反面合成商品图。

若已提供清晰正反面且成品符合白底要求，可以选择复用原始参考，避免无意义的再次生成；如果合成图里的背面是推断，不能把它当作得到实物认证的真实背面。

## 验收

- 同一画面只有两视图，左正右背，均完整且不重叠。
- 白色背景像素目标为纯平 `#FFFFFF`；避免灰白、乳白、渐变、纹理、场景。
- 可见商品细节一致；同一件产品的比例、版型、颜色、印花、袋位、扣子一致。
- 正反面实际依据与推断边界清楚；不把推断照片当实物证据。
- 无人体、模特、衣架、道具、文字、额外商品或虚假的产品结构。
