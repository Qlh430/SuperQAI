# Agent 画布执行与验收指南（工具无关）

此文件用于指导 Agent 在拥有画布编辑/生图/生视频能力的环境中执行 Skill；不是特定 AI OS API 清单。只能使用当前会话**真实公开可调用**的工具，不猜测函数名或端口。

## 1. 确认任务模式

- **仅方案**：输出分阶段思路或所需提示词，不创建任何节点。
- **搭建画布（默认）**：准备真实输入素材、创建/复用节点、写入自足中文提示词、设置真实素材关联、排列及保存；不执行任何可能收费的图像/视频生成。
- **执行生成**：用户明确授权运行时，按每一阶段顺序执行，并遵守原有费用确认与重试/额度机制。不能把“帮我搭工作流”当成默许付费。

## 2. 创建逐产品结构

对于 N 件商品（建议 1–10）：

`商品 i 的真实原图节点` → `商品 i 的白底正反面图生成节点` → `商品 i 的单人模特正面图生成节点` → `商品 i 的自然转身视频生成节点`

必要时后续节点可以同时接受**本商品原图**的辅助参考，但只要环境支持有效多路输入，不得假设任意工具能接受任意类型。多件商品分别建立 N 条不混淆的分支；单件原图不复制 N 份。

推荐名称：

- `01_裙装A_白底正反面`
- `02_裙装A_模特正面`
- `03_裙装A_自然转身视频`
- 其他产品按相同规则命名；序号或简称供展示，不是产品内部不可变 ID。

每个真实生成节点都应填入**针对该产品重新具体化**的完整中文提示词，不能只有“套用 Skill”“使用上一节点提示词”等占位。

## 3. 有效关联而非视觉连接

- 用户将产品图发给 Agent：若尚无真实画布资产，先使用许可的导入/引用工具加入本工作流；不应凭空声称“已经连接”。
- 当前画布已有原图：使用已有节点 ID / 资产引用，不再导入重复文件。
- 阶段二依赖阶段一生成结果。阶段三依赖阶段二模特真实成品；若上游尚未运行，只在**画布确实支持待运行依赖**时建立可解析的连接，明确“待生成”。
- 如当前工具无法自动建立图像到图像/图像到视频的输入连接，应将对应节点留为“待关联”，明确报出缺少哪种能力，不能创建装饰性连线或谎报连接完成。
- 有现成合格阶段结果时复用并减少生成节点；用户明确要求重做时才重建对应节点。

## 4. 可重复执行与恢复

重复使用 Skill 前检查当前画布上已存在的同一任务分支和用户目标。只新建缺失节点或按用户要求更新特定提示词，**已完成的操作不重复做**。不要因为模型切换、工具超时或 Agent 回合上限重复创建一套工作流。对收费的图片/视频生成，遵守现有幂等、用户授权和重试规则。

正常按所属商品分列布局，阶段从左到右，清晰标注“待执行/执行中/已生成/待验证/已通过/失败”；已创建 ≠ 已生成 ≠ 已通过质量验收。

## 5. 最小验证和准确回报

1. 是否真实创建或复用了对应 N 件产品的输入素材？是否把某商品错误连接到另一商品？
2. 是否有该商品的三阶段生成节点或已复用的真实阶段结果？提示词是否是完整中文且每件不同？
3. 依赖和连接是否由当前真实 API/节点端口确认，而非视觉上看起来连着？
4. 是否保存成功并在允许的情况下刷新/重新打开仍存在？
5. 默认没有自动付费生图和生视频？
6. 如果用户启动生成，输出是否真的生成并可预览？质量验收依据是否真实？
7. 正反面未提供的一侧是否正确说明属于推断？视频是否存在产品漂移、错误口袋、机械转身或首尾不一致？

向用户汇报时分开列出：**真实创建、真实关联、已保存、已生成、质量检查、待用户确认**。即使只有部分完成，也应清楚报告哪一个阶段受阻及已保留的成果。
