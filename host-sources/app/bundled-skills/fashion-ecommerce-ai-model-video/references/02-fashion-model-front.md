# 阶段二｜单人模特正面上身图

## 任务边界

输入：对应当前商品的正反面参考图（及原产品可见信息）；用户可指定模特特征、目标人群、画幅。正反面只用于理解**一件商品的完整结构**，最终图只输出**单人、单张、正面**。不得产生双视图、拼图、多个模特或多个角度。

## 专业分析与强制保真

逐项识别该商品的：品类、颜色、图案、Logo/文字、面料纹理、材质、剪裁、宽松度、衣长、版型、领口、袖长、袖口、肩线、裙摆/裤腿、口袋、钮扣、拉链、五金、绑带、开合方式、缝线、褶皱、比例和物理垂坠方式。优先引用真正可见的商品细节；推断的背部视角只作为低置信度参考，不可据此改变正面已知结构。

**口袋规则尤其重要**：原商品没有口袋就绝不能出现口袋，甚至不能靠手势、折痕、阴影暗示有口袋；有口袋时必须忠于真实的数量、位置、形状和大小。所有手都不能插口袋，也不得按压、遮挡产品图案和设计重点。

### 模特和姿态

- 根据商品和用户人群选择真实且适配的模特，不固定为女性或 22 岁；脸部自然、专业、**不微笑**，真实皮肤纹理、毛孔和细微不完美，不要塑料肤质和过度磨皮。
- 模特正面对着镜头，脸和躯干都保持正面，完整展现产品正面。体重自然落在一条腿上，另一腿略微松弛或脚尖稍前移；肩膀放松，轻微自然不对称，不能站成木偶。
- 双手松弛置于衣服关键区域之外，肘部可轻微弯曲。禁止双手插袋、叉腰、交叉手臂、夸张摆姿、遮挡领口/腰线/缝线/扣子/图案。衣服不被拉拽、掀起或扭曲。
- 避免腿过长、腰过细、手指数量异常、肢体拉伸、僵硬对称、戏剧性扭身、舞台感时装走秀。

### 搭配规则

- 若原图是**整套穿搭**：保持所示成套产品，不重新配色或换款。
- 若只有上衣：配简单低调的裤/裙/鞋，不挡住主商品。
- 若只有下装：配适当且不遮挡腰部、口袋、裤线的上衣与鞋。
- 若只有裙装：可配简单鞋履，避免改变裙装设计。
- 其余品类按视觉展示目标调整。辅服或配饰仅用于衬托，不能被误认为原主产品的一部分。

### 背景、机位和画质

- 背景与地面是**纯平白色** `#FFFFFF`，不允许灰、米色、奶白、渐变、无关道具、家具或场景。
- 使用柔和均匀的专业棚拍灯光；模特双脚下有轻微真实接触阴影，其他地方保持干净。面料细节、自然阴影、人体皮肤与材质必须写实。
- 优先**完整全身**，包括头、手、脚和产品全部细节。对小件服装可在不裁切主商品前提下优化构图。真实透视、留白和主体比例，不要时装插画/3D/CGI/人台感。

## 节点完整中文提示词写法

Agent 应以每件衣服**实际识别结果替换字段**，不能直接塞入通用占位模板：

> 以输入的【当前商品正反面参考图及真实商品图】作为最高权威，制作一张真正专业的高端服装电商模特棚拍照片。要展示的唯一主商品是【品类、具体颜色、面料表现、轮廓版型、长度、领型、袖型、口袋、钮扣、拉链、纹样、Logo、缝线、所有可见特征】，必须保持原样，绝不添加、删除或修改任何已知产品细节。若原商品无口袋，画面不得生成口袋或任何类似暗示。画面里只有**一位**适合该商品受众的真实模特【已确认的模特条件】。模特正面对镜头，前身服装清晰完整；站姿轻松有自信，重心微偏一侧，一腿自然放松，肩部和手臂稍有自然不对称但不扭转躯干；双手自然垂在产品关键区域以外，不插口袋、不叉腰、不交叉手臂、不遮挡主商品。表情自然克制、不微笑，人体比例真实，肤质有毛孔和细节。仅在原商品不是完整套装时搭配少量与【当前产品】协调而低调的辅服和鞋履；不得覆盖主产品的腰线、长度、设计细节。使用纯白背景与纯白地面 #FFFFFF，柔和专业棚拍光线，脚下轻微且可信的接触阴影。照片真实自然、面料质感清晰、手指和肢体正确、色彩忠实，适度自然颗粒，不出现 CGI、塑料皮肤或过度修图。优先全身构图，模特头、手、足、衣服都完整在画面内，留有适当白边。最终只输出**一张单人正面模特照**；不得出现拼贴、前后对比、第二个人物、额外视角、文字、标签、无关道具、品牌重设计。

## 批量生成注意

- 一张商品图片对应一条独立提示词、一位模特、一张正面上身图。不同商品不能交叉引用服装。
- 10 件商品生成 10 条**彼此独立**的提示词，原则上不需用“从上一个 LLM 输出提取 Prompt 6”等操作；如果是纯文本导出，按商品顺序以独占一行的 `*` 分隔。
- 不同商品可以根据目标风格共享模特摄影基调和背景，但要保持各件产品的具体差异。

## 验收

一人一图、正面、商品完整；服装结构保真，无乱加口袋或图案；模特姿态自然、不僵硬、不插袋；全身不裁切；纯白背景、脚下真实接触影；没有附加视图和拼图。
