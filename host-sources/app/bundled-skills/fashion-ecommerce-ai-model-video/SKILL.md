# 服装电商 · AI 模特动态展示

## 目标和适用范围

让用户从服装商品素材出发，形成可检查、可修改、可逐步执行的电商视觉链路：

**每件产品原图 → 纯白背景正反面商品参考图 → 单人模特正面上身图 → 单镜头自然转身展示视频。**

以服装（裙装、上衣、下装、外套、套装等）为主要支持范围。鞋包或配饰可根据实际展示方式调整模特和视频方案；不可硬套“穿着服装转身”动作。适合单件或批量任务，默认支持 1–10 件，超过 10 件按资源限制分批；**不要求用户凑齐 10 件**。每件产品始终保持独立身份，不将不同商品的颜色、版型、细节混用。

## 核心分工与执行约束

- 本 Skill 定义专业视觉方法、分阶段生成提示词、输入输出关系、质量和验收标准；Agent 自行使用当前环境确实存在的画布/图像/视频工具。**不依赖任何 AI OS 专属函数名，不自带执行脚本。**
- 用户明确说「在画布执行」「搭建工作流」「创建节点」时，**默认搭建待执行的真实节点并写入完整中文提示词**，不自动运行图像或视频生成。
- 用户说「直接生成」「批量跑图」「开始生成视频」时，按其授权范围调用可用模型，但必须遵守 AI OS 已有的付费确认、额度、权限及重试保护；不得绕过，也不得在失败后暗中重复付费。
- 用户只要思路、提示词或方案时，仅给出相应内容，不修改画布。
- 不得谎称已创建、连线、保存、生成或验证。缺少工具能力时说明哪一步受阻，保留已完成成果。
- **所有生成提示词默认中文**，以完整、可直接粘贴或写入生成节点的自然语言撰写；用户主动指定英文时才改用英文。

## 输入识别

每件商品至少需要一张能辨认服装主体的参考图，来源可以是**用户发送给 Agent 的附件**、当前画布上的图片节点，或已获授权的资产库素材。若聊天图片尚未成为画布可引用素材，先通过当前实际可用的导入工具建立唯一的引用；无导入能力时报告阻碍，不用虚构文件路径。

可选补充：服装名称与卖点、正面/背面/多角度参考图、目标模特的年龄段和风格、性别呈现、画幅、图片模型、视频模型、视频时长、输出尺寸以及是否立即运行。缺少这些信息时优先从可见素材保守推断，沿用已配置的合理模型选项，**不得凭空添加材质、口袋、图案、Logo、功能或商业声明**。未给定商品图时，不假装完成精确产品还原。

特别区分：

- **可确认信息**：参考图中真实可见的产品细节，必须忠实保持。
- **推断信息**：参考图中未显示的背部、内部构造或遮挡细节，只能保守合理推断；**绝不能宣称与实物完全一致**。如需真实商品准确性，应优先向用户索取背面参考图。
- **组合图片**：同一张参考图如有正反面多个视角，视为**同一件商品的不同视角**，不能被当作多个不同商品。

## 三段核心制作流程（每件产品）

### 第一段：纯白正反面商品参考

阅读并遵循 [正反面商品图规范](references/01-product-front-back.md)。分析商品图是否已有正面、背面或两面；生成或整理**一张**纯白 `#FFFFFF` 背景、左正面右背面、两件视图完整且相互分开的标准商品参考图，绝不添加模特或文字。已提供的视角严格保真；缺失的视角只能作保守推断，并在任务报告中注明推断状态，而不是在生成图片上添加注释。

若输入已经是合格的正反面白底图，可复用而不无意义地再生成；但不要擅自将明显不符合规范的图片标记为“已标准化”。

### 第二段：真实白底模特正面上身

阅读并遵循 [模特上身图规范](references/02-fashion-model-front.md)。以**当前商品的正反面参考**及原始可见商品细节为依据，为该产品形成**单张、单人、正对镜头**的专业服装电商照片。自然微不对称站姿、全身或确保商品完整的构图、纯白地面与背景、真实接触阴影；服装优先。只在单品缺少搭配时添加低调互补单品，不能遮盖或改变主商品。没有口袋不得凭空生成口袋，手不得插入口袋。

### 第三段：真实自然转身展示视频

阅读并遵循 [自然转身视频规范](references/03-natural-turn-video.md)。以第二段实际生成的模特图作**真实引用输入**，并尽可能结合第一段正反面参考（仅限模型/工具支持）生成单镜头、纯白摄影棚、固定机位的服装展示视频。模特**自己移动重心、脚步、髋部和身体完成自然转身**，呈现正面、侧面、背面再回到正面；不是转盘或整个身体机械自转。优先尝试回到起始站姿以形成循环，但首尾帧一致是**验收目标而非必然保证**。

若视频模型不能引用背面图或无法稳定还原未知背部细节，必须说明局限；不能写出“已经验证背部完全真实”这样的结论。

## 画布模式：真实节点和关系

调用前阅读 [画布执行与验证规则](references/04-canvas-execution.md)。

对每件商品建立一条**独立的三阶段分支**；默认最小结构为：

`商品原图（共享引用） → 正反面商品图生成 → 正面模特图生成 → 自然转身视频生成`

这是一条**逻辑链路**，执行时必须根据当前画布真实支持的输入端口和素材格式建立有效连接；不允许只画装饰性连线或凭文字声称已连接。

- 每一个图像/视频生成节点中都直接写入其阶段**完整的中文提示词**，而不是“见上游第 N 条提示词”“Extract Prompt 6”这类依赖前一段文本解析的占位。
- 每件商品原图只导入/复用一份；本件商品的多个节点复用同一原图资产标识。**不同商品不得错误引用同一张图。** 第二阶段引用本件正反面参考；第三阶段引用本件模特成品。
- 使用实际存在的工具创建节点、连线和保存。节点应有可读名称，例如 `01_商品A_正反面参考`、`02_商品A_模特上身`、`03_商品A_自然转身视频`。多件商品采用清晰的并行列/行布局，不重叠。
- 如果第二或第三阶段所需的上游结果**尚未生成**，允许先创建待运行节点并连接将来的输出端口（仅当画布真实支持），清楚标注“待生成”；不能给其伪造一张已生成图片。
- 重复执行同一请求时，检查用户明确指定的当前工作流和现有节点；只补齐缺失阶段，不得在未确认的情况下无限复制节点或重复运行生成。
- 用户已提供合格正反面图、模特图或视频时，可以复用相应成果并跳过已满足的阶段，避免浪费。

## 完整提示词生成规则

Agent 必须结合**当前实际商品参考**，按对应阶段的参考文档生成可直接执行的具体提示词，不可以将泛化模板原样塞给生图/生视频节点。每条提示词应写清：该商品可见颜色与版型、材质表现、特别结构与细节、正反面信息可信度、镜头/光线/背景、必须保留的细节、禁止出现的新增设计和异常行为。

十件商品可各有不同搭配与面孔，但每件商品的主产品必须独立且准确；不得把一套服装错装到另一人的视频中。默认不创建额外十个“提取 Prompt N”的 LLM 节点，除非当前工作流确有必要且用户要求固定流程。

如果用户要求**导出批量提示词文本**，按输入商品顺序，每件一条完整提示词；使用独占一行的 `*` 分隔，N 件对应 N 条提示词和 N-1 个分隔符。对于原示例的 10 件则为恰好 10 条和 9 个分隔符。这个文本分隔规则**不强制用于画布内部节点**，画布节点应该直接携带各自完整提示词。

## 完成条件与回复

搭建模式：逐件确认原图资产、三阶段节点及其完整中文提示词；核对真实连接关系、保存与刷新恢复，并说明哪些待实际生成。对话模式：输出所需提示词，不报称画布已创建。执行模式：按已获授权的阶段运行、核查结果；质量不达标可提供具体调整方案，未经允许不自动重复付费。

特别验收：白底为纯白而非灰渐变；正反面同一件产品、可见细节不改变；模特单人且正面；站姿、手部、衣服、阴影自然；视频中身体主导转身、机位固定、没有莫名口袋和设计漂移；若首尾不一致，要如实指出而非声称无缝循环已成功。

**不要把三阶段“节点已搭建”误说成“三段素材已生成”，也不要把生成成功误说成品质已通过检查。**
