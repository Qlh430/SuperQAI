# 服装电商 · AI 模特动态展示

**展示名称：** 服装电商 · AI 模特动态展示  
**标准 Skill ID：** `fashion-ecommerce-ai-model-video`  
**版本：** `1.0.0`  
**建议分类：** 电商设计 / 视频创作  
**用途：** 将服装商品图通过纯白正反面参考、AI 模特白底正面照、自然转身视频三阶段流程转化为可执行的画布创作链路。

## 用户输入

1. 一件或多件服装商品图（必须，有正反面更准确）；
2. 可选模特特征、风格、视频时长、图片比例和指定模型；
3. 可选选择「只搭建节点」或「执行生成」。

## Agent 默认行为

- 支持单件或批量，默认最多 10 件一起规划，超出可分批；
- 每件产品独立建立 `原图 → 正反面图 → 模特上身图 → 动态视频`；
- 各节点直接写入具体的**完整中文提示词**，使用真实有效的产品素材连接；
- **默认仅搭建待运行节点，不擅自运行付费图片/视频生成**；
- 已知服装结构要忠实，未知背面只能保守推断；无缝循环是检查目标，不保证每次成功。

## 文件组成

- `SKILL.md`：标准 Agent Skills 入口与执行规范；
- `references/01-product-front-back.md`：纯白正反面商品图；
- `references/02-fashion-model-front.md`：写实模特正面上身照；
- `references/03-natural-turn-video.md`：真人自然转身与循环视频；
- `references/04-canvas-execution.md`：画布节点、真实连接及验收。

本包不包含脚本、可执行文件、示例图片或视频。示例效果素材应由有权使用的人**在 AI OS Skill 展示资料中单独添加**，避免伪造或重复打包素材。
