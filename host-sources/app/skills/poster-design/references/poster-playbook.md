# 专业海报执行规范

## 一、先确定一个视觉任务

海报只能有一个首要任务：让用户记住产品、理解优惠、感受品牌、接收通知或产生祝福联想。所有元素都必须服务于这个任务。无法说明作用的信息、装饰和特效应删除。

## 二、建立信息层级

按以下顺序组织：

1. 第一眼：主体或主标题，占最强视觉权重。
2. 第二眼：一句辅助卖点、活动主题或传播主张。
3. 第三眼：时间、价格、行动入口等决策信息。
4. 最后：品牌署名、条款和次要说明。

同一层级使用一致的字体、颜色和间距。不要用多个高饱和色块、发光标题和夸张描边同时争夺注意力。

## 三、构图与视线

- 使用明确的焦点位置，常见为三分点、中心或对角动势。
- 让主体视线、产品朝向、运动方向或图形引导线指向主标题或行动入口。
- 留有足够负空间，避免元素贴边和互相遮挡。
- 促销海报的信息可以更密集，但必须形成清晰的阅读路径。
- 品牌与节日海报可以使用更强的留白和情绪表达，但不能牺牲主题识别。

## 四、色彩与对比

- 先确定主色、辅助色和强调色，再决定渐变、材质和光效。
- 用明度对比建立层级，不能只靠颜色数量制造热闹感。
- 红色、金色等强情绪颜色需要控制面积，并加入低饱和色、留白或深色来稳定画面。
- 文字与背景必须满足可读性。浅色文字放在复杂背景上时，增加暗部蒙版或独立色块。

## 五、中文字体与文字安全区

- 图片生成阶段只预留文字区域，不要求模型直接写长段中文。
- 主标题区、副标题区、价格区、日期区和品牌区应分别预留干净空间。
- 标题安全区要避开主体轮廓、产品 Logo、二维码和画面主要纹理。
- 竖版海报优先使用从上到下的阅读路径；横版海报优先使用左右分区和明确的主视觉中心。
- 需要准确文字时，由文字节点或后续排版完成，并检查断行、标点、数字和单位。

## 六、产品与品牌一致性

- 产品外观、结构、比例、颜色、材质和 Logo 位置不能变化。
- 没有真实产品素材时只能制作明确的无品牌占位方案，不能假装是真实产品。
- 品牌视觉元素必须来自用户提供的素材或公开资料；不确定时宁可留空。

## 七、生图提示词结构

提示词按以下顺序组成：

1. 海报类型和唯一传播目标。
2. 核心主体、动作、材质和参考图约束。
3. 画幅、机位、景别和构图位置。
4. 视觉主题、色彩、光线和环境。
5. 文字安全区和留白。
6. 禁止项，例如乱码、假 Logo、错误价格、额外人物、主体变形和元素过载。

## 八、交付前检查

- 3 秒内能否看出这是什么海报、给谁看？
- 第一眼和第二眼是否有明确主次？
- 产品是否保持一致，信息是否真实？
- 标题、价格、日期和二维码是否有安全位置？
- 颜色是否稳定，是否因为元素过多失去专业感？
- 是否符合投放渠道的尺寸、观看距离和缩略图识别要求？
