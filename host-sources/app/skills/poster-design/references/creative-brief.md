# 海报需求确认规范

## 目标

需求确认不是让用户填写问卷，而是找出会改变设计结果的关键条件。用户已经说清楚的，不重复询问；可以用专业判断安全补全的，不追问；会改变主体、传播目的、信息真实性或交付尺寸的，必须确认。

## 先判断海报类型

| 类型 | 核心目标 | 最重要的确认项 |
| --- | --- | --- |
| 产品海报 | 让用户看见并记住产品 | 产品是什么、真实素材、目标卖点、销售渠道 |
| 品牌海报 | 传递品牌价值与气质 | 品牌名、品牌主张、已有视觉规范、禁用表达 |
| 促销海报 | 在限定条件下促成行动 | 优惠机制、时间、价格、行动入口、合规限制 |
| 节日祝福 | 建立关系与传递祝福 | 送给谁、署名方、祝福文案、投放渠道 |
| 活动通知 | 让用户知道事件并参与 | 活动内容、时间地点、参与方式、报名入口 |
| 其他 | 按用户明确目标确认 | 传播目标、受众、主体、必显信息 |

“春节海报”只说明节庆主题，不代表已经知道用途。若用户没有说明，优先确认是产品、品牌、促销、祝福还是活动通知。

## 最低必要信息

按以下顺序补齐，最多问 5 个问题：

1. 海报类型和传播目标。
2. 核心主体，以及必须使用的图片或素材。
3. 投放渠道和画幅。
4. 必须出现的文字、品牌素材和合规限制。
5. 期望风格、情绪和明确禁忌。

受众、风格、构图和色彩如果用户没有要求，Agent 可以根据类型给出推荐值，不必全部追问。

## 问题编写规则

- 一次最多 5 题，单题优先给 2 到 6 个互斥选项。
- 问题只问结果相关项，不问“喜欢什么颜色”这类可以专业决定的问题。
- 对容易误解的主题，给出具体选项。例如春节海报可提供“产品传播、品牌祝福、促销活动、节日通知”。
- 推荐值必须说明专业理由，不能用“更好看”作为理由。
- 用户选择“按专业建议补全”后，不再重复询问同类问题。

## 不可推断内容

以下内容没有用户提供时不得虚构：品牌名和 Logo、产品参数、价格、折扣、活动日期、门店地址、电话号码、网址、二维码、认证、代言人与合作方。

## 完成标准

确认后应形成一张可直接指导制作的 brief，至少包含：

- 海报类型与一句话传播目标。
- 目标受众与投放渠道。
- 核心主体、素材来源和产品一致性要求。
- 画幅、信息层级和必须出现的文字。
- 视觉主题、色彩、构图方向、氛围和禁忌。
- 哪些内容由用户提供，哪些内容由 Agent 专业补全。
