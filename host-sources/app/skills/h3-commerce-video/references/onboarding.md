# 用户启动与资料收集

将安装后的首次使用变成一段能完成的对话。默认约30秒、9:16、轻快自然中文，交付A/B两段H3提示词。画面有两种形式：人物对镜讲解与商品镜头交替；纯商品分镜配同一旁白。按用户已表达的形式执行，未指定时采用人物讲解，在填写卡中允许改选。启动语对应资料收集与提示词制作；运行生成按用户另行提出的执行请求进行。用户已有的资料持续有效，后续每轮只处理剩余缺项。

## 1. 一句话启动

推荐启动语：**使用H3带货视频Skill，开始制作。**

只有启动语时，用简短中文说明默认效果，并给以下填写卡。商品品类从商品名或介绍识别；确实不能判断时再问。字段结构固定，允许用户把详情页原文整段粘贴，由Agent整理。

```text
商品名称、款式/规格：
画面形式：人物讲解 / 纯商品＋旁白（选填，默认人物讲解）
主要卖给谁，或用于什么场景：
商品介绍或卖点：（可直接粘贴详情介绍，保留其中的适用范围、规格/适配和成立条件）
最想突出哪一两点：（选填）
价格、优惠、购买引导：（选填）
```

此轮完成条件：用户知道要提供什么文字、随后会收到对应商品的图片清单。价格、优惠和主推偏好可以留空。用户说“不露脸”“只拍产品”“商品分镜加旁白”时直接采用纯商品旁白，不再索要模特或确认同一选择；单纯缺少模特照片时仍按已选形式处理。清单可一次填写，也可按用户现有内容分次补齐。

如果用户一开始已经发了介绍或图片，从它们继续处理，不再发空白表让用户重填。

## 2. 按本款商品给出图片清单

读取[素材协议](assets.md)，从介绍中选出本次值得讲的一两项购买理由，简短归纳已收到的资料，给出与之匹配的四图清单。此时优先完成素材收集，完整口播和分镜在资料齐备后统一交付；用户明确先要草案时再提前写稿。清单要让用户能实际找图，逐张说明“这张拍什么、需要看清哪里”。下面的图号是最终交给H3的角色；用户原图可用原文件名，Agent负责映射。

|最终图位|给用户的要求|
|---|---|
|图1 开场场景|人物讲解：一位成年模特与商品同场，脸嘴及所需手部/身体清楚。纯商品旁白：同款商品的场景或整体展示图，商品主体与摆放关系清楚|
|图2 完整主图|本次单一款式的完整商品，正面或三分之四角度，颜色与关键结构清楚|
|图3 补充展示|按本次品类，从素材协议允许的角度、内容物或使用状态中选择一种，说明本次具体需要哪种|
|图4 核心细节|选本次主卖点对应的部位、质地或功能细节，说明需要看清什么|

例如服装可要求背面与领袖细节；食品可要求内容物与切面；美妆日化可要求本品质地与对应使用状态；小家电可要求结构或功能完成状态。清单随本次理由选择，各图仍须同款。人物形式按计划景别要求身体范围；纯商品形式可用服装平铺/悬挂、鞋包整体与细节等画面。旁白声音由提示词描述，用户无需另交旁白人像。

向用户说明：商品图保持同一颜色、款式与结构，每张为独立PNG/JPG；包含多款拼贴、只有大字海报或被遮住关键部位的图要换成具体合格图。口味、功效、材质与性能由商品资料提供，照片只承担它能看见的内容。

此轮完成条件：每个缺失图位都有具体内容要求，用户不必猜“多角度”和“细节”指什么。用户已发的合格图直接占位。

## 3. 区分原始照片与已准备的场景图

先按画面形式处理。纯商品旁白只准备同款商品场景与展示图；需要简单手部操作时核对参考和动作前提，手部是画面动作来源，旁白是独立声音来源。人物讲解可以先给独立模特照和商品照片；模特穿着本款、持握本款或同场操作的图1，是进入H3前的素材准备结果。

- 已有合格上身/持物图时直接使用。
- 人物与商品分离时，列出需要准备的场景图；获得生图授权且宿主有相应工具时完成准备，再对照商品原图检查款式与结构。已有授权继续有效。
- 宿主没有生图工具时，交付该张图的生图提示词与检查点，告诉用户通过配套生图工具准备后再上传；当前状态为“场景图待准备”。
- 未知的背面、内部结构或真实质地仍需同款资料，合成图不能补成真实结构证据。只缺人物图时保持已选的模特讲话方案并补图；用户明确选择纯商品画外音后再切换模式。

此轮完成条件：明确哪些是用户原图、哪些是待准备图，最终四图具有可核对的来源和角色。独立头像加商品主图不能直接视为四图已经齐备。

## 4. 每次收到新资料或图片都核验当前缺项

实际看图，将收到的文件映射到四个角色，并与文字款式、颜色、结构核对。简短回报：已收到哪些、可用在哪个图位、还缺什么。四图尚未齐备时，直接给具体补图项并等待用户提交；用户询问如何找图、拍图或要求生图时，再展开准备方式。补图选项须能实际补足缺失角色；同一角度的重复照片、复制或裁切不能增加尚未展示的部位和结构，也不能将两个已有角色凑成四个。只有文件存在或分辨率够高，不等于素材已经合格。

文字归档为商品身份、目标需求/场景、已支持特点、选购条件、使用步骤、可选引导。每个入选特点同时保留“具体是什么、对本次需求有什么用、来自哪段资料或哪个可见部位、成立需要什么条件”。有几条有效事实就处理几条，优先选择最相关的一两条。已有条件直接使用；只缺影响所选购买理由的信息时再追问。操作与拍摄要求归入制作说明，按[口播写作规则](selling-copy.md)完成取舍。

缺少影响购买理由的事实时，只问能增加选购价值的具体问题。有效内容只能支撑短稿时说明估时与最少补充项。图片缺项、文字缺项、同款冲突分别记录；四图和资料齐备后按[正式制作](production.md)继续。

资料与图片验收由Agent执行，满足条件直接推进；只有真实缺项或冲突才需要用户补充。用户没有要求分阶段审批时，不增加“确认卖点/确认分镜后才出提示词”的往返。

## 5. 输出可用提示词

完成口播取舍、连续正文和内部审稿，再按正文安排对应商品镜头。逐项核对购买理由中的体验评价与本次资料，规格组合带来的选择或便利按原义表达，体感和效果评价保留实际来源。随后读取正式制作所链接的提示词规则与工作流契约，按协议输出两段完整提示词、分镜及上传表；有文件能力时保存配套产物并运行文本校验，聊天中明确给出A/B提示词或文件入口。技术参数和节点说明放在最终使用说明。

对用户先展示能使用的结果：本次采用的四图、完整口播、对应分镜、A/B提示词及上传位置。事实取舍、未确认信息和检查结果放在交付说明。区分“提示词已完成”和“视频已生成”；需要补图或资料时给可支持部分与准确待办，保留当前进度。
