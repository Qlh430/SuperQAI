# 产品摄影方法

本文件提供可组合的拍摄判断方法，不是固定场景模板。先辨认产品几何形态、表面反射、透明度、颜色、标记和使用情境，再决定灯光、机位与布景。

## 从商品与用途确定摄影方向

1. 提取可见外形、比例、颜色、透明度、反射、关键部件，以及用户的用途、风格、受众、画幅和创意要求。分别记录事实、推断与未知。
2. 写清一个可见的产品卖点、一种面向受众的视觉感受，以及用来建立记忆点的空间或光影关系。透明商品可以表现背光下的薄边，印字包装可以让投影引向标签。概念决定道具、材质、构图和光源的取舍。
3. 每件商品提取 3–5 个可见特征，再为这些特征设计 3–5 个概念。分别确定主体位置和占比、实际接触面、前中远景、机位、光源方向与硬度、反射和配色。用场景、构图、布光比较差异，至少两项有实质变化，再选择能实现各案的摄影方法。用户指定方向时，在该范围内比较不同拍法。
4. 将实物事实、观察证据与各案拍法分别写入 `known_context`。推荐理由从当前实物出发，例如某案让标识、展开部件和暗背景边界同时可读。各案先核对原有开合、承托、关键结构、标识和透视。投放载体不进入摄影视觉描述。画面留白描述其位置、大小与亮度，标题和图标由后期排版。

选案时从「观看路径、光影形状、材质关系、色彩层次」中找两项能服务主题的证据。读取 `references/visual-method-catalog.md`，为每案匹配一至两项作品方法。迁移前问清楚：它的亮暗怎样组织空间，何种边缘、焦点或反射让主体成为主角，换成当前商品时应保留哪种关系。REF 编号和借鉴说明放在确认卡。最终摄影执行写清新的场景和拍法。

按用途迁移构图关系。户外广告可用低位主体、连续地形和天空留白建立尺度。办公情境可用真实工作面承托，以产品长边呼应建筑线条，用少量道具说明用途。几何主视觉可借背景色块与投影呼应商品轮廓，兼顾标识与空间纵深。

## 构图选择与空间安排

| 手法 | 何时使用 | 视觉结果与代价 |
| --- | --- | --- |
| 三分与偏心 | 主体有侧向延伸，需给标题或动势留空间 | 偏移主体后用阴影、反射或低对比背景平衡，避免留白成为另一个视觉中心 |
| 中心与对称 | 正标识别、轮廓规整或电商首图 | 识别直观。用机位、比例、受光面和背景层次提供变化，避免平面贴图感 |
| 对角线 | 长形商品、延伸部件或错位组合 | 引导视线深入。可用取景边界、台面接缝或投影形成斜势，商品可保留原姿态 |
| 三角形 | 三件或多件商品、主品和两项附件 | 主次稳定。用前后距离和高低关系引导，保持实际比例与部件连接 |
| 框架式 | 建筑、窗边或编辑主视觉 | 让低对比前景局部入画，借遮挡提示距离。框景远离商品关键边缘和标识 |
| 留白与非对称 | 海报、横幅及带文字版位 | 留白给指定版位。平衡亮度与分布，在目标裁切内保留完整主体 |
| 前中后景分层 | 需要表现环境和商品体量 | 主体在可辨承托面。用前景入口、实体边界、材质尺度、背景间距与明暗形成纵深 |

空间从摆放面开始，再决定观者先看到什么、背景退到哪里、主光从哪个开口进入。窗边以台面和退后墙体建立空间，极简室内借墙角或平面转折，石材空间用体量与尺度，植物生态用距离和虚实，户外用地平线与日照。极简棚景可用真实墙面、反射面或画外遮挡。抽象自然空间同样需要可解释的表面、光源和接触关系。为产品选一种主要空间线索，其他元素保持从属。

## 光线选择与物理关系

| 光线 | 适用与可见结果 |
| --- | --- |
| 自然窗光 | 窗面越大、商品越靠近，阴影过渡越软。有阳光直入时会投出方向明确的窗影，透帘或阴天时边缘更软 |
| 侧光与掠射光 | 沿侧面掠过哑光纹理或石面，强化表面凹凸。适度补亮暗侧，保留标签和边缘 |
| 逆光与侧逆光 | 为透明玻璃、液体和半透明塑料保留边缘透射。在相机侧用中性反射补亮正标与关键结构 |
| 漫射与阴天环境光 | 大范围亮面压低小亮斑，利于光洁包装和低反差画面。可保留明暗方向，用侧墙或负补光塑造轮廓 |
| 直射阳光与树叶过滤光 | 短距离产生清楚投影，枝叶间隙能组织节奏。将高对比光斑留给台面或背景，避免打断商品细节 |
| 清晨与傍晚低角度光 | 低位长影适合户外层次与季节情绪。用天空光或中性反射控制商品色偏 |
| 环境反射与接触阴影 | 反射应对应画外窗、墙或实际材料。接触处阴影紧而深，离开接触点后渐软；阴影和高光应服从同一光源方向 |

## 光线与材质

- 透明玻璃、透明液体、晶体：用大面积柔光源形成可控边缘高光，以侧后方或背光揭示轮廓和透光；用黑白反光板塑造边缘，检查标签和液体边界是否仍可读。深色卡纸会改变玻璃边缘观感，只有与产品和品牌色调相符时才采用。
- 高反射金属、镀层或镜面塑料：优先让产品反射有形状的大面积柔光面，而不是直接点光源；用黑旗和白卡分离明暗面，观察高光是否遮没结构。控制周围环境的杂色反射。
- 哑光塑料、陶瓷、纸面、织物：使用掠射侧光或柔和侧前光揭示表面纹理，同时保留暗部细节；避免把细纹磨成塑料感，也避免过度锐化造成虚假的材质。
- 深色产品：背景亮度和边缘光需与轮廓分离；不要以提亮为由改变产品本身的颜色。
- 浅色产品：背景保持色调和亮度分离，加入真实接触阴影；避免纯白背景让产品边界消失。
- 磨砂玻璃、亚克力和半透明塑料：保留材料不同的透明程度与表面纹理。用明暗背景分区和受控侧逆光读出厚度，同时保证正面可读。
- 环境材料：石灰岩、砂岩与粗岩表现干燥颗粒，灰泥或微水泥提供细哑的中尺度纹理，木材用纹路引导方向，纸和织物适合表现触感。大理石纹理较强，用局部或压低对比。水、苔藓、枝叶、花、沙土和露珠只有服务于层次、季节或用途时才采用。易反光环境会改变产品色与反射形状。

## 形状、机位与比例

- 机位应服务产品形状：正面适用于标签和正面结构识别，三分之四角适用于展示体积和侧面深度，俯拍适用于平面包装、套装或具有明确布局的组合物。使用前检查是否会隐藏关键结构。
- 根据画面的观看路径决定商品的姿态、方向、位置和占比。对角构图可以由商品整体斜放、场景线条或投影建立；低机位适合强调体积和前后尺度，俯拍适合强调形状、排列与留白。选择能交代商品的可见角度。涉及关键未见面时补充多角度原图或 3D 模型。
- 单张白底原图的接触和受力通常不可见。场景中的接触面、阴影方向和反射由所选拍法重新设计。用实际可承托的连续表面与自然阴影解释重力，保留前中远景的光源一致性。
- 35mm 等效视角适合兼顾环境，近距离会放大近端结构。50mm 容易在商品与环境之间取平衡。85mm 适合保持拍摄距离并简化背景。微距适用于真实可见的材料或细节，以焦平面覆盖关键结构。透视主要由相机距离决定。低机位增加体量，高机位揭示平面布局，平视强调正面识别。
- 在其他条件近似时，f/1.4、f/2 形成浅景深，适合局部细节。f/2.8、f/4 可分离背景，需检查展开部件或后排商品是否清晰。f/5.6 至 f/8 适合兼顾同一商品的多个结构，f/11 可保留更多环境细节。实际效果取决于距离、焦距与画幅。先写「镜头、铰链与展开环同样清晰，远墙柔化」等可见结果，再决定是否写参数。
- 少量辅助道具可解释尺度、用途、触感，也可提供颜色呼应、形状对照或前后景层次。明确每件道具的画面作用，保持产品的视觉主次、真实承托和使用逻辑，避免遮挡关键标识及部件。
- 留白按投放版位和裁切安全区决定；没有版位信息时，采用适度、可裁切的周边空间，并把它标注为方案建议。

## 背景、色彩与层次

- 背景需在色相、明度或质感中至少一个维度与产品分离，同时支持品牌气质和用途。不要默认把所有商品放进植物、木纹或米色场景。
- 自然元素和材质背景可用于色彩、形状、光影或氛围设计，根据产品气质选择，控制数量、尺度与景深。装饰关系须与产品属性声明分开，植物、石材或水景本身不能证明产品成分、产地、环保或防水性能。
- 保留产品原始色彩关系。环境反射色、白平衡和后期调色不能改变产品的真实颜色或商标。
- 同类色适合统一品牌气质，用明度区分主体。邻近色能在自然色系中保持层次。互补色和冷暖对比适合突出局部，背景色通常降饱和以控制反射。青绿可搭暖灰米色或较深的植物绿，银色可搭中性灰或深炭色，棕色可与较浅木材或砂岩对比。白色包装以明度差和侧边影分离。配色可明快或深沉，按商品原色、投放用途和用户要求选择。
- 透明和反光产品需要同时检查高光形状、背景反射与边缘分离；纹理产品需要检查纹理方向、细节清晰度与阴影层次。

## 七种可组合的文字预设

| 预设 | 适用和视觉目标 | 拍摄设计 | 可调整 |
| --- | --- | --- | --- |
| A 自然窗光静物 | 标识、透明边缘或表面形状需与环境分离 | 先观察开口方向、窗面尺寸与商品距离。直射日光可沿空间产生清楚投影，漫射天光可控制镜面亮斑。背景和承托依据商品色与尺度选材，通过明度、反射和物距区别前后 | 窗方位、直射或漫射、背景距离、受光面、留白方位 |
| B 天然材质对比 | 金属、玻璃、塑料、电子品和精品包装。用纹理尺度显示精密质感 | 一处粗面承托，侧光揭示纹理，大片柔反射沿金属面连贯延伸。控制色反射，以中性石灰色或与商品协调的自然色。中长焦减少比例夸张 | 石材粗度、主光掠射角、高光宽度、影长、关键结构的清晰范围 |
| C 自然生态清透 | 透明壳、护肤、户外小物。边缘透光、环境有远近 | 侧逆光从实际开口进入，低对比叶影或退远植物提供背景层次，前侧中性补光撑住标识。配色跟随产品，50–85mm 等效视角，焦点覆盖商品 | 植被密度、反射色、透光区域、背景远近。水、苔藓按用途选用 |
| D 极简商业静物 | 品牌主视觉、详情页、电商图。产品易识别、可配版 | 居中或偏置呼应版位，用少量墙面转折、细哑纸、灰泥或石面建立纵深。柔和侧光形成清楚边界，平视或中焦，景深覆盖正标和关键边 | 主体占比、画幅、留白侧、背景亮度、阴影密度 |
| E 户外自然摄影 | 有户外用途或希望强调自然尺度的商品。空间开阔、光影可信 | 用环境面真实承托，远处地形或天空提供层次。选直射、阴天或低角度阳光，天空回光和投影同向。35–50mm 等效视角交代环境 | 地平线、时段、机位高度、景深、日照硬度与真实使用情境 |
| F 艺术编辑摄影 | 品牌专题、社媒主视觉。画面有记忆点，主体仍清楚 | 以非对称、遮挡或斜线导向安排主体，允许较强画外投影或材质反差。背景亮区避开关键结构，按标签和部件选择景深 | 框景距离、对比、视角、留白、前景遮挡比例 |
| G 季节性自然摄影 | 季节活动和品牌叙事。借实际物候与光温表达时节 | 春用轻透绿与散射光，夏可用较高日照与清透配色，秋用低位暖光与干燥纹理，冬用低角度中性冷光与安静色面。先确定商品的位置与接触，景深保留必要季节线索 | 季节色、自然元素数量、光照时段、空间层次、传播版位 |

主预设解决最重要的摄影问题。辅预设只引入一个兼容机制，例如 A 的窗光、B 的材质尺度与 D 的版位留白可共用一块承托面和一个主光来源。E 的烈日和 A 的漫射窗光属于不同布光，只有交代遮挡或反射之后才能同时使用。季节、道具和参数均从用户用途中推导。

### 如何选主预设与辅助技法

先明确交付需要观众读到什么。主图优先品名、轮廓与结构，品牌海报可扩大环境比例和留白，组合图优先主次顺序和实际件数。按商品作判断：

- 轮廓薄或带透明边缘时，先解决边缘清晰与原色，选 A、C 或 D，再从透射、背景分离、纹理尺度中挑选必要技法。对装有配件的商品，焦平面要覆盖原有连接和主体。
- 镜亮或拉丝表面需要连续反射时，B 适合以一块自然亮面画出高光，D 适合正标清楚的资产。背景过亮会吃掉银色边缘，可加入一面稍暗的反射区域。
- 白包装、小字和正面几何优先 D。用户希望季节叙事时才转由 G 主导，背景以明度差保持识别，季节以光色和一处真实材质表达。
- 产品在环境中的真实使用是卖点时选 E 或 C。只需要视觉氛围时避免引入夸大的承托、用水或户外使用暗示。强构图、遮挡或局部对比有明确版位价值时再选 F。
- 先选一个主预设，辅技法最多两种，单独交代它们各自解决的摄影问题。简单需求直接给出推荐方案。改稿先复用可见商品事实，再更改用户指定的环境、光线或版位。

### 可跨预设组合的七种技法

以下技法描述可执行的摄影关系。布局、支持面与光位可以迁移，具体道具和商品随任务重新判断。

**不规则暗框与暖逆光 · F 或 B。** 适合轮廓鲜明的透明香氛、实体边缘明确的珠宝或金属件。用暗前景形成有开口的框，主体低位接触中景连续面，远处暖亮区留出可读轮廓；侧后有方向的光透过薄料，前侧以中性回光保留正标。可用同色系暖石、木、纸形成远近的纹理差。中焦轻低机位保持比例，暗前缘虚而主体全清。适合品牌海报，详情图避免遮挡和戏剧化暖偏色。可写「左上不规则暗前景止于商品外侧，右后亮面把透光边和实体边缘分开，底部留真实接触影」。

**自然倒影与反射空间 · C、E 或 F。** 适合玻璃容器、轮廓简洁的包装和小型金属件。让商品落在可承重中景面，连续低位反射面从接触点向前延伸；镜面反射清晰，微波纹减弱倒影细节，均应沿同一物体轴向与观察方向。低机位可见较长反射，中焦保标签清晰，背景退远以同色系中性的低对比过渡。亮边和倒影来自同一侧光，暗面用弱回光打开。产品介质不适用水时改用实面，避免双主体一样亮、镜像文字变成第二份包装、反射被错误理解为浸水。可写「保留主体底缘，浅反射紧接落点，越远越淡，焦点留在正标」。

**暗调轮廓与局部高光 · F，或作为 B、C 的辅技法。** 适合深色玻璃、绿或棕色包装、哑金属。用同色暗背景衬局部明度带，侧逆光描一段产品外缘，以窗墙窄反射分离深盖和深背景，正面用弱中性回光保持标签。叶、枝或帘边可在画面边缘作为曲线引导，虚化让低反差前景与清楚主体分开。50–85mm 等效的自然视角便于控制暗背景与比例。适合氛围广告，在线首图须保证结构读得出。可写「深橄榄的暗背景保留一处较亮远面，左侧光只分开瓶肩与瓶盖，正标由低强度回光照亮」。

**透明材质与光学层次 · A、B、C 或 D。** 适合玻璃、透明液体、半透明塑料和磨砂表面。先确认透过产品能看到哪些亮暗边界；将亮背景与较暗侧面安在主体两侧，以侧后大光面显示厚度、透射与宽窄变化，正面回光保护文字。背景先退远，再按透明度调节亮度，避免整块泛白、不透明化、反射遮没小字和假造内部结构。机位保留同侧可见面，景深覆盖折射边和正标。可写「较亮远墙透过薄缘，暗侧保留轮廓，盖面仅有一条连续受控反射，可见液面和标签清楚」。

**实体墙转折与窗光投影 · A，或作为 D、F 的辅技法。** 适合包装、精细数码、瓶罐和生活用品。先摆主体与中景承托面，再让墙体后退、转折，或用画外窗框投影编码景深。主光由可解释的窗开口侧入，近处接触影紧实，较远的投影随距离弱化。浅灰泥、织物或纸面维持低干扰层次，环境色随原品，留白服务实际版位。50–85mm 等效近自然透视，机位以标签和连接结构可见为准。促销首图可收敛投影，品牌图可稍强化空间；禁止把建筑开口描述成发光描边。可写「连续台面上有清楚落点，后退的墙面转角承接一段画外窗投影，阴影在远处渐软」。

**纹理尺度对照 · B，亦可辅助 A 或 D。** 适合拉丝金属、釉面、磨砂塑料、玻璃和印有小字的包装。环境选择颗粒或纹路略粗的石、木、灰泥、纸或布，主体保持更精细清楚。用掠射光凸显环境颗粒，以大面积反光面的明暗交界画出商品受光形状，两者保持一个主光方向。浅背景或暗背景以轮廓分离为准，机位在已见面，景深留出材质信息同时降低远处纹理对比。适用于材质卖点图及详情；粗纹过密、反射染色或接触看似悬空时，应简化背景或换承托面。可写「细而连续的高光沿拉丝边缘延伸，低反差粗纹在远处柔化，商品底缘落于未中断的台面」。

**生态与季节的前中远层次 · C、E 或 G。** 适合有真实情境关联的护肤、户外商品、季节活动或透明容器。近前从边缘用叶影、斜木纹或低反差布面引导，中景在可靠表面落位，远处用雾、地平线、植物或开口的明度变化分隔。光源可用阴天宽光、单一方向日光或林隙侧逆光，季节用实际光温与一处相关色彩提示。保证产品原色，按包装细节选择中焦或视野更宽的环境角度，主体清楚、前远景分别适度柔化。视觉元素不得暗示未经证实的成分、防水或承重。可写「近处只有低对比柔化的叶缘，主体在中景干燥面有短接触影，远处灰绿植物与侧后天光拉开距离」。

## 质量核验

先检查策划能否产生新的商业画面，再列出实际出图后可观察的验收条件。

- 对照原图逐项说明场景、构图/机位、光线/色彩的变化及其理由。通常至少两个维度有实质设计，具体变化服务产品卖点和传播用途。用户明确保留原拍法时按其要求执行。
- 区分产品结构与摄影选择。检查是否误把原背景、居中位置、拍摄朝向或输入画幅列为产品硬约束，并据用途重新决定。灰桌面、无道具、方形构图都需要本产品的选择依据。
- 比较方案能否突出真实商品特征，检查构图、反射、接触和空间是否能同时成立。确认当前需求的画幅安全边和主体清晰范围。
- 每案提示词按「产品依据」「艺术指导」「构图与空间」「光色与镜头」组织。商品原图一句引用。画面段写清主题、观看路径、近中远层次、光源到影子的关系，以及色彩和焦点如何把注意力引回商品。可以选择不同姿态、机位与尺度。光圈、曝光或快门只有能说明焦点、反差或动作效果时才写。

出图后按确认的方案逐项核验，未实际生成时将其列为待验收。

1. 产品轮廓、结构、附件和可见标识与参考素材一致。
2. 产品颜色、材质观感、表面纹理没有被场景或色偏改写。
3. 关键部件和可见标识有正确的位置关系，没有新增接口、功能、配件或伪造品牌。细小文字、复杂键位和精密纹样需要人工比对，不能承诺生成模型逐字逐键还原。模糊文字或隐藏结构保留未知，影响交付时补充清晰参考。
4. 受光面、阴影和接触关系符合所提方案，没有悬浮、穿插或不合理反射。
5. 背景、道具和留白支持用途，不抢主体，也未制造未经用户确认的产品功效或来源声明。
6. 输出画幅与真实模型能力相容；若能力未确认，明确标记待选择而不伪造配置。
7. 场景层次、主体摆放、光影和色彩符合确认方案的创意变化，具有清晰的商业视觉重点。如果实际结果仍接近原照片的小幅重绘，应明确指出未达到创意目标，保留原方案供用户调整后重新确认。

## 来源与适用边界
