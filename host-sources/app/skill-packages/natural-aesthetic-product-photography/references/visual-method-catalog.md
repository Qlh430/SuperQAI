# 摄影作品方法索引

每条源自本地图片的逐图视觉观察，REF ID 用于回到原件。根据每案的构图、光影、配色、材质和空间条件匹配条目，记录 1–2 项具体迁移。图片文件的来源或授权未核定时，仅提供摄影方法文字。

### REF-002
艺术静物；斜线；侧光；绿、暖；木、玻璃、纸、水。湿润香氛特写可照亮一条玻璃边和少量标签水珠，控制水滴位置，让小字仍能读出。

### REF-007
艺术静物；居中、偏左；方向光；白；木、水、沙；沙丘。木质调香水可用低机位和横卧枯木固定瓶底，利用浅色地平线勾出黑盖与肩线。

### REF-014
极简、艺术静物；绿、灰、黄、高反差；石、玻璃、金属；影棚、岩。枝条构成活动对角，瓶口保持竖直稳定。从玻璃底部保留透光，暗顶也能读出主体；文字较小，宜取构图和布光。

### REF-019
艺术静物、广告；柔光；紫；木。倾斜摆位可先明确两个受力点，再用雾化花卉增加距离感。小字较多的产品可缩小倾角以便阅读。

### REF-021
生活方式、广告；居中；绿、蓝；玻璃；虚化。低机位仰拍可借天空开口显示半透明瓶色，适合情绪主视觉。做电商主图时需单独加强浅色标签反差。

### REF-023
艺术静物、广告；蓝、灰、冷；水。冷色夜景可用边光与可辨轮廓展示包装结构，通过瓶底波纹连接实物和倒影。小体量品牌字需局部提亮。

### REF-025
艺术静物、广告；框景；侧逆光、逆光、条形高光；灰、琥珀、赭、暖；石、玻璃、金属、纸；影棚、岩；框景。用前景框景隔离强光，让下半瓶仍有透射深度。布景有透光褶纹，更适合模拟岩口的纸材方法；细标签同底色易读性下降。

### REF-027
广告；侧光；绿；木；墙、窗。套组可用高低错落区分瓶型，以同一台面保持归属感。让阴影和瓶壁高光避开小字，提高浅绿标签可读性。

### REF-035
商业静物；留白；窗光、焦散；绿、白、暖、高反差；石、玻璃、织物；室内、影棚、窗。用帘幕弧边、墙上光带和矩形石台形成三种边缘尺度。瓶底焦散提示材质。产品比例小，不能替代商品详情图。

### REF-039
生活方式、组品；偏心、对角、前景；窗光、反射；绿、琥珀、暖；石、玻璃、金属、纸；室内、窗、台面；反射。瓶身偏前保留正标，纸盒向后错位且顶面可见；依托盘并排取得落地关系。原图还带额外滴管和油滴，不能把它当目标产品默认配件。

### REF-053
商业静物、极简；绿、灰、白；石、金属；影棚。柔和的瓶体亮度过渡与清晰的石面投影并存；用灰阶而非强色差分开白瓶和石背景。瓶底细字较弱，适合造型研究。

### REF-059
商业静物、生活方式、极简；柔光；绿；木、玻璃。保留枝轴与瓶底可见的接点，使用淡色净背景衬出清透液体，适合轻量单品海报。

### REF-069
商业静物、生活方式、极简；逆光；白、暖；石、木、植物；桌。桌板纹理引向平石，控制蕨叶与花枝低于标面。可用来表达草本配方或日常使用情境。

### REF-074
商业静物；柔光；青绿、绿、蓝、灰；木、玻璃、金属、水；水面。让左上枯枝和下方倒影形成连续方向，白标签在蓝水上清楚。原图倒影内文字已变形，迁移只取空间分层，不照搬镜像细节。

### REF-076
广告；留白；柔光；绿、灰、白、黑；石、水、苔藓；水面、雾林、草、岩。借背景雾提升阴影侧轮廓，保留近景湿石纹理。原图接触点小，必须重建承托并避免为不防水产品添加湿水叙事。

### REF-079
广告；框景；侧逆光、逆光；绿、蓝、灰、白；石、玻璃、纸、水；雾林、岩；框景。雾化远景提高局部亮度，边缘轮廓明确；标签保留暖白。顶部俄文是独立排版，迁移时避开原字、品牌与湿润功效联想。

### REF-082
艺术静物、广告；偏右；白；石、水。用叠石抬高香水，低位茶具与可见茶叶交代香调，花茎提供高度呼应。香调道具围在侧下方，方瓶标签单独朝前。

### REF-096
商业静物、广告；留白；逆光、反射；白、暖；玻璃；岩、岩洞；反射。用亮背景通过瓶体、两侧深暗竖边界共同显出厚度，岩口框住主体并保留右空。品牌标识原样仅属于参考图中的该商品。

### REF-097
广告；前景；青绿、绿、灰、白；石、玻璃；岩；光斑。落在瓶底石台的轻亮斑与背景浅区形成呼应，靠近瓶右侧的暗岩让透光边缘清楚。文字清晰处可作观看层次，成分不能从道具类推。

### REF-108
商业静物、生活方式、极简；留白；侧光；绿、灰、白、琥珀；石、苔藓、植物；室内、影棚。用一根高花梗与喷头形成双竖线，宽高光解释圆柱曲率；石台接触阴影完整，避免用大花压住说明文字。

### REF-126
商业静物、香氛、广告；对角；侧光、透光；黄、暖；木；影棚。由焦内花枝围出商品空间，前景黄花散焦形成边界且不遮标签；瓶底与枝条接触区域需按新商品重量重新布置。
