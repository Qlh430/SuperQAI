# 图片转视频

## 前置条件

必须选择一个包含有效图片的画布节点。默认输出 `16:9`、8 秒；若用户明确指定比例或时长，则在支持范围内采用用户参数。不要为静态图片臆造复杂剧情、对白或未提供的人物身份。

## 工作流程

1. 识别画面主体、景别、光线和最安全的运动方式，优先使用轻微推拉、横移、环绕或环境动态。
2. 创建 MiniMax H3 视频节点，提示词包含主体动作、镜头运动、环境动态、速度、稳定性和禁止变形约束。
3. 将选中图片节点连接到视频节点，并把视频节点排列在参考图右侧。
4. 获得付费确认后执行视频节点。
5. 根据工具返回的真实任务状态报告结果；提交失败或生成失败时停止并保留节点。

## 质量规则

- 保持主体身份、服装、产品结构和场景连续性，避免突然出现新物体。
- 镜头运动与原图透视相符，限制大幅肢体运动和快速旋转造成的变形。
- 不自动重复执行失败的视频任务。
