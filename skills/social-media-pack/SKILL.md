# 社媒多尺寸

## 前置条件

必须选择一个主视觉图片节点。适配过程中保持主体、品牌颜色和核心构图关系，不凭空增加营销信息。用户未指定平台时生成 `1:1`、`4:5` 和 `16:9` 三种通用比例。

## 工作流程

1. 基于同一个选中节点创建三个图片编辑节点，分别设置 `1:1`、`4:5` 和 `16:9`。
2. 每个提示词说明安全区和构图调整方式：方形居中、竖版强化纵向层级、横版保留两侧延展空间。
3. 将主视觉节点连接到三个适配节点。
4. 创建“社媒多尺寸”图集，将三个结果节点连接到图集，并按行排列。
5. 获得付费确认后依次执行三个节点。
6. 汇报每个比例的真实执行状态；任何失败任务都等待用户决定是否重试。

## 质量规则

- 只做构图适配和合理补景，不改变产品、人脸、Logo 和核心视觉身份。
- 重要主体不得被裁切，边缘补景应延续原图光线与透视。
- 不在图片中生成未经确认的长文案。
