# 电商套图

## 前置条件

必须有且只需使用一个已选中的真实产品图片节点作为主要参考。若没有选中图片，停止并请用户先选择产品图。不要臆造品牌、型号、材质、认证、价格或功效。

## 工作流程

1. 从画布上下文读取选中产品节点 ID，提取产品颜色、轮廓、材质和不可改变的识别特征。
2. 创建三张相互独立的图片节点，并将同一个产品节点连接到每个节点：
   - 主图：`1:1`，主体清晰、背景简洁、无未经提供的文字和标识。
   - 卖点图：`4:5`，用构图和环境表现一个真实可见卖点，不编造数据。
   - 场景图：`4:5`，放入合理使用场景，同时锁定产品外观和颜色。
3. 创建标题为“电商套图”的图集节点，将三张生成节点连接到图集。
4. 先排列节点，使产品参考图位于左侧，三张生成节点位于中间，图集位于右侧。
5. 依次执行三张图片节点。执行是付费操作，必须等待界面确认，不要自行重复失败任务。
6. 根据工具返回的真实状态报告成功和失败节点；只有三张均成功时才称为套图完成。

## 质量规则

- 产品主体只能来自选中的参考图，三张图保持颜色、结构、Logo 位置和材质一致。
- 每张图只有一个明确传播目标，提示词需要包含构图、镜头、光线、环境、色彩和产品一致性约束。
- 禁止生成不可验证的促销承诺、参数和品牌文案。
- 若某个执行失败，说明失败节点和原因，等待用户决定是否重试。
