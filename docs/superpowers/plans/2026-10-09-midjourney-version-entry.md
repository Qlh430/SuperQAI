# Midjourney 版本入口统一实现计划

> 使用 executing-plans 逐项实施；用户已确认本消息前的方案。

**目标：** 每个中转站外部只保留一个 Midjourney 入口，版本选择集中到齿轮，保留真实 ID、动态能力规则和已有设置。

**实现：** Flora 设置模块负责同一服务商 Midjourney 模型族的展示聚合与真实版本映射；模型选择器接收可选的展示目录及展示名称，原目录与原 select 仍保存真实模型。齿轮选择映射到真实 ID 或单 ID 的 version/niji 参数，再调用原同步/提交路径。

**边界：** 不合并不同服务商；未知参数不显示、不发送；不自动迁移用户数据；不改 Neon/Flora 样式。目录迟到和模型删除按既有失败/保留机制处理。3199 不停止，部署仅通过 deploy.mjs。
