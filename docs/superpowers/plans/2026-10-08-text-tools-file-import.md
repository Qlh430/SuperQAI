# 文字工具与文件导入 Implementation Plan

执行方式：按 executing-plans 顺序在当前共享工作区实施，不启动子代理。

**Goal:** 为文字节点增加背景色、放大编辑和 MD 导出，支持四类文档及独立媒体文件导入，修复媒体选中描边。

**Architecture:** 新增独立 Flora 文字工具模块和文件导入控制器，宿主提供节点操作、上传和状态接口。Mammoth/PDF.js 本地浏览器解析文档，独立构建解析包，仅导入复杂文档时加载。复用既有文字编辑器，避免两份正文状态。

**Tech Stack:** 原生浏览器组件、现有富文本渲染器、Vite、Mammoth、PDF.js、Playwright。

约束：Neon/Flora 语义令牌、简体中文；画布数据由宿主接口保存；构建成功后仅通过 deploy.mjs 备份部署；不得停止 3199 服务。

- [x] 文字工具：增加背景色、全屏编辑、Markdown 下载；统一背景字段保存/撤销/恢复/复制；检查当前正文与格式不丢失。
- [x] 文件导入：分类与批次控制器，接入粘贴/拖放；四类文档解析包与本地资源；媒体沿用上传接口，每文件独立节点；中文错误与切换画布隔离。
- [x] 媒体描边：定位被清除/遮挡的框层，新增 Flora 主体选中覆层，验证原比例不变。
- [x] 意义明确的回归：色板、全屏编辑/下载、真实文档解析、混合多文件拖放/粘贴、失焦、复制恢复、导入失败、四宽度与缩放/媒体选中状态。
- [x] 构建、备份部署、实际运行时回归与 acceptance.cjs；记录模拟 API 与真实登录边界，更新上下文。
