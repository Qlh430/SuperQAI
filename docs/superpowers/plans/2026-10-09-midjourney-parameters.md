# Midjourney 版本与动态参数实现计划

**目标：** 统一图片生成节点中的 Midjourney 版本与专属参数，用户看到中文易懂选项，请求严格遵守当前接入和版本规范。

**架构：** 共享能力规则由浏览器和后端共用。真实模型ID保留；只有单一 Midjourney 接入在画布模型列表展开配置版本，独立版本模型按真实目录显示。Flora 操作区齿轮打开专属设置，比例入口保留，切换版本清理不兼容参数，后端再次校验。

**约束：** 仅显示已确认支持的参数，不兼容项不显示不发送；不凭名称将其它协议当成 APIMart；不虚构上游模型ID；复用 Neon/Flora 组件与令牌；保存、恢复、复制、撤销、历史和多中转站目录均保留。禁止付费生成、改变用户真实画布、停止3199；部署前构建与备份，通过 deploy.mjs 部署。
