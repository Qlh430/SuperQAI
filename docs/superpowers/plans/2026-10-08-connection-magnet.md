# 连接点吸附与连线可见度实现计划

用户已确认方案，在当前会话按 executing-plans 顺序执行，不另建会话。

**目标：** 所有实际节点端口靠近鼠标时轻微跟随，扩大可操作范围；拖线优先吸附最近兼容端口；已有连线清晰、缩放后保持屏幕粗细。

**架构：** 新增 Flora 连接交互模块，负责屏幕距离命中、磁吸位移与鼠标事件，不保存任何画布数据。宿主保留连接类型校验、端口标识、操作队列和撤销；正反向拖线共用模块。现有 Flora/Neon CSS 提供端口和 SVG 状态，缩略场景渲染沿用同一令牌。

**约束：** 复用 Neon 语义令牌和原 Flora 按钮；中文文本；不移动系统鼠标；避让编辑区和工具栏；测试仅模拟 API；不停止 3199；构建通过后仅 deploy.mjs 备份部署。
