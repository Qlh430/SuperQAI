# 画布流畅度优化实施计划

**目标：** 不改变功能、交互、样式和保存结果，消除画布的重复计算与无效刷新。

**架构：** 先在真实宿主引擎、隔离 API 和相同混合画布上记录 CPU 采样、帧耗时、布局读取及重复调用。根据实际证据修复热点，限定在已有调度、DOM 同步和资源生命周期内；不降低媒体质量、不改变虚拟化规则、不重写画布引擎。

**技术：** 宿主 JavaScript、Flora 模块、Playwright/Edge、CDP 性能采样。

**约束：** Neon 独立工作台及 Flora 视觉保持一致；不修改用户数据库、不停止 3199；保存/撤销/历史/参考/生成回填完整；运行时仅通过构建后 deploy.mjs 备份部署。当前工作区已有大量修改，原地保留，无额外提交。用户已确认执行，使用 executing-plans 在当前会话逐项实施。
