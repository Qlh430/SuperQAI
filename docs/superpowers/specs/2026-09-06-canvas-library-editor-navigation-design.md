# 无限画布项目首页与编辑器双页面设计

## 目标

把无限画布从“编辑器里打开历史画布遮罩层”改为与 DX OS 一致的两级应用结构：打开无限画布应用时先进入独立项目首页，选择或新建画布后才进入编辑器。

## 已确认行为

- 每次从桌面、Dock 或启动台打开“无限画布”，默认进入项目首页，不自动恢复上次画布。
- 项目首页和画布编辑器是 `#canvasView` 内的两个同级页面；首页不是编辑器遮罩层，首页显示时编辑器不在背后参与交互。
- 项目首页保留“全部画布、我的画布、协同文件、最近使用、我的项目、回收站”、搜索、项目管理、画布卡片、共享和移动功能。
- 点击可用画布卡片后进入该画布编辑器；新建画布保存成功后进入新画布编辑器。
- 编辑器左上角显示“返回画布”按钮，返回时保存当前待处理修改并恢复离开前的首页范围、项目和搜索条件。
- 从共享文件或桌面文件按资源 ID 打开画布时允许直接进入指定画布编辑器；无权限或资源不存在时停留在项目首页并显示错误。
- 资产库只属于编辑器，不在项目首页显示。
- 删除“历史画布”入口、关闭历史按钮和首次启动遮罩，不保留独立历史弹层。

## 页面结构

`#canvasView` 的直接内容改为：

```text
#canvasView
├─ #canvasLibraryScreen.canvas-library-screen
│  ├─ 项目/范围侧边栏
│  ├─ 搜索、路径与画布卡片网格
│  └─ 画布卡片菜单
├─ #canvasEditorScreen.canvas-editor-screen [hidden]
│  └─ .canvas-workspace
│     ├─ 返回画布、资产库、新建、复位、清空
│     ├─ 无限画布与节点工具
│     └─ 编辑器专用提示层
└─ 新建/重命名/移动等两页面共用对话框
```

任何时刻只允许一个主页面可见。`hidden` 属性和 `data-canvas-screen="library|editor"` 是页面状态的 DOM 契约，CSS 不得用更高优先级重新显示被隐藏页面。

## 状态与导航

`canvasState.appScreen` 保存当前页面，初始值固定为 `library`。现有 `canvasScope`、`activeProjectId`、`boardSearchQuery` 继续作为首页导航上下文，因此编辑器返回首页时不需要重建另一套状态。

新增统一导航函数：

```js
setCanvasAppScreen(screen)
showCanvasLibrary({ reload = false } = {})
showCanvasEditor()
openCanvasBoardByResourceId(resourceId)
handleCanvasAppActivation(event)
```

- `setCanvasAppScreen` 是唯一可以切换两个主页面可见性的函数。
- `showCanvasLibrary` 关闭资产库和浮动菜单，保存当前画布，再按需刷新项目/画布列表。
- `showCanvasEditor` 只有在已经存在 `activeBoardId` 时才进入编辑器。
- 卡片打开流程必须先验证画布、恢复内容，再保持编辑器状态；加载失败时返回首页，不留下空编辑器。
- 桌面运行时为普通画布应用启动补充 `{ screen: "library" }`；带 `resourceId` 的启动参数不被覆盖。

## 交互与视觉

- 首页占满画布应用窗口，使用现有全局浅色/深色变量和系统缩放，不显示半透明遮罩或背后的网格画布。
- 首页头部显示当前范围/项目、数量和说明；右侧保留刷新、回收站和新建画布，删除关闭按钮。
- 编辑器返回按钮使用左箭头加“所有画布”，替代“历史”。
- 首页侧边栏和卡片网格独立滚动，在 75%、100%、125%、150%、175% 缩放和窄窗口中保持可用。
- 页面切换不重建无限画布 DOM，以保留节点、缩放、资产面板和 Agent 的既有生命周期。

## 数据与兼容性

- 不修改数据库结构、画布存储格式、项目归属、资源共享模型或资产库数据。
- `openCanvasBoardFromHistory` 保留函数名以兼容现有内部调用，但语义改为“从首页/记录打开画布”，成功后进入编辑器。
- 统一历史记录点击画布仍可直达编辑器。
- 桌面应用每次显式启动回到首页；共享文件传入 `resourceId` 时例外直达对应画布。
- 旧的 `#canvasBoardPanel`、`.canvas-start-gate` 和用户可见“历史画布”文本应从运行时 DOM 移除。

## 失败处理

- 首页刷新失败：保持首页和已有卡片，状态栏显示错误。
- 画布恢复失败：关闭加载提示、回到首页并显示“画布打开失败”。
- 资源 ID 不存在或当前账号无权读取：停留首页，提示“找不到可访问的画布”。
- 返回首页时保存失败沿用现有非阻断状态提示，不阻止用户离开编辑器。
- 快速连续点击卡片时继续使用 `boardOpening` 防重入。

## 验收标准

- 登录后自动打开无限画布窗口时，首页可见、编辑器隐藏。
- 关闭后再次打开、最小化后从 Dock 再次打开、已聚焦时再次点击 Dock，均回到首页。
- 点击画布卡片后首页隐藏、编辑器显示且标题/节点对应所选画布。
- 点击“所有画布”后编辑器隐藏，原项目、范围和搜索条件保持。
- 新建画布进入编辑器；返回后新画布出现在原项目中。
- 共享文件按资源 ID 打开可访问画布时直接进入编辑器；无权限时回到首页。
- 首页 DOM 是编辑器的同级页面，不存在 `#canvasBoardPanel` 和 `.canvas-start-gate`。
- 浅色/深色与五档系统缩放下首页均位于窗口边界内，侧边栏和卡片可操作。
- `npm run check`、画布项目检查、资产库检查和新增导航检查通过。
