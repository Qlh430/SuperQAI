# 暗房工作台界面精修设计

## 背景

当前深色模式存在两个明确缺陷：

- 在线生图关闭按钮被后置通用规则设为浅色背景，叉号又继承深色主题的浅色前景，形成近似“白底白叉”的低可见状态。
- GPT 历史标题在样式表后段重新写入固定的 `#202020`，覆盖链脆弱，深色面板上出现近黑文字。

在线生图还混用了白色表单控件、深色面板和不同风格的卡片，三栏功能完整，但视觉层级不统一。

## 目标与非目标

目标：

- 保留在线生图的左侧参数、中间预览、右侧历史三栏布局。
- 保留 GPT 对话左侧历史、右侧消息区域及现有操作路径。
- 修复深色模式关闭按钮和历史文字可见性。
- 统一为“暗房工作台”视觉语言：安静、专业、精确，黄色只表达操作与状态。
- 建立语义颜色和末端主题覆盖，防止 CSS 级联再次引入低对比。
- 保持浅色模式、其他调色板、响应式布局和业务行为不变。

非目标：

- 不重排三栏结构，不新增抽屉、弹窗或操作步骤。
- 不修改图片生成、历史保存、对话保存和模型选择逻辑。
- 不引入网络字体、图片素材或前端框架。
- 不重构画布、设置中心或其他工具页面。

## 设计方向

采用已确认的方案 A“暗房工作台”。产品服务于在本地集中进行图片生成、预览和对话协作的创作者；页面的任务是让用户快速配置参数、判断视觉结果并继续下一次操作。

设计不使用纯黑背景、满屏霓虹黄和强发光效果。背景采用略带暖色的石墨层级，模仿数字暗房和影像工作台；信号黄仅出现在主按钮、当前会话、键盘焦点和短暂状态上。

### 色彩

深色默认黄黑调色板使用以下语义色：

- `darkroom-canvas: #121311`：窗口外层与主背景。
- `darkroom-panel: #191A18`：控制区与历史区。
- `darkroom-field: #222320`：输入框、选择器与参考图槽位。
- `darkroom-preview: #10110F`：中央图片预览工作台。
- `darkroom-line: #30312C`：边界与分隔线。
- `darkroom-ink: #F5F3EA`：标题与主要内容。
- `darkroom-muted: #AAA89F`：说明、模型与时间。
- `darkroom-accent: #FFD23F`：主操作与状态。

这些值以作用域内的 CSS 自定义属性提供。非默认调色板从现有 `--panel`、`--ink`、`--muted`、`--line` 和 `--accent` 派生，不覆盖用户个性化选择。

### 字体

- 标题与工具标签：`"Bahnschrift SemiCondensed", "Microsoft YaHei UI", sans-serif`。
- 中文正文与说明：`"Microsoft YaHei UI", "Microsoft YaHei", sans-serif`。
- 模型、比例与尺寸：`"Cascadia Mono", Consolas, monospace`。

不加载外部字体；缺少首选字体时使用本机回退。

## 布局与视觉层级

现有 DOM 与三栏网格保持不变：

```text
┌ 在线生图                                      [关闭] ┐
├────────────┬──────────────────────────┬────────────┤
│ 提示与参数  │        图片预览工作台       │  历史记录   │
│ 参考图      │                          │  缩略图列表  │
│ 模型/尺寸   │                          │             │
│ [生成图片]  │                          │             │
└────────────┴──────────────────────────┴────────────┘
```

- 头部维持 63–64px 高度和单一底部分隔线。
- 三栏间距、面板内边距和圆角收敛到 12/14/16px 节奏。
- 中央预览保持最大视觉权重；左右面板比预览略亮一级，不堆叠明显阴影。
- 参考图槽位、输入框和选择器统一使用 `darkroom-field`，消除白色下拉框的视觉跳脱。
- 历史缩略图统一边框、文字和悬停逻辑，不改变尺寸与滚动方式。

## 在线生图组件

### 关闭与清除按钮

- 关闭按钮保持 36px 和原位置、点击逻辑。
- 深色默认状态使用 `#24251F` 背景、暖灰边框和 `#FFF4C0` 叉号。
- SVG 显式使用 `stroke: currentColor`。
- 悬停和键盘焦点使用黄色背景、深色图标；焦点增加 3px 半透明外环。
- 清除预览按钮沿用相同的图标对比逻辑。
- 现有 `aria-label` 与行为不变。

### 参数与参考图

- 提示文本框、模型、尺寸、张数和复选框统一为深色字段。
- 标签使用次要文字色，当前值使用主要文字色。
- 输入焦点只使用细黄色边框和外环，不添加发光动画。
- 主按钮继续使用信号黄，并保证图标和文字对比。
- 参考图槽位使用低对比边界，悬停与键盘焦点时边界转黄。

### 预览与历史

- 中央预览使用接近黑色的“灯箱”表面与极弱棋盘纹理；空状态标题清晰，说明文字保持次级。
- 历史标题、清空动作和历史卡片建立三级文字层次。
- 历史卡片默认不发光；悬停只改变边框和表面亮度。
- 图片历史当前没有常驻选中状态，因此不新增虚假的选中标记；卡片在键盘焦点时显示 2px 黄色“曝光指示线”。

## GPT 对话历史

- 历史侧栏使用 `darkroom-panel`，与主对话区保持一级亮度差。
- 对话标题使用 `darkroom-ink`，模型与时间使用 `darkroom-muted`。
- “最近对话”和“清空全部”在默认、悬停和焦点状态下保持可读。
- 当前会话使用轻微提亮背景和左侧 2px 黄色曝光指示线；这是本次精修的识别性细节。
- 更多操作按钮在行悬停、键盘焦点或菜单打开时可见。
- 样式表末端使用暗房语义变量重申深色历史标题规则，明确覆盖此前的固定 `#202020`。
- 顶部新对话、清空当前和关闭按钮使用同一套深色控件状态，移除低对比深蓝状态。

## 动效与无障碍

- 悬停、背景和边框过渡统一为 140ms。
- `prefers-reduced-motion: reduce` 下关闭非必要位移和过渡。
- 正文和历史标题以至少 4.5:1 的对比度为验收目标；图标和控件边界以至少 3:1 为目标。
- 所有可点击控件提供清晰的 `:focus-visible` 状态。
- 当前会话同时使用背景变化和曝光指示线，不以颜色作为唯一状态信息。

## 技术边界

- 修改集中在 `styles.css`，在文件末端增加作用域严格的 `Darkroom workbench polish` 主题区块。
- 使用 `#imageView`、`#chatView` 与 `:root[data-theme="dark"]` 的组合选择器，避免影响其他工具。
- 不使用无边界的全局元素选择器；不新增 `!important`。
- 不修改 `script.js` 或 `index.html`；当前 DOM 与状态类足以实现设计。

## 验证策略

自动检查先行：

- 新增一个最初失败的主题回归检查，验证在线生图深色关闭按钮具有深色背景、浅色图标及悬停/焦点状态。
- 验证叉号 SVG 显式继承按钮颜色。
- 验证 GPT 历史标题的最终深色规则位于固定标题规则之后，并使用暗房语义变量。
- 验证主要标题、次要信息和焦点色由暗房语义变量控制。
- 实施后运行 `npm run check`，确保现有回归检查全部通过。

浏览器视觉验证：

- 在深色模式、默认黄黑调色板下分别打开在线生图和 GPT 对话。
- 检查 1920×1080 桌面视口和小于 1080px 的现有响应式断点。
- 截取全窗口及关闭按钮、参数控件、历史列表局部截图。
- 验证默认、悬停、键盘焦点、当前会话和历史菜单打开状态。
- 复查浅色模式及一个非默认调色板，确认没有布局或对比度倒退。

## 验收标准

- 在线生图右上角叉号在深色模式默认状态下一眼可辨，悬停和键盘焦点状态明确。
- GPT 历史标题、模型和时间可直接阅读，当前会话清晰但不过度抢眼。
- 在线生图仍为原三栏结构，所有字段、按钮和历史操作位置不变。
- 白色表单控件不再割裂深色工作台；中央预览仍是视觉中心。
- 黄色只用于生成按钮、选择、焦点和状态，没有新增大面积渐变或发光装饰。
- 自动检查全部通过，浏览器控制台无新增错误。
