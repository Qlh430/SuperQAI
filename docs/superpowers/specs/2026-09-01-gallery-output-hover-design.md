# 图集连接点与悬浮交互设计

## 目标

让图集的整体输出和单图输出无需文字也能清楚区分，并让图片在悬停时具有克制、精致的前浮反馈。

## 视觉规则

- 图片网格相对图集容器四边缩进 16px，图片不再紧贴标题栏或左右边框。
- 图集整体输出继续位于容器右侧中心，保留现有金色圆形端口，但不显示任何文字。
- 多图图集的单图输出默认隐藏。悬停、键盘聚焦或已选中某张图片时，仅该图片显示自己的小型端口和短引导线。
- 单图输出使用无文字的细描边端口，与图集金色圆点保持不同的尺寸、色调和形态；单图图集仍只保留整体输出。

## 交互与动效

- 悬停或聚焦图片时，图片本体上移 5px，轻微放大并增加柔和阴影，持续约 180ms。
- 前浮图片提高层级，避免阴影被相邻图片覆盖；离开后平滑复位。
- 单图端口与短引导线和图片一起淡入，不改变图集整体输出的位置或连线语义。

## 数据与兼容性

- 保留 `member-output:<id>` 与图集通用 `output` 两套现有端口句柄及既有连线逻辑。
- 只修改渲染标记与 CSS；不重建成员、不给图片裁切、不改变原始比例或自动列布局。

## 验证

- 图集 UI 静态检查覆盖：无端口文字、图片内边距、单图端口仅在图片交互状态出现、图片前浮动效。
- 保持图集操作检查和全量 `npm run check` 通过。
