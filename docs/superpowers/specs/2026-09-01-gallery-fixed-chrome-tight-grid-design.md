# 图集固定框架与紧凑网格设计

## 目标

图集被放大或自动向下扩容时，顶部工具栏与底部信息栏保持其原有高度；图片区是唯一接收额外高度的区域。图片始终以原始比例显示，成员间隔固定为 16px，不因容器变高而被拉大。

## 布局规则

- 图集外层使用固定的三段轨道：38px 顶部栏、可伸缩图片区、30px 底部栏。
- 图片区使用 `align-content: start`，行从顶部开始紧凑排列。
- 图片区的行、列间距均固定为 16px；横向扩展仍通过列数变化放大图片，纵向扩展仍通过现有尺寸计算选择行列，但不会把空白分配进间距或顶部栏。
- 不改变成员顺序、图片比例、连接点、悬浮效果、拖拽、撤销或连接线逻辑。

## 验证

- CSS 回归检查确认三段轨道与成员网格的顶部对齐规则。
- 图集专项检查、画布存储检查和全量 `npm run check` 必须通过。
