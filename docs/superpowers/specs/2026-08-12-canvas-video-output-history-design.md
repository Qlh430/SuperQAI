# 画布视频输出历史设计

## 目标

把现有单结果“视频输出”节点增强为节点级视频图集。每个视频输出节点只保存其所连接 MiniMax H3 节点的成功结果；新生成的视频成为当前视频，旧结果继续保留并可查看。

## 交互

- 视频输出节点继续以当前视频播放器作为主视图。
- 节点右上区域增加历史按钮和视频数量；只有一条记录时也可打开历史。
- 历史面板按最新结果优先显示，每项包含视频缩略播放区域、名称、生成时间和提示词摘要。
- 点击历史项将其设为当前视频并在主播放器中播放。
- 每项支持播放预览、下载和从本节点历史中删除。
- 删除当前项后自动切换到剩余的最新项；删除最后一项后节点恢复为空输出状态。
- 生成失败或被中断时保留全部已有历史，不新增记录，也不改变当前视频。

## 数据模型与兼容

视频输出节点新增 `videoHistory` 数组和 `activeVideoId`：

- `id`：节点内稳定唯一标识。
- `src`：本地 `/output/...` 视频地址。
- `name`：下载和显示名称。
- `mimeType`：默认 `video/mp4`。
- `duration`：可选时长秒数。
- `promptSummary`：生成提示词摘要。
- `createdAt`：ISO 时间。

画布序列化只保存上述元数据，不嵌入视频二进制。旧画布中的 `videoSrc`、`videoName`、`videoMimeType`、`videoDuration`、`videoPromptSummary` 和 `videoCreatedAt` 在恢复时自动转换为一条历史记录；原字段在当前版本继续写入，保证旧代码路径和已有连接仍能读取当前视频。

复制粘贴、撤销重做和画布保存沿用现有节点序列化流程，完整保留历史和当前项。视频输出节点作为其他 H3 节点的参考视频时，只输出当前选中的视频。

## 生成数据流

H3 成功返回视频后：

1. 查找与当前 H3 相连的视频输出节点；没有时创建并连接一个。
2. 将新结果规范化为历史项并追加，按 `src` 去重。
3. 将新结果设为 `activeVideoId`。
4. 重绘播放器、历史面板和连接消费者，并保存画布。

再次生成不会创建重复输出节点，也不会覆盖已有历史。

## 删除与文件安全

删除历史项只修改节点内历史数据，不删除 `output/` 中的实际文件。这样可避免同一视频被其他节点、旧画布快照或下载链接引用时发生数据丢失。删除整个视频输出节点同样不删除磁盘文件。

## 样式

复用图片图集的堆叠封面、历史按钮、浮层层级、列表和深色主题视觉语言，并为视频元素补充适配。历史面板在画布节点之上显示，不改变视频输出节点现有宽度；内容过长时面板内部滚动。

## 验证

自动化检查覆盖：

- 连续两次生成追加两条历史且最新项激活。
- 旧单视频节点自动迁移。
- 切换、删除当前项和删除最后一项。
- 序列化、恢复、复制粘贴和撤销重做保留历史。
- 当前选中视频继续作为下游参考视频。
- 失败任务不覆盖已有历史。
- 项目完整 `npm run check` 通过。

浏览器验证覆盖：历史按钮数量、面板开合、主视频切换、下载、删除、刷新恢复以及深色主题布局。
