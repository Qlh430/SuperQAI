# MiniMax H3 参考素材 `@` 选择器设计

## 目标

在 MiniMax H3 画布节点的视频描述输入框中提供 `@` 参考素材选择器。用户只需连接素材节点、输入 `@` 并选择素材，即可插入 H3 官方格式的引用标签，然后直接提交生成。

该选择器只显示已经连接到当前 H3 节点的素材，不扫描画布上的其他节点，也不会因为选择素材而创建新连接。

## 官方规则依据

MiniMax H3 的全参考 Ref2VA 提示词使用以下标签：

- `<Picture N>`：作为具体画面、关键帧或构图参考的图片。
- `<Video N>`：作为编辑源、续写起点、镜头运动、剪辑节奏或时序结构参考的视频。
- `<Audio N>`：被复制或用于音色、对白、节奏、音乐和音效参考的音频。
- `<Subject N>`：从一个或多个素材中抽象出的可复用人物、物体、场景、动作或风格；它不是文件选择器中的独立素材类型，因此本功能不自动插入 `<Subject N>`。

图片、视频和音频分别独立编号。选择器插入的标签必须保持官方英文拼写、尖括号和从 1 开始的序号。

## 选定方案

保留现有原生 `textarea`，增加一个与当前 H3 节点绑定的浮动选择菜单。选择结果仍然是普通文本，不引入 `contenteditable`、不可编辑标签块或隐藏富文本状态。

这样可以保留现有的复制、粘贴、画布保存、外部提示词同步和 API 请求结构，同时把改动限制在 H3 节点的输入交互层。

## 交互设计

### 打开与关闭

- 当 H3 视频描述输入框可编辑时，输入 `@` 打开菜单。
- `@` 必须位于文本开头，或前一个字符是空白、换行或常见标点，避免普通字符串中的 `@` 误触发。
- 中文输入法组合输入期间不打开或更新菜单。
- 按 `Escape`、点击菜单外部、输入框失焦，或将光标移到触发位置之前时关闭菜单。
- 当 H3 提示词由外部文本或 LLM 节点同步、输入框处于只读状态时，不打开菜单。

### 菜单内容

- 菜单仅读取连接到当前 H3 节点的图片、视频和音频节点。
- 可用素材按“图片、视频、音频”分组，组内顺序与 H3 节点现有参考素材列表完全一致。
- 图片显示缩略图；视频和音频显示类型图标。
- 每项显示官方引用标签和文件名，例如 `<Picture 1>` 与 `人物正面.png`。
- 已连接但尚未上传文件的空素材节点显示为“等待上传”，置于所属分组末尾并禁用；它没有可插入的引用标签。
- 没有任何已连接素材时，菜单显示“请先连接参考素材”，不提供全画布搜索入口。

### 搜索和键盘操作

- `@` 后、光标前的文本作为当前筛选词。
- 可按文件名、素材类型中文名、官方类型名或编号筛选。
- `ArrowDown`、`ArrowUp` 移动高亮项，`Enter` 或 `Tab` 选择，鼠标点击也可选择。
- 禁用项不参与键盘高亮循环。
- 菜单没有可选结果时，`Enter` 保留输入框原有换行行为。

### 插入行为

- 选择素材后，将本次 `@筛选词` 替换为准确的官方标签。
- 标签后自动补一个空格；如果后方已经有空白，则不重复添加。
- 插入后恢复输入框焦点，并把光标放在标签后的空格之后。
- 触发与现有输入事件相同的保存流程，使提示词立即写入节点数据并进入画布自动保存。
- 通过菜单插入的标签只是普通文本，可继续编辑、删除、复制和粘贴。

## 编号与状态同步

- 可用素材编号复用当前 H3 节点的参考顺序函数，不能建立第二套编号逻辑。
- 连接、断开、上传完成或调整参考顺序后，下一次打开菜单时必须反映最新状态。
- 菜单打开期间发生上述变化时，菜单立即重绘，并保留仍然有效的筛选词。
- 提示词内已经存在的标签不因素材重排而自动改写；标签始终指向当前参考列表中对应序号的素材。

## 提交前校验

点击“生成视频”时，在原有素材数量和上传状态校验之外，扫描提示词中的标准引用标签：

- `<Picture N>` 必须对应当前可用图片。
- `<Video N>` 必须对应当前可用视频。
- `<Audio N>` 必须对应当前可用音频。

若存在越界或已失效的标签，则不发送生成请求，并在节点状态区列出缺失标签，例如“提示词引用的 `<Video 2>` 当前不存在”。校验不要求提示词必须包含引用标签；用户仍可只连接素材并用自然语言描述。

有效提示词按原文本原样提交到现有 `/api/minimax-h3-video` 接口，服务端和 ComfyUI 工作流不改变引用格式。

## 组件边界

实现拆分为以下职责：

1. 素材适配器：从当前 H3 节点连接中生成统一的菜单项，并复用现有参考顺序与编号。
2. 触发解析器：根据文本、光标和输入法状态识别当前 `@` 查询区间。
3. 菜单控制器：负责渲染、定位、筛选、键盘导航和关闭。
4. 文本插入器：只负责替换触发区间、恢复光标并派发输入事件。
5. 引用校验器：在提交前检查标准标签是否对应当前可用素材。

这些模块只依赖 H3 节点和现有画布连接数据，不读取其他节点的全局素材目录。

## 视觉与可访问性

- 菜单沿用 H3 节点现有深色面板、黄色强调色、缩略图和圆角规范。
- 菜单固定在视频描述输入框附近；下方空间不足时显示在输入框上方，不能被节点内容裁切。
- 当前高亮项必须有明显背景与边框变化。
- 菜单使用 `role="listbox"`，选项使用 `role="option"`；输入框维护 `aria-expanded` 和当前活动项。
- 鼠标按下菜单项时阻止输入框提前失焦，确保点击能够完成插入。

## 错误处理

- 当前节点已被删除、菜单项在点击前失效或引用顺序变化时，取消本次插入并安全关闭菜单。
- 缩略图加载失败时显示图片类型占位图，不影响标签选择。
- 空素材上传完成后自动从禁用状态变为可选状态。
- 任意选择器错误都不能影响用户继续手工输入提示词或使用现有生成流程。

## 测试与验收

### 自动化检查

- 触发解析：文本开头、空白后、标点后、邮箱式字符串、换行、光标移动和中文输入法状态。
- 菜单数据：图片、视频、音频独立编号，组内参考顺序，空素材禁用，断开后移除。
- 插入：替换 `@查询词`、空白去重、光标恢复、输入事件和节点保存。
- 键盘：上下键循环、跳过禁用项、回车或 Tab 选择、Escape 关闭、无结果时保留换行。
- 校验：有效标签、越界标签、断开后的标签、不同素材类型独立编号以及无标签提示词。
- 持久化：保存并恢复画布后，已插入标签和参考顺序保持一致。

### 浏览器验收

1. 连接一张图片、一个视频和一个音频到 H3 节点。
2. 在描述中依次通过 `@` 插入 `<Picture 1>`、`<Video 1>`、`<Audio 1>`。
3. 使用鼠标和纯键盘各完成一次选择。
4. 调整参考顺序，重新打开菜单并确认编号与右侧参考列表一致。
5. 连接一个空视频节点，确认它显示“等待上传”且不可选；上传完成后变为可选。
6. 断开已引用素材，确认生成前给出明确缺失标签提示。
7. 恢复有效连接并提交，确认请求中的提示词保留官方标签且任务正常创建。

最后运行现有 MiniMax H3 聚焦检查、浏览器 UI 检查和完整 `npm run check`，不得破坏画布连接、素材上传、提示词同步或生成任务流程。

## 非目标

- 不从整个画布选择或自动连接素材。
- 不自动生成 `<Subject N>` 定义或完整六段 Ref2VA 提示词。
- 不把文本框改造成富文本编辑器。
- 不自动改写用户已经输入的引用标签。
- 不改变 MiniMax H3 工作流、素材上传接口或服务端任务协议。
