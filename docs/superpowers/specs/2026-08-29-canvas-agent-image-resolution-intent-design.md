# Canvas Agent 生图分辨率意图与兼容降级设计

## 背景

Canvas Agent 在更新已有图片生成节点时，可能把“2K”“4K”等要求只写入提示词，没有同步写入节点的结构化 `resolution` 字段。节点随后沿用旧分辨率执行，导致界面文字、节点状态和实际请求不一致。

此外，不同图片模型、平台和画幅支持的分辨率组合不同。请求端只能保证提交参数正确，不能保证第三方接口严格按照请求分辨率返回图片。因此，验收必须区分“请求参数错误”和“服务端降级返回”。

## 目标

- Agent 能把用户表达的 `512 / 1K / 2K / 4K` 稳定转换为结构化分辨率参数。
- 更新旧节点和新建节点使用同一套分辨率规范化与兼容规则。
- 不兼容时无需二次确认：提示用户后自动调整并继续生成。
- 请求端测试验证实际发出的请求参数，不把第三方返回像素作为请求正确性的必要条件。
- 生成完成后如实显示服务端返回图片的实际像素，不把降级返回误报为生成失败。

## 非目标

- 不强制第三方接口返回与请求档位完全一致的像素。
- 不对第三方模型的内部缩放、压缩或质量策略作推断。
- 不修改画布布局、节点缩放或图片展示尺寸。
- 不改动用户现有 API 配置和模型能力开关。

## 参数规范化

内部标准分辨率值为：

- `512`：512 档
- `1`：1K
- `2`：2K
- `4`：4K
- `auto`：自动尺寸
- `exact:宽x高`：平台允许的精确兼容尺寸

Agent 工具收到 `1K`、`2k`、`4K清晰度` 等别名时，先转换为标准值。若 `resolution` 为空，但本次节点更新的提示词中存在明确分辨率意图，则补全该结构化字段。普通数字、文件名或与清晰度无关的文本不参与推断。

## 兼容性决策

执行前使用模型候选的 `platform`、`family`、已启用 `resolutions`、画幅和现有 `ImageResolutionRules` 进行预检。

处理顺序如下：

1. 用户请求组合可用：保持原参数执行。
2. 档位可用但当前画幅不兼容：优先采用规则返回的同画幅精确兼容尺寸。
3. 模型未启用请求档位或没有精确替代尺寸：选择不高于用户请求的最高可用档位。
4. 没有低档位可选时：选择该模型最低可用档位，保证任务仍可执行。
5. 所有候选均不可执行时：停止付费请求并返回明确错误，不伪装成“没有模型”。

发生自动调整时，Agent 在任务状态中明确说明原参数和新参数，例如：

> 当前模型的 1:1 标准 4K 不兼容，已调整为最大兼容尺寸 2880×2880，并继续生成。

该提示不要求用户再次确认。

## 数据流

1. Agent 工具适配层规范化用户和模型输出中的分辨率别名。
2. 节点更新层把规范化后的值同步写入下拉框、节点 dataset 和持久化字段。
3. 节点执行层重新读取当前模型能力并运行兼容预检，防止旧节点或并发更新带入失效值。
4. 请求构造层只使用预检后的结构化参数。
5. 工具结果返回实际提交的比例、分辨率档位或精确尺寸，以及是否发生自动调整。
6. 图片返回后保存真实宽高，界面显示实际尺寸；实际尺寸低于请求档位不改变任务成功状态。

## 错误处理

- 无法识别的分辨率别名不直接写入 `<select>`，避免出现空白下拉框。
- 模型列表刷新导致原档位失效时，执行前重新选择兼容参数并提示。
- 请求已经正确发送但返回低分辨率图片时，记录“请求档位”和“实际尺寸”两组信息，不自动重复生图，避免额外费用。
- 只有请求失败、结果不可读取或没有任何可运行模型时，任务才进入失败状态。

## 测试设计

### 单元测试

- `2K`、`2k`、`2K清晰度` 均规范化为 `2`。
- 空 `resolution` 加明确提示词时补全档位。
- 明确结构化参数优先于提示词推断。
- 不相关文本不触发分辨率推断。
- 不兼容 4K 能选择规则建议的精确尺寸或最高可用低档位。

### 真实浏览器回归测试

浏览器测试创建默认 1K 图片节点，通过 Agent 更新为 `9:16 + 2K` 并执行。测试拦截 `/api/images` 请求并断言：

- 节点下拉框不是空白。
- 节点持久化值为标准分辨率值 `2`。
- 出站请求包含与 `9:16 + 2K` 对应的正确参数。

模拟接口可以返回任意测试图片尺寸，包括 1K。只要请求参数正确、返回结果被正常保存并显示真实像素，测试即通过。

另增加不兼容 4K 用例，断言系统自动调整、继续发送一次请求，并向用户展示调整说明；不得弹出二次确认，也不得重复付费请求。

## 验收标准

- 用户通过 Agent 要求 2K 时，结构化请求不再沿用旧 1K 值。
- 用户要求不兼容的 4K 组合时，Agent 自动调整、提示并继续生成。
- UI、节点 dataset、持久化数据和出站请求中的分辨率保持一致。
- 第三方返回尺寸与请求档位不一致时，任务仍可成功，并显示实际像素。
- 便携版打包入口仍能包含更新后的前端脚本和测试所依赖文件。
