# 项目返回与回收站删除

用户已请求增加两个操作，沿用现有 Neon 独立工作台组件与中文文本。

- 选择项目目录、共享目录、未归类或回收站时，在下方画布列表的项目名称前展示绿色“← 返回”按钮（可访问名称为“返回全部画布”）。点击清除搜索、项目筛选，切到画布列表。
- 点击左侧“项目”，包括当前已经在项目页时，重新进入默认全部视图并回到内容顶部。画布返回项目及浏览器历史继续保留来源上下文。
- 回收站中自己的画布提供“恢复画布”和“永久删除”。永久删除先展示官方确认弹窗，明确不可恢复、画布节点与连接被删除，其他媒体引用仍保留。
- 取消不调用删除接口；执行中禁用操作；失败保留目标及中文错误供重试，成功刷新列表。
- 复用现有 DELETE /api/canvas/boards/:id/permanent，宿主限制仅所有者且画布必须位于回收站。此次仅增加前端入口，不删除用户实际数据进行测试。
- 回归覆盖四宽度的返回、重复导航、搜索清除、回收站确认/取消/失败重试/恢复、无错误和溢出；真实临时服务验证删除权限、非回收站拒绝与原媒体保留。构建后仅通过 deploy.mjs 备份部署，部署后完整验收。
