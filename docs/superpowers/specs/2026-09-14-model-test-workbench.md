# 模型测试与参数简化

用户已确认：参考 DX OS，提供用户主动输入的简单对话和图片测试；不要要求用户编写 JSON。沿用当前工作区和已有修改，不再逐项确认。

## 交互

- 模型行“测试”只打开小型测试窗口，不能自动发请求或保存配置。
- 标题标明平台与原始模型 ID。对话与生图按模型能力展示，支持两种能力时可以切换。
- 提示词、发送按钮、结果是核心。对话保留本次窗口内的对话上下文；图片显示预览，可放大。
- 发送前明确“会调用所选 API，可能产生费用”。不自动重试、不自动切平台。
- 反馈区显示等待、成功与耗时、失败原因和建议。任务编号只能表示已提交，不能显示图片生成成功。
- 支持关闭、Esc、焦点约束；发送期间防止重复请求，关闭后不让旧响应覆盖新窗口。关闭不承诺取消上游任务。
- 图片只允许安全 HTTP(S) 或限定图片 data URL，回复用 textContent，禁止将上游内容当 HTML。

## 参数

- 删除 JSON 编辑器；常用默认参数放在折叠的“默认参数”下，通过中文控件配置。
- 按模型协议展示参数，不对所有平台暴露同一组字段。不支持的协议仅保留已有配置。
- 保留未知参数和原有值；未改动时不进行类型转换，不因隐藏字段而清空配置。
- 用户调整常用值才更新对应键；节点明确传入的值仍优先。

## 技术与视觉

- Vanilla JS / CommonJS + UMD，与现有设置页和协议引擎兼容。
- 新增独立测试窗口模块和参数控件模块，设置页仅负责接线。
- 沿用现有浅蓝/深色主题变量、系统字体、蓝色发送按钮。窗口 640px 内，窄屏占可用宽度，回复/图像区优先于技术字段。
- 不增加依赖、不修改密钥、不迁移数据库、不重启运行中的服务、不调用真实收费接口。

## 验证

单元测试覆盖字段保留/删除/校验、请求内容、结果状态、安全图片和响应长度。浏览器测试覆盖主动发送、回复/图片显示、失败、关闭后旧响应、主题和窄屏。后端本地测试覆盖空结果、任务待完成、真实回复与大图片数据保留。
