# 视频输出节点紧凑布局设计

## 目标

让视频输出节点像生成图集节点一样简洁：节点主体只保留标题栏和原生视频播放器，历史入口悬浮在节点右侧靠下位置。

## 已确认方案

- 删除播放器下方的文件名、提示词摘要和操作条。
- 删除当前视频的独立“下载”按钮；当前视频使用浏览器原生视频控件右下角菜单下载。
- 历史按钮直接挂在视频输出节点上，定位于右侧靠下，并部分跨出节点边缘。
- 历史按钮采用图集入口相同的 42px 悬浮按钮语言，使用视频历史图标和右下角数量徽标。
- 没有历史记录时隐藏历史按钮；有历史记录时显示数量。
- 保留现有历史面板；历史卡片继续展示文件名、提示词、时长，并保留历史视频的下载与删除操作。
- 不修改历史数据结构、当前视频切换逻辑、下游连接解析、画布保存恢复或 H3 生成链路。

## 交互与布局

- 标题栏保持“视频输出”或“等待视频”。
- 播放器紧接标题栏，作为节点的主要视觉内容。
- 历史按钮位于节点右边缘下部，避免覆盖原生视频控件的三点菜单。
- 点击历史按钮沿用现有侧边历史面板；点击节点外或按 Escape 关闭。
- 打开面板、切换当前视频、删除历史视频后的交互保持不变。

## 验收标准

- 视频输出节点 DOM 不再生成 `.canvas-video-output-meta` 和当前视频下载链接。
- 历史按钮不再位于底部操作条，而是节点的直接子元素。
- 历史按钮具有绝对定位、右侧负偏移和靠下定位，数量徽标固定在按钮右下角。
- 历史面板仍能显示文件名、提示词，并提供历史条目的下载和删除。
- 既有视频历史检查、完整 `npm run check` 和浏览器交互验收全部通过。
