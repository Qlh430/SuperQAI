# 项目删除与媒体清理

用户已确认：项目删除必须覆盖目录内全部画布，需要保留的画布可提前移走；画布永久删除时，没有其他画布引用且不在资产库登记的素材一并删除。引用和入库不复制媒体文件。

- 项目删除只允许所有者执行，系统未分类目录和接收者的共享目录不提供删除。
- 项目目录删除后，其全部画布进入回收站，已有回收站画布继续保留。恢复目的地为所有者未分类目录；不会把画布保留在活动列表里。
- 移入回收站保留素材，永久删除才清理该画布引用的本地媒体。其他活动/回收站/迁移中的画布、任意账户资产登记保护媒体；外部地址和他人拥有的媒体不由本操作删除。
- 不依赖分享权限判定是否保留资产，资产引用即使非公开也保护原媒体。不扫描删除不相关文件。
- 媒体引用写入和清理串行协调。项目两库变更失败需补偿，删除请求可重试。
- 文件清理失败但画布已删除时显示清理提示，不能把已完成的画布删除报告为整体失败。
- 历史保留提示词，但已清理媒体不继续产生损坏预览。
- 删除入口、确认、忙碌、错误、返回及移动端统一复用 Neon 官方组件。
- 所有验收使用临时数据库与独立端口，不删除现有用户画布或媒体；部署只通过 deploy.mjs，备份后写入，禁止结束3199服务。
