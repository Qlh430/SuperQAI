# ComfyUI 独立设置

## 范围与选择

沿用用户“按推荐直接执行”的授权。本次采用独立设置页中的“远程连接 / 本机托管”，不再反复确认设计。单纯改名无法提供进程管理；安装远程控制代理需要额外部署与凭据，因此不包含在本次实现中。

“本机”始终指 AI OS 服务所在电脑。浏览器可以在局域网其他电脑打开。同机托管可启动；分机连接只需 URL，不能靠共享目录远程启动。默认监听 127.0.0.1，用户可以明确选择 0.0.0.0 开放局域网。页面说明防火墙要求，不自动修改防火墙。

## 数据与兼容

- 独立模块管理配置、路径检测、连接探测、进程生命周期；配置保存在现有 SQLite system_settings 中。
- 读取已有 ComfyUI provider 的地址作为首次配置，不在查看页面时写库。
- 保留 provider ID、加密密钥和工作流/模型；保存时只同步所选旧连接的地址，不删除其他连接。
- 多个旧连接可在独立页面切换；当前选择作为默认 ComfyUI 工作流地址，显式任务地址保持有效。
- API 页隐藏 ComfyUI provider 和平台选项，运行协议保留以兼容已有视频模型。

## 界面

沿用系统设置主题与文字大小。基础面板只有访问地址和测试；本机模式展示根目录、“识别路径”、监听地址和端口，高级设置含 Python、main.py、输出目录。常见安装在保存时自动识别缺失路径。独立状态区域显示连接状态、进程归属、PID、错误建议和按需展开的启动日志。

不加装饰性仪表盘。标志性元素为“AI OS 服务主机 → ComfyUI”连接说明，明确操作位置。配色复用现有蓝 #2f80ed、浅蓝 #e1eaf6、纸白 #f7f9fc、墨色 #222832、绿 #45c866；路径使用 Cascadia Mono，正文 Microsoft YaHei UI，标题沿用系统显示字体。暗色由现有变量驱动。窄屏改为单列，按钮可换行，键盘焦点可见。

## 安全与错误处理

- 所有配置、探测与进程端点限超级管理员；写操作要求 JSON 并拒绝跨源请求。
- 使用绝对本机路径、参数数组、shell:false、windowsHide:true，不允许用户输入 shell 命令，不安装环境。
- 拒绝 UNC/远程共享启动路径和无效监听 IP；只探测 ComfyUI GET /system_stats（旧版可回退 GET /queue），不提交工作流。
- 启动前检查文件与端口；已运行但非本服务启动的实例只连接，不接管或终止。
- 进程创建后显示正在启动，探测成功才标记可用；启动超时、缺少依赖、端口占用均给出建议。
- 只结束当前持有句柄的子进程（Windows 同 PID 进程树），等待退出才允许重启；服务关闭时清理托管进程。
- 运行期间禁止修改启动配置；请求串行化，防止双击重复启动；限制返回日志和探测响应大小，不返回 API 密钥。

## 验收

隔离临时数据库、模拟 HTTP ComfyUI、子进程边界替身，验证配置迁移、路径推导、跨源/角色权限、连接失败分类、就绪状态、并发启动、停止归属、退出清理、工作流默认地址。用现有 Playwright 测试模式检查独立入口、API 排除、保存/测试/启动/停止、过期响应不覆盖输入、明暗主题和窄屏布局。不得启动用户真实 ComfyUI、写真实配置或调用付费 API。
