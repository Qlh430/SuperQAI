# 画布缩放范围设计

## 背景

无限画布当前在滚轮缩放时把比例限制在 25%–300%。大型画布包含较多节点时，25% 仍不足以一次查看整体布局；缩放边界还是事件处理器中的硬编码，后续恢复画布等入口难以共享同一规则。

## 目标

- 将画布缩放范围统一为 5%–400%。
- 允许通过滚轮缩小到 5%，方便查看大型画布全局布局。
- 保持以鼠标指针所在画布坐标为缩放中心，缩放时内容不发生跳动。
- 百分比提示正确显示 5%–400%。
- 保存并恢复处于新范围内的缩放比例。

## 非目标

- 本次不增加缩放滑块、加减按钮或“适应全部”按钮。
- 不改变节点尺寸、连线、图片清晰度策略或画布平移操作。
- 不改变“复位”行为；复位后仍为 100%。

## 设计

在画布模块中定义统一的最小、最大缩放常量：

- 最小比例：`0.05`（5%）
- 最大比例：`4`（400%）

滚轮缩放继续使用现有的渐进倍率，并通过统一边界限制最终比例。缩放前后仍以指针下方的画布坐标重新计算平移量，从而保持鼠标锚点不变。

恢复已保存画布时，对读出的比例进行数值校验并限制到同一范围：范围内的值原样恢复；旧数据中小于 5% 或大于 400% 的值分别归一到 5% 或 400%；非数字值回退到 100%。保存结构不变，继续写入 `viewport.scale`。

百分比提示沿用现有取整显示，因此边界分别显示为 `5%` 和 `400%`。复位视图继续设置为 `1`。

## 错误与兼容处理

- 缺少缩放值：恢复为 100%。
- 非有限数字：恢复为 100%。
- 超出新范围的历史值：限制到最近边界。
- 已处于 5% 或 400% 时继续向外滚动：比例保持边界值，画布不越界。

## 测试

增加聚焦检查覆盖以下行为：

1. 统一缩放边界为 5%–400%。
2. 滚轮缩放使用统一边界，而不是旧的 25%–300% 硬编码。
3. 保存画布恢复时使用同一范围，并正确处理无效值。
4. 复位仍回到 100%。
5. 现有项目完整检查继续通过。

## 验收标准

- 用户可连续缩小到 5%，提示显示 `5%`。
- 用户可连续放大到 400%，提示显示 `400%`。
- 无法缩放到范围以外。
- 缩放过程中鼠标指向的画布位置保持稳定。
- 重新打开画布后，5%–400% 范围内的比例被正确恢复。
- 复位视图仍为 100%。
