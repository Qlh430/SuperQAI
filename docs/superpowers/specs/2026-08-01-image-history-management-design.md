# 在线生图历史管理与控件修复设计

## 背景

在线生图界面当前有三类问题：尺寸行的分辨率下拉框被固定在 72px 宽的网格列中，同时保持 `overflow: visible`，导致“最大方图 2880×2880”越出参数卡片；深色模式提示词框继承了亮色主题的白色顶部内阴影；图片历史记录仍使用无确认的一键清空。

浏览器计算样式已经确认：分辨率控件宽度为 72px，尺寸行列宽为 `42px 170px 72px`，提示词框最终 `box-shadow` 为 `rgba(255,255,255,.85) 0 1px 0 inset`。现有历史接口已经支持按记录 `id` 删除，因此不需要修改服务端数据格式。

## 已确认方案

采用“管理 → 多选图片 → 删除所选”的管理模式，并使用整张历史卡片作为选择热区。

正常模式下，“管理”按钮位于历史标题右侧，历史卡片点击行为仍是恢复提示词并打开图片预览。进入管理模式后：

- “管理”按钮变为“取消”；
- 顶部显示“已选 N 张”和“全选”；
- 每张卡片显示圆形勾选标记，点击卡片只切换选中状态，不打开预览；
- 选中卡片使用黄色边框、浅黄色表面和勾选标记共同表达状态；
- 底部显示“删除所选（N）”，未选择记录时禁用；
- 第一次点击删除只展开原地确认条，显示“确定删除 N 张？”以及“取消 / 确认删除”；
- 只有点击“确认删除”才按记录 `id` 执行删除；删除请求串行发送，避免多个请求同时改写同一历史文件；
- 删除成功后退出管理模式，刷新在线生图历史和统一历史；失败时保留可理解的状态提示并刷新当前列表。

## 布局与视觉

- 尺寸行保持“标签 / 比例 / 分辨率”三列，但第三列调整为 116–128px，并为选择器设置 `min-width: 0` 与 `width: 100%`，保证窄控制卡内不溢出。
- 深色模式下明确将提示词框 `box-shadow` 重置为 `none`，保留既有边框和焦点环。
- 历史面板在管理模式下增加两条紧凑工具栏：顶部选择摘要、底部删除操作；图片列表继续占据中间可滚动区域。
- 管理控件沿用暗房工作台的暖黑表面、浅色文字和信号黄强调色，不引入新的弹窗或外部图标资源。
- 所有新增按钮提供可见的 hover、disabled 和 `:focus-visible` 状态；历史卡片使用 `aria-pressed` 暴露选择状态。

## 状态与边界

- 进入、取消或完成删除时清空本次选择与待确认状态。
- 选择发生变化时自动退出待确认状态，防止确认文案与实际选中数量不一致。
- 没有图片历史时仍可进入管理模式，但删除按钮保持禁用；“全选”不会产生错误。
- 记录缺少 `id` 时在管理模式下不可选，但正常预览不受影响。
- 管理模式不改变历史记录保存、预览、生成图片、统一历史或其他工具页面的行为。

## 验证

- 新增静态回归检查，覆盖 DOM 管理控件、管理状态、串行按 id 删除、无清空调用、尺寸列宽和提示词框阴影重置。
- 运行新增检查并先观察其因功能缺失而失败，再实现最小改动使其通过。
- 运行 `npm run check` 和 JavaScript 语法检查。
- 在 2048×1024 深色黄黑主题的真实浏览器中验证：分辨率控件不越界、提示词框无白线、管理/选择/全选/取消/删除确认状态正确，首次点击删除不产生 DELETE 请求。

## 验收标准

- “最大方图”文字和控件完整位于参数卡片内。
- 深色提示词框顶部没有白色条纹，焦点状态仍清晰。
- 历史标题右侧不再出现“一键清空”，而是“管理”。
- 管理模式下整张卡片可勾选，普通模式下仍可打开历史预览。
- 未确认前不会发送删除请求；确认后只删除选中的记录。
- 新增检查、完整检查和浏览器控制台验证无新增错误。
