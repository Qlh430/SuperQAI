# 在线生图结果信息分离标签设计

## 目标

移除生成图片底部横跨整张图片的信息条，只保留左右两端真正有内容的紧凑标签，让图片中间区域保持完全可见。

## 范围

- 仅调整在线生图 `#imageView` 内结果卡片的 `figcaption` 展示方式。
- 保留现有结果编号、尺寸、预览和下载内容与行为。
- 不改变高清放大、换鞋、扩图等其他工具的结果卡片布局。

## 设计

- `figcaption` 本身变为透明、无边框、无阴影的定位层，不产生可见横条。
- 左侧第一个 `span` 独立成为左下角紧凑标签，显示“结果 N · 宽×高”。
- `.image-actions` 独立成为右下角紧凑操作标签，继续显示“预览”和“下载”。
- 两个标签分别使用主题化半透明背景、细边框与轻量阴影；中间区域没有背景、边框或模糊效果。
- 定位层使用 `pointer-events: none`，两个真实标签恢复 `pointer-events: auto`，避免透明区域拦截图片点击。
- 标签保持常驻可见，不改成仅悬停显示，确保操作容易发现。

## 主题与响应式

- 浅色主题使用半透明 `var(--panel)` 与 `var(--ink)`。
- 深色主题使用半透明 `var(--darkroom-panel)` 与 `var(--darkroom-ink)`。
- 在窄宽度下允许左侧信息截断，右侧操作保持可点击；两个标签不得重新合并为整条横栏。

## 验证

- 静态回归检查确认 `figcaption` 无可见背景、边框和阴影，中间定位层不拦截鼠标。
- 静态回归检查确认左右标签分别绝对定位在底部两端，并拥有独立主题化背景。
- 浏览器实测确认信息条中间计算背景透明，左右标签尺寸只包裹内容，图片点击区域未被透明层拦截。
- 运行完整项目检查与 `git diff --check`。
