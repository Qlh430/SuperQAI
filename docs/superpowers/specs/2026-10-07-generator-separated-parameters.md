# 比例与分辨率分组修整

用户明确要求同一参数浮层内，比例和分辨率分成两组，比例行不能混入2K/4K；移除操作区底部默认待完成。保持现有 Neon/Flora 与44px控件规则，不增加参考图中的批量数量能力。

原生独立分辨率模型继续委托原尺寸/分辨率控件。旧像素预设模型按已有option提取比例及档位，比例去重，选择两组参数后映射回原像素option并触发change，保留原服务端请求与保存路径。当前比例没有某档位时禁用并提供中文原因；切比例尽量保留原档位，否则回退到该比例可用预设。自适应和自定义保留原行为，不能捏造原预设以外的分辨率。只移除默认待完成，不移除失败或生成中状态。

验收覆盖旧GPT图片模型与独立比例模型、映射像素请求、禁用、切换回退、自定义宽高、状态隐藏与错误保留，以及四宽度、焦点、悬停、全屏。构建后通过deploy.mjs备份部署，执行acceptance及生成节点回归，记录模拟接口边界。
