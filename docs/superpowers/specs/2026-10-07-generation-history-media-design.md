# 生成节点与历史记录

用户已确认执行以下设计：图片、视频和AI文本生成节点采用上方结果、选中后下方操作区；新增真实音频生成节点；图片结果保存在原节点且有独立历史面板，不自动另建图集。加载按钮持续动画，返回尺寸差异只作说明，不阻断结果显示或裁切。历史按节点保存，支持当前结果切换、下载、删除及全屏；已有图集的数据仍保留并兼容读取。

复用现有Neon语义令牌和Flora壳体、同源宿主接口。文本生成复用现有LLM节点，普通文本编辑节点保留双击编辑能力。视频API及ComfyUI/H3保留真实参数、任务查询和播放器。音频模型来自已保存且具有audio.generate能力的模型，协议按服务端配置执行；不虚构SeedAudio或音色库，只有实际协议支持的声音/格式/参数才显示。缺少模型、接口失败、权限失败均中文说明。

生成历史进入宿主画布节点JSON，文件/生成请求由服务端负责，禁止用localStorage保存。参考图保持连接，草稿切换/取消选中保留。桌面、移动端、默认/悬停/选中/焦点/全屏及成功失败状态均验收。
