# 文字工具与文件导入设计

用户确认的范围：文字节点增加背景色、放大编辑、Markdown 下载；文件拖入或粘贴到画布，每个文件独立形成图片、视频、音频或文字节点；文档支持 TXT、MD、DOCX、PDF，DOCX/PDF 提取正文；图片与视频选中显示统一绿色边框。

复用 Flora 浮动工具栏、语义色板、富文本编辑器和原有宿主上传/保存/撤销流程。文字放大界面复用同一编辑 DOM 与格式工具，关闭或 Esc 提交并回到画布，下载使用当前内容和节点名称。背景色按节点保存、复制恢复；背景选择不影响编辑格式。

文件导入按类型分派，编辑框内粘贴保持原行为，多文件各建一个节点；保留内部画布复制和图库拖动。文档浏览器内解析，只有文本结果经宿主保存；MD 保留 Markdown 语义，TXT/DOCX/PDF 按纯正文呈现。损坏、加密、扫描件无正文、超限或不支持格式必须显示中文错误，批次内成功项继续导入。切换画布后不向新画布写入旧导入结果。

媒体选中描边覆盖在媒体内容上方，使用原有主色、圆角和屏幕缩放规则，不改变原图比例或裁切内容。

设计自检：已明确四类文档和正文提取边界，不增加 OCR、原文件复杂版式复刻或云端文档上传功能。无需停止生产服务。
