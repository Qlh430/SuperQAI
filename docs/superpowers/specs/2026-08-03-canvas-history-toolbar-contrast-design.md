# 历史画布工具栏对比度设计

## 目标

提高历史画布面板中“新建画布”按钮的文字可读性，并让相邻的回收站图标更清楚、更协调，同时保持现有紧凑工具栏布局。

## 根因

- `.canvas-board-head span` 将标题区域内所有 `span` 统一设为弱化文字颜色，连带覆盖了 `#canvasBoardNew` 内部文字，因此按钮虽然使用主题强调色背景，文字仍显示为低对比度灰色。
- 回收站使用 17px、默认 1.8px 线宽的 `trash-2` 图标，在 38px 圆形按钮里视觉重量不足，深色界面下显得细小。

## 设计

- “新建画布”继续使用当前主题的 `--accent` 背景与 `--accent-contrast` 前景。
- 为按钮内部文字增加专用规则，使用 `color: inherit`，并设置 13px、800 字重，避免再次被标题区通用 `span` 规则覆盖。
- 回收站由 `trash-2` 换为轮廓更简洁的 Lucide `trash` 图标。
- 回收站图标设置为 20px、2.2px 线宽；按钮仍为 38px 圆形，不改变工具栏整体尺寸。
- 回收站默认、hover、active 与键盘焦点继续使用主题变量；不写死黄色、蓝色或白色。

## 边界

- 不改变刷新、回收站、新建和关闭按钮的位置或功能。
- 不增加“回收站”文字标签，继续依靠 `title` 与 `aria-label` 提供说明。
- 不调整历史卡片、搜索框或其他工具栏。

## 验证

- 静态检查确认新建按钮文字继承按钮前景色，回收站使用 `trash`、20px 和 2.2px 线宽。
- 浏览器检查黄黑深色主题下按钮文字与背景具有明显对比，回收站图标尺寸和悬停反馈正确。
- 运行项目完整检查、JavaScript 语法检查与 `git diff --check`。
