# 640 像素预览与图片工具栏

用户已明确要求 640 预览、按需原图、顶部下载/删除/放大按钮、双击原图预览。沿用这些交互，不增加审批或更换整体画布设计。

DX OS canvas 1.0.46 的前端文件位于指定便携目录的 data/developer-apps/.versions/canvas/1.0.46+10046-1dc163b9/source/assets/index-CwAeND6_.js。jm 生成缩略图地址；xy 在可见图片显示最长边 >=320 或被选中时启用原图覆盖层；N8 给选中图片上方工具栏反向缩放；s8/fp 双击打开原图，b8 从原图下载。因此不照搬其较积极的原图门槛。

本软件当前 DETAIL_SCALE=1，且按整个节点尺寸判断图集成员，导致默认 100% 和大图集误触发原图。新规则：先显示缩略图；画布 >=200%、单张图片实际显示最长边 >640 CSS 像素、停止交互 300ms 后升级原图。选中图片不升级。查看/下载/裁剪明确使用原图。已加载原图保持到离屏卸载，避免反复解码。

服务端和浏览器备用预览统一最长边 640，保持比例、透明度和原图。仅 <=640 且 <=1MiB 的小图可直接复用。服务器缓存记录规格，旧规格在请求时更新。局域网本地图片缩略图缺失时，不隐式传输大原图进行浏览器缩略图制作。

独立工具栏模块在选中的单张图片上方显示原图预览、下载、删除；独立上传图片保留替换入口。图集只删除点击成员，记录撤销与相关连线操作。双击打开现有原图预览器。工具栏跟随位置，保持屏幕尺寸，切换选择/画布后隐藏。
