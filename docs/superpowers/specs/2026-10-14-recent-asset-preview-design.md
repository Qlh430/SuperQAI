# 最近素材直接全屏预览

用户要求：概览中的最近素材图片直接全屏预览，底部提供重命名、共享设置、删除、下载；视频沿用相同入口并支持播放。打开、关闭不切换到素材库。

复用 Neon Dialog、Button 与 AssetActions，新增共用 AssetPreview：概览使用全屏形态，素材库保持现有弹窗形态。媒体保持原比例，支持加载、中文错误与重试。操作依照服务返回的权限显示；修改使用现有宿主接口，关闭并刷新资源，首页名称、共享状态和删除结果同步。

预览与操作区独立分配空间；手机可换行，编辑区域可滚动。Esc/关闭恢复触发焦点，路由变化关闭预览。所有文字简体中文，视觉复用语义令牌，无新增存储、无真实上游调用。

验收：390/768/1440/1728 下图片和视频直接预览、保持概览路由、正确显示四个动作、图片完整显示、视频可播放、重命名/共享/删除与失败重试、下载内容、权限、加载/错误、焦点及页面溢出。使用独立 33199 端口和模拟 API，不读写真实用户数据。构建通过后通过 deploy.mjs 备份部署，再运行完整 acceptance.cjs。
