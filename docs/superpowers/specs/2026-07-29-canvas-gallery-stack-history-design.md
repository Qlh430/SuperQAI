# 画布生成图集堆叠封面与历史记录设计

## 背景

当前生成图集节点会把所有生成图片平铺在节点内，并将全部图片作为一个图片组输出给下游。随着历史结果增加，节点内容拥挤，也无法明确指定后续编辑使用哪一张图片。

本次改造将生成图集变成单张活动封面节点：节点主体显示当前图片和堆叠层，历史记录通过独立面板浏览，节点连接只输出当前图片。

## 目标

- 图集节点主体始终只展示一张活动图片。
- 使用 2–3 层错位卡片表达还有其他历史结果。
- 新生成图片自动成为活动封面。
- 用户可打开历史记录并选择任意旧图作为活动封面。
- 切换活动封面不改变历史记录的时间顺序。
- 下游节点只接收活动封面这一张图片。
- 旧画布中的图集数据自动兼容。

## 节点主体

图集节点保留输入端口、输出端口、标题栏和缩放能力。

有图片时，主体包含：

- 一张活动封面，使用 `object-fit: contain` 完整展示图片。
- 封面背后最多三层错位卡片，仅作视觉提示，不重复加载历史图片。
- 历史记录按钮，显示图集图标与图片总数徽标。
- 点击活动封面继续打开现有全屏预览，并从当前图片位置浏览整个历史列表。

空图集继续显示“生成后的图片会排在这里”。

节点宽高调整时，封面跟随可用区域缩放。堆叠层不得改变节点真实尺寸或连接端口位置。

## 历史记录面板

点击历史记录按钮后，在图集节点右侧打开面板。面板作为图集节点的浮动子层，随画布移动和缩放，不撑大节点本体。

面板包含：

- 标题“结果 · N”。
- 关闭按钮。
- 按生成时间倒序排列的历史列表，最新图片位于最上方。
- 当前活动图片的高亮和“当前”状态。
- 每项的完整缩略图、放大预览、下载和删除操作。

点击缩略图将该图片设为活动封面。面板保持打开，方便连续比较。点击面板外部、关闭按钮或按 `Escape` 关闭面板。

面板高度受画布视口限制，超出部分在面板内部滚动。面板操作必须阻止画布拖拽、连线和节点选择误触。

## 数据模型

每个图集图片对象规范化为：

```js
{
  id: "稳定且唯一的图片 ID",
  name: "生成图 N",
  src: "显示地址",
  savedUrl: "下载和下游使用地址",
  createdAt: "ISO 时间"
}
```

图集节点新增：

```js
node.dataset.galleryActiveImageId
```

画布序列化新增：

```js
galleryActiveImageId: "图片 ID"
```

恢复旧画布时：

- 为没有 ID 的历史图片补充稳定 ID。
- 如果没有保存活动 ID，选择数组最后一张，即旧逻辑中的最新结果。
- 如果保存的活动 ID 已不存在，同样回退到最新一张。

历史数组继续保持生成顺序，旧图在前、新图在后。UI 面板仅在渲染时倒序，不修改存储顺序。

## 状态变化

### 追加新图

1. 将带唯一 ID 的图片追加到历史数组末尾。
2. 将该图片 ID 设置为活动 ID。
3. 重绘节点封面和历史面板。
4. 刷新下游引用并保存画布。

### 选择历史图

1. 校验图片 ID 存在。
2. 更新活动 ID，不重排数组。
3. 重绘活动封面和当前状态。
4. 刷新所有下游节点，使其立即使用新图片。
5. 保存画布。

### 删除图片

- 删除非活动图片时，活动封面不变。
- 删除活动图片时，回退到剩余数组最后一张。
- 删除最后一张图片时进入空状态，图集不再向下游输出图片。
- 每次删除都刷新下游节点并保存画布。

## 连接输出

`getCanvasNodeOutput` 对生成图集返回单张图片：

```js
{
  type: "image",
  name: "活动图片名称",
  url: "活动图片 savedUrl 或 src"
}
```

不再返回 `type: "group"`。因此连接到生成、编辑、LLM 或 ComfyUI 节点时，只会产生一个参考图。切换活动图片后，下游缩略图和后续请求立即更新。

普通图片组节点和循环节点的多图输出行为保持不变。

## 预览、下载与拖拽

- 点击主封面从活动图片开始打开现有图集预览。
- 历史项的放大按钮打开同一预览器并定位该项。
- 历史项下载使用 `savedUrl`，没有时回退到 `src`。
- 现有从图集拖出图片到画布的能力保留：主封面可拖出当前活动图片；历史列表中的具体图片也可拖出。

## 错误与边界处理

- 无效或损坏的图片项在渲染和输出时跳过。
- 活动 ID 指向无效项时自动回退到最新有效图片。
- 图片加载失败时历史项仍保留名称和操作，不阻塞其他图片。
- 重复快速选择只以最后一次选择为准。
- 删除操作不得误触发选择、拖拽或预览。

## 验收标准

- 新图生成后自动显示在堆叠封面最上层。
- 图集有多张图片时显示堆叠层和正确数量徽标。
- 历史面板按最新到最旧排列，选择旧图后数组顺序不变。
- 选择历史图后主封面、当前高亮和下游参考图同步更新。
- 图集连接到下一个图片编辑节点时只传递活动图片。
- 删除活动图片后正确回退，删除全部图片后输出为空。
- 保存并重开画布后活动图片保持一致。
- 旧画布图集自动选择最后一张作为活动图片。
- 主封面和历史项继续支持预览、下载及拖出为图片节点。
- 页面无新增 JavaScript 错误，现有自动检查继续通过。
