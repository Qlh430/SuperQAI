# 画布 Agent 自然交互改造设计

## 背景与问题

当前右侧 Agent 在 Skill 列表加载后自动选中第一个 Skill，并在浏览器发送前校验 Skill 的素材要求。这导致普通问候也被解释为“产品精修”，没有图片时直接被前端拦截。画布选区使用 `.is-selected`，但 Agent 没有订阅选区变化，也只把 `getCanvasNodeOutput()` 返回的单张 `image` 当作视觉上下文；宫格、分组、循环等可见素材因此可能被忽略。

## 目标

- Agent 面板打开后无需选择 Skill 即可聊天或调用画布工具。
- Skill 是可选的专业流程；用户可手动锁定，也可让 Agent 自动判断。
- 画布选中项实时显示为输入上下文，发送时以实际节点 ID 和素材内容为准。
- 支持 `@` 搜索并引用未选中的画布节点。
- 支持从输入区上传、拖入或粘贴图片，素材先进入画布再自动成为上下文。
- 缺少素材时由 Agent 在对话中询问，不由浏览器硬拦截。
- 任何可能扣费的画布执行仍在首次执行前暂停确认；同一运行确认一次。

## 交互方案

采用“自动 Agent + 可选 Skill”方案。

### 默认状态

面板主区域只显示欢迎语、常用建议和会话，不再长期占用大块空间展示 Skill 列表。底部输入区始终可输入。状态文案为“Agent · 自动选择流程”，发送按钮只在输入为空或运行中禁用。

Skill 入口放在输入区工具栏的“技能书”按钮中。打开后显示五个内置 Skill。选择后，输入区上下文栏出现可移除的 Skill 标签；再次点击当前 Skill 或点击标签关闭按钮即可回到自动模式。

### 画布上下文

画布选择函数在选区变化后派发 `canvas:selectionchange` 事件。Agent 订阅该事件，并在输入框上方渲染最多 15 个上下文标签：图片显示缩略图，视频、文字、生成器和分组显示类型图标与名称。

发送时不信任缓存标签，而是重新读取 `.is-selected` 节点，并与 `@` 引用及输入区附件创建的节点合并去重。上下文标签可单独移除；移除当前画布选中项仅代表不发送给 Agent，不改变画布本身的选择。

### `@` 引用

当输入光标前出现 `@关键词` 时，在输入框上方显示可搜索节点列表。列表按“当前选区优先、最近画布顺序其次”排列，展示节点类型、名称和缩略图。点击条目后插入 `@名称` 文本，并把稳定节点 ID 加入显式引用集合。点击上下文标签的关闭按钮可以移除引用。

### 附件

输入区提供附件按钮和隐藏的多选图片输入。文件选择、拖放到输入区或在输入区粘贴图片时，复用画布现有上传与 `addCanvasImage()` 能力，在当前视口中心创建图片节点，选中新节点，并自动加入显式上下文。上传状态在上下文栏显示，失败时给出可重试错误，不发送半成品请求。

### Skill 与自动路由

请求使用 `skill_mode`：

- `auto`：默认。服务端向模型提供全部画布工具、Skill 摘要和内置工作流正文，要求只在需求匹配时采用相应流程；普通问候直接回答。
- `manual`：用户选择某个 Skill。服务端只提供该 Skill 声明的工具和完整说明。

两种模式都不在浏览器校验 `required_selection`。所需素材不存在时，模型必须先用自然语言说明缺少什么，不得虚构素材或盲目执行。

### 执行与确认

Agent 的创建、更新、连接和排列操作可直接执行。第一次出现 `run_canvas_node` 时暂停，显示本次将执行的生成数量和“确认并继续”。确认后仅对当前运行有效。重复执行同一节点仍被阻止，避免重复扣费。

## 技术设计

### 纯规则层

`canvas-agent-core.js` 新增引用规范化函数，将图片、图库活动图、宫格源图、分组/循环图片、视频、文字和生成器统一为 `{ nodeId, type, name, url, originalUrl }`。同一节点内的多张图片使用 `nodeId:index` 作为引用键，最大返回 15 项，视觉图片最多上传 3 张。

### 服务端运行层

`canvas-agent-runtime.js` 接受空 `skill_id` 和 `skill_mode: "auto"`。自动模式使用所有已注册工具的并集，并生成自动路由说明；手动模式保留现有严格白名单。continuation 请求沿用首次运行保存的 `skill_id` 与模式。

### 画布桥接

`script.js` 在 `selectCanvasNode`、`clearCanvasSelection`、`addCanvasNodeToSelection`、`toggleCanvasNodeSelection` 和框选完成后派发选择事件。宫格节点输出补充源图 URL，使其可被 Agent 作为视觉参考。现有函数行为和键盘选择规则保持不变。

### 面板层

`canvas-agent-ui.js` 管理三个独立集合：当前画布选区、显式 `@` 引用、用户排除项。渲染时合并并去重；发送后保留画布选区但清空本次显式引用。Skill 弹层和 `@` 弹层互斥，Escape 关闭弹层。

## 错误与边界

- Skill 加载失败不阻止自动聊天；界面显示“专业流程暂不可用”。
- API Key 未配置时仍可浏览上下文和 Skill，发送时显示配置错误。
- 被引用节点在发送前已删除时自动移除并提示。
- 跨域图片无法压缩时仍发送结构化节点信息，不因此中止整个请求。
- 自动模式不额外调用一次路由模型，避免增加首字延迟和成本。
- 单次运行继续受 12 回合上限约束。

## 验收标准

- 打开 Agent 后直接输入“你好”可以发送，且请求为自动模式。
- 没有选择 Skill 时，模型仍能依据需求创建和操作节点。
- 选择任意图片、图库、宫格或分组节点后，输入区在一次事件循环内出现上下文标签。
- `@` 可以搜索画布节点并加入引用。
- 输入区上传、拖入或粘贴图片后，画布创建图片节点并显示上下文标签。
- 手动 Skill 可选、可清除，不再自动选中第一个 Skill。
- 缺素材不被浏览器拦截，Agent 以对话方式询问。
- `run_canvas_node` 在确认前不执行，确认后继续。
- `npm run check` 与浏览器端关键路径验收均通过。
