# AI OS 全局外观与显示缩放设计规格

- 日期：2026-09-04
- 状态：用户已确认
- 视觉基准：用户提供的 DX OS“外观”设置截图
- 行为基准：对 `F:\DXOS-Portable-0.2.0-win-x64` 活跃运行时的只读审计

## 1. 目标

让“浅色 / 深色 / 自动”和“75% / 100% / 125% / 150% / 175%”成为真正的 AI OS 系统级设置。主题必须覆盖桌面背景、菜单栏、Dock、启动台、所有应用窗口、标题栏、侧栏、弹窗、表单、无限画布及其他现有业务应用内容；缩放必须覆盖整个 AI OS 桌面并保持窗口和应用交互坐标准确。

## 2. 已确认的根因

1. 当前 `system-settings.css` 使用 `--settings-sidebar` 等无作用域变量，与旧工作台主题变量重名。旧样式在级联中覆盖新设置页变量，因此选择浅色后仍出现深色侧栏。
2. 当前缩放通过 `html { font-size: calc(16px * var(--os-ui-scale)); }` 实现，只能影响 `rem` 尺寸，不能同步缩放菜单栏、Dock、像素尺寸窗口、间距和旧应用内容。
3. 窗口管理器仍以未缩放的 `innerWidth`、`innerHeight` 和原始指针位移计算边界。若只添加 CSS `transform`，窗口拖动、缩放和最大化会与指针错位。

## 3. 采用方案

采用与 DX OS 相同的系统级模型：

- 偏好存储使用离散的 `appearance` 和 `displayScale` 状态。
- AI OS 桌面根节点持有 `--system-scale`，使用 `transform: scale(var(--system-scale))` 和 `transform-origin: top left`。
- 根节点逻辑宽高使用 `calc(100% / var(--system-scale))` 反向补偿，使缩放后的可见桌面仍完整覆盖浏览器视口。
- 窗口管理器使用 `innerWidth / displayScale` 和 `innerHeight / displayScale` 得到逻辑视口。
- 窗口拖动和八方向缩放将物理指针位移除以 `displayScale` 后再更新逻辑几何。
- 不继续使用根字号缩放，也不调用浏览器缩放 API。

该实现复现 DX OS 的状态语义和交互算法，但不复制其品牌资源或打包后的实现代码。

## 4. 全局主题架构

### 4.1 系统主题状态

系统保留三种选择：`light`、`dark`、`system`。`system` 通过 `prefers-color-scheme` 解析为实际浅色或深色；操作系统主题变化时实时更新。

`html[data-theme]` 是全局实际主题的唯一事实来源。设置页不再建立一套可能覆盖全局状态的主题系统。

### 4.2 系统语义令牌

在桌面壳定义两套完整的语义变量，包括：

- 桌面背景与光晕；
- 菜单栏、Dock、启动台和窗口玻璃材质；
- 主背景、次级侧栏、卡片、浮层和输入框；
- 主文字、次文字、边框、阴影、焦点色和危险色。

所有新桌面组件和系统设置只读取这些语义变量。设置页专用变量必须限定在 `.ai-os-settings-layout` 作用域内，并改用不会与旧样式冲突的名称。

### 4.3 旧应用兼容层

现有无限画布、生图、AI 对话、历史记录、共享文件和账户管理仍含有旧颜色变量。新增一个位于现有样式之后的 AI OS 主题兼容层，在 `html[data-theme="light"]` 与 `html[data-theme="dark"]` 下映射旧变量和高优先级组件颜色。

浅色模式不得保留黑色侧栏或深色表单；深色模式不得出现大面积未主题化白底。应用自身有明确业务语义的内容颜色（图片、视频、画布对象、状态色）不被强制反色。

### 4.4 无限画布统一主题

无限画布不再提供或保存独立的“画布主题”。画布工作区、网格、工具栏、节点、浮层、生成器和历史记录全部读取系统实际主题，与桌面及其他应用同步切换。

设置页删除“画布主题”控件。偏好规范化过程兼容读取旧账号中的 `canvas.theme` 字段，但不再返回、保存或应用该字段，避免旧数据阻止升级。

## 5. 全局缩放架构

### 5.1 显示比例

仅允许 DX OS 同款五档：`0.75`、`1`、`1.25`、`1.5`、`1.75`。非法或损坏值回退到 `1`。

登录页不应用账号缩放，以保证任何账号都能可靠登录。登录成功并载入账号偏好后，缩放应用到 `.ai-os-desktop`；退出登录后恢复未缩放登录页。

### 5.2 根画布布局

桌面根节点使用逻辑尺寸：

```css
.ai-os-desktop {
  --system-scale: 1;
  width: calc(100% / var(--system-scale));
  height: calc(100% / var(--system-scale));
  transform: scale(var(--system-scale));
  transform-origin: top left;
}
```

菜单栏、窗口层、启动台和 Dock 全部位于该根节点内，因此一起缩放。页面背景继续覆盖物理视口，并跟随全局主题。

### 5.3 窗口坐标

窗口状态继续保存逻辑像素，避免切换比例时破坏几何数据。以下路径必须使用当前比例：

- 可用桌面宽度：`innerWidth / scale`；
- 可用桌面高度：`innerHeight / scale - MENU_BAR_HEIGHT - DOCK_HEIGHT`；
- 拖动或缩放位移：`(currentClient - startClient) / scale`；
- 浏览器尺寸或比例变化后调用窗口管理器重新约束全部窗口；
- 最大化、居中、级联和屏幕边缘限制全部基于逻辑视口。

### 5.4 应用内部交互

浏览器基于 `getBoundingClientRect()` 的命中和归一化计算通常已经处于物理坐标系，不额外重复换算。对于直接把 `clientX/clientY` 差值写入 CSS 像素或画布世界偏移的路径，统一通过系统坐标辅助函数除以全局比例。重点验证无限画布平移、节点拖拽、节点缩放、选框和浮动菜单定位。

## 6. 设置页视觉

外观页按用户提供的 DX OS 截图重做缩放选项：

- 五列等宽布局；
- 每项使用带红黄绿交通灯、标题和文本线条的微型窗口预览；
- 预览内部密度由 `--scale-preview` 表达对应比例；
- 选中项显示蓝色描边、柔和焦点环和蓝色文字；
- 窄屏时允许自适应换行，但不改变五档数值和语义。

预览只使用界面组件和现有系统颜色，不引入外部图片资源。

## 7. 数据流与持久化

```text
登录账号
  → GET /api/preferences
  → normalizePreferences
  → 解析实际主题
  → 写入 html[data-theme] / html[data-ui-scale]
  → 写入桌面 --system-scale
  → 更新窗口管理器逻辑视口
  → 重绘桌面和应用
```

用户点击主题或比例后，前端先通过既有 `PATCH /api/preferences` 保存；服务端返回规范化偏好后再统一应用。刷新、重新登录和同账号其他浏览器会读取该账号的保存值。不同账号互不共享主题和缩放设置。

本地 `ai-theme-mode` 只用于登录完成前避免主题闪烁，不替代服务端账号偏好。

## 8. 错误处理

- 偏好接口失败时保留当前可用主题和 100% 比例，并显示现有非阻塞提示。
- 无效比例、空值或旧版 `2` 值统一规范化为支持的最近安全值；本阶段固定回退为 `1`。
- `matchMedia` 不可用时，`system` 回退浅色。
- 比例变化不得清空、重建或关闭应用窗口。
- 若窗口几何在新逻辑视口外，窗口管理器将其收回可见区域，而不是删除账号布局。

## 9. 测试与验收

### 9.1 自动化测试

1. 主题切换会更新全局 `data-theme`，且浅色、深色和自动均正确解析。
2. 设置页变量不再与旧 `--settings-sidebar` 变量冲突。
3. 五档比例正确规范化、保存并写入 `--system-scale`。
4. 根桌面包含宽高补偿和整体 `transform`，不再通过 `html` 根字号缩放。
5. 75%、125%、150% 和 175% 下逻辑视口计算正确。
6. 缩放后的窗口拖动和八方向缩放使用反算后的指针位移。
7. 切换比例和浏览器尺寸后，窗口保持在可见区域且账号布局仍使用逻辑像素。
8. 设置页不再显示独立画布主题，无限画布背景、网格、工具栏和节点面板跟随全局主题。

### 9.2 浏览器验收

在与参考图一致的桌面尺寸下分别验证：

- 浅色模式中设置侧栏、桌面壳和全部已注册应用均无残留暗色结构；
- 深色模式中全部系统界面一致切换；
- 五档预览外观、间距、选中态与 DX OS 截图一致；
- 75%、100%、125%、150%、175% 均真实改变整个 AI OS；
- 每个比例下窗口拖动、缩放、最大化、Dock 和启动台操作准确；
- 无限画布平移、节点拖动及基本命中没有比例偏差；
- 无限画布与桌面在浅色、深色和自动模式下保持统一，不存在独立主题入口；
- 刷新和重新登录后恢复当前账号设置。

最终必须生成或更新项目根目录 `design-qa.md`，对照用户截图完成视觉检查；P0、P1、P2 问题全部修复后才能交付。

## 10. 不在本次范围

- 不改变浏览器自身缩放级别或 Windows DPI 设置。
- 不新增主题颜色自定义、壁纸上传或更多缩放档位。
- 不重写无限画布业务引擎，也不拆分现有 legacy DOM adapter。
- 不复制 DX OS 的商标、图标、图片或其他品牌资产。
