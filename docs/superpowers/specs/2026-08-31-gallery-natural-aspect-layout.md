# 图集原比例拼贴布局

图集内的每张图片保持源图比例：不裁切、不在图片周围添加边框、圆角、内边距或列间距。

成员使用零间距的多栏流式布局，栏宽保持 120px；横图与竖图按自然高度排列，图集节点高度由实际图片内容撑开。保留现有的标题、裁切入口、拖拽，以及每张图片的输入/输出连接点。

列分配按已记录的源图尺寸一次性确定，不使用浏览器会在图片加载时重新平衡的多栏算法。图集图片也进入画布的按需清晰度队列：移动或缩放时先显示缩略图，停止交互后按可见性升级为原图。

图集只保留一个总输入点。成员输入点不显示；当图集中有两张或更多图片时，每张图片显示独立输出点，并以 16px 横向、14px 纵向间隙留出辨识空间。单图图集只显示图集总输出点；旧的单图成员输出连接自动复用该总输出位置。
