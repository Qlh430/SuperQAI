# 画布中键平移与 500% 缩放设计

## 背景

无限画布当前仅支持在空白区域按住鼠标左键平移。当画布放大、图片节点铺满视口时，用户无法从图片上直接拖动画布。同时，现有缩放范围为 5%–400%，不足以检查更细的图片局部。

## 目标

- 按住鼠标中键时，可从画布任意位置拖动画布，包括图片、视频、节点控件等区域。
- 中键平移不选中、不移动节点，也不清除当前节点选择。
- 保持空白区域左键平移、节点左键拖动、Ctrl 框选、滚轮缩放等现有交互不变。
- 将画布缩放范围调整为 5%–500%。
- 阻止中键操作触发浏览器自动滚动或其他默认行为。

## 交互设计

### 中键平移

画布视口在捕获阶段的 `pointerdown` 中优先识别 `event.button === 1`。中键按下后直接进入画布平移并立即停止该事件的后续监听器和传播，跳过节点选择、节点拖动、文字失焦和框选分支；即使直接点中视口本身或节点内部控件，中键仍能可靠生效。平移沿用现有视口坐标更新与保存机制：移动期间更新 `canvasState.x/y`，结束时保存当前视口。

中键按下、拖动和释放期间阻止浏览器默认行为；在视口上拦截中键 `auxclick`，避免自动滚动或中键点击副作用。现有左键平移函数扩展为接受左键和中键；独立的捕获阶段监听器保证中键具有最高优先级，普通左键事件分发保持不变。

### 缩放范围

统一缩放上限常量从 `4` 调整为 `5`。滚轮缩放、历史画布恢复以及所有调用 `normalizeCanvasScale` 的入口自动共享 5%–500% 边界。缩放锚点算法不变，仍保持鼠标指针下方的画布位置稳定。

### 提示文案

画布快捷操作提示增加“中键拖动画布”，让功能可被发现，不新增按钮或设置项。

## 事件优先级

1. 中键按下：始终平移画布，不处理节点操作。
2. 左键按下节点：保持原有选择和节点拖动。
3. Ctrl + 左键空白：保持原有框选。
4. 左键按下空白：保持原有画布平移。
5. 其他鼠标键：不启动画布平移。

## 测试与验收

- 自动化检查确认缩放常量为 5% 和 500%，并验证 `normalizeCanvasScale(5)` 保留、超过 5 时限制为 5。
- 自动化检查确认视口 `pointerdown` 在节点分支前识别中键并调用画布平移。
- 自动化检查确认中键不会进入节点拖动分支，且视口拦截中键 `auxclick`。
- 自动化检查确认画布提示包含“中键拖动画布”。
- 运行脚本语法检查与完整 `npm run check` 回归。

## 非目标

- 不改变触控板、触摸手势和滚轮缩放倍率。
- 不新增空格键平移模式。
- 不修改节点自身的缩放或图片原图加载策略。
