# Auto 画幅与自动尺寸同步设计

日期：2026-07-29

状态：已确认

## 目标

当 OpenAI image 节点或主生成表单的画幅切换为 `Auto` 时，分辨率必须自动选择“自动尺寸”，避免停留在 `1K（不可用）` 等无效状态。

## 交互规则

1. 画幅从任意具体比例切换为 `Auto` 时，分辨率立即切换为 `auto`。
2. 分辨率下拉框继续显示：
   - `自动尺寸`：选中、可用。
   - 已配置的 `1K / 2K / 4K`：可见但灰置，用于解释 Auto 不保证具体输出档位。
3. 生成按钮保持可用，不显示错误态。
4. 从 `Auto` 切回具体画幅时：
   - 优先选择此前在该具体画幅下使用的合法标准档位。
   - 没有可恢复值时选择第一个合法配置档位。
   - 不自动选择精确替代尺寸。
5. Google nano-banana 维持现有模型家族规则，不套用 OpenAI 的 Auto 同步逻辑。

## 数据与请求

- UI 中的自动尺寸值为 `auto`。
- OpenAI 请求发送 `size: "auto"`，分辨率不伪装成 `1K / 2K / 4K`。
- 服务端继续接受 `auto + auto`，拒绝 `auto + 1K/2K/4K`。

## 测试

- 节点：`1:1 + 1K` 切换到 `Auto` 后选中“自动尺寸”，生成按钮可用。
- 主生成表单执行相同行为。
- 下拉框中的标准档位仍然可见且禁用。
- 切回具体画幅后恢复合法档位。
- Google 模型行为不变。
