# AI OS Electron 便携版

用户要求发布根目录与 DX OS 一样简洁，可直接运行，现有功能和源码开发继续保留。旧部署是项目文件夹，包含 `data` 与 `.env`。

## 发布结构

根目录仅包含 `AI OS.exe`、`.ai-runtime`、`data`、`ai-os-portable.json`。启动器启动 `.ai-runtime/versions/<版本>/AI OS Runtime.exe`，后者使用 `resources/app` 中的现有应用代码。单独随包携带兼容的 Node 24 运行后端，避免部署电脑 Node 版本差异影响 SQLite、图片处理及工作线程。

发布包由当前工作区构建，源码位置、npm 开发命令、浏览器与局域网访问保持兼容。开发工具和用户凭据不进入公开包。使用新目录构建，禁止清除已有发布目录里的用户数据。应用资源与数据分开；更新通过新包导入旧目录实现，旧包保留用于回退。不在本次加入在线自动更新。

## 数据和迁移

便携版所有持久数据位于同级 `data`：旧 `data` 内容直接导入，旧 `output` 导入 `data/output`，旧 `.env` 导入 `data/.env`，旧自定义工作流导入 `data/workflows`。Electron 配置位于 `data/.desktop`，临时文件位于 `data/.tmp`，诊断和迁移报告位于 `data/.logs`。

首次启动在创建数据库前提供“迁移旧项目 / 全新使用”。迁移要求关闭旧服务，选择旧项目根目录，在临时区域完成复制、流式哈希和 SQLite 完整性检查后发布。数据库 WAL 一并处理；接口加密主密钥与数据库一起迁移。拒绝覆盖已有业务数据，拒绝目录交叉、符号链接以及复制期间变化的来源。失败清理本次创建的文件，保留源目录。机器专属网络学习状态重新生成。旧目录中显式外部数据位置不能静默遗漏。

新旧版本可各自在自己的目录和数据副本上运行，端口冲突沿用现有回退机制。回退到旧目录使用其旧数据副本，不承诺旧代码能打开已升级数据库。

## 画布性能

目录整洁不改变逐帧渲染成本。AI OS 已使用 Electron；DX OS 当前运行时版本为 38.8.6，AI OS 为 44.1.1，不能凭版本直接断定速度。保留硬件加速默认设置，记录实际 GPU 功能状态及 Chromium/Node 版本，在打包后验证画布交互、图片加载和窗口缩放。沿用现有渲染回归；性能结论区分合成场景与用户画布。不通过关闭浏览器安全机制或盲目强制 GPU 开关提升分数。

## 验收

- 双击根目录 exe 在无外部 Node 依赖的路径启动；根目录保持四项。
- 实际 Electron 进程加载打包资源，所有业务写入同级 data；中文、空格和移动目录后可运行。
- 临时旧项目迁移后账号、接口密钥、画布、历史、媒体与工作流可读，源文件不变。
- 重复导入、来源变化、数据库损坏、路径交叉、已有目标数据均有明确处理。
- 开发启动检查、打包依赖检查、核心画布与图片交互回归通过。
- 最终 ZIP 不含真实用户数据与凭据；迁移说明提供关闭旧服务、导入、更新和回退步骤。
