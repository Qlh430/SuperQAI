# 在线生图预览简化设计

## 目标

让在线生图的空状态更简洁，并移除生成结果周围影响观看的白色区域，同时确保图片完整显示、不被裁切。

## 范围

- 在线生图空状态初始内容。
- 点击“清空图片结果”后恢复的空状态内容。
- 在线生图结果卡片、图片衬底和底部结果信息条的视觉样式。
- 不改变图片生成、保存、历史记录、预览和下载逻辑。

## 设计

### 空状态

空状态只显示“图片预览”。删除“生成结果会显示在这里，并自动保存到本地 output 文件夹。”说明文字。初始 HTML 与清空按钮动态恢复的 HTML 必须保持一致。

### 结果展示

- 图片继续使用 `object-fit: contain`，保证完整画面可见。
- 结果卡片和图片元素的背景改为透明，让宽高比以外的空间显示预览区域本身的深色纹理。
- 去掉结果卡片的浅色画布感和不必要的浅色阴影。
- 底部结果信息条使用深色半透明背景与浅色文字，保留结果编号、尺寸、预览和下载操作，但不形成白色横条。
- 不使用 `object-fit: cover`，避免裁切生成内容。
- 不增加模糊背景、动画或新的交互行为。

## 可访问性与主题

- 信息条文字与操作按钮保持足够对比度。
- 浅色主题沿用透明卡片并使用主题化信息条；深色主题明确使用深色半透明信息条。
- 空状态仍保留可被辅助技术读取的“图片预览”文本。

## 验证

- 静态回归检查确认在线生图空状态不再含有 output 文件夹说明。
- 静态回归检查确认结果图片继续使用 `contain`，且卡片、图片背景不再为白色或浅灰色。
- 浏览器中注入一张非画布同比例图片，确认两侧露出深色预览背景、图片完整显示、底部信息条不为白色。
- 运行项目完整检查与 `git diff --check`。
