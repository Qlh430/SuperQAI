# 画布生成完成提示音设计

## 目标

画布中的图片、文字、ComfyUI、API 视频、H3 视频和音频生成成功后播放一次短促低音量提示音，帮助用户在等待异步任务时知道结果已回到节点。

## 交互

- 只在结果成功写入节点后播放；校验失败、请求失败、取消、超时和仅开始任务不播放。
- 每次生成任务最多播放一次，即使结果恢复、轮询回调或历史同步重复进入成功路径。
- 不新增按钮、设置项或视觉状态；现有完成状态、结果卡片和历史记录保持不变。
- 音频上下文在用户点击生成时唤醒，成功时发出短促双音；浏览器禁止播放时静默跳过，不影响生成结果。

## 实现边界

画布桥接提供小型 `CanvasGenerationSound` 服务，维护 AudioContext 和按任务/节点的去重标记。各生成成功回调调用同一个 `playComplete` 接口；音频生成组件通过既有 `onResult` 回调接入。声音参数使用 Web Audio 合成，不增加资源文件或网络请求。

## 验收

回归覆盖各成功类型至少一次、同一任务重复回调只响一次、失败不响、没有 AudioContext 时不抛错，以及四种宽度工作台无 pageerror/横向溢出。真实付费生成不执行。
