# 画布 Agent 用户消息视觉设计

## 目标

让用户消息采用成熟 AI 聊天产品常见的克制、中性表达，删除多余身份标签，避免高饱和强调色和白字形成突兀的小色块，同时兼顾浅色与深色主题。

## 视觉方向

采用“中性浮层气泡”而不是品牌强调色气泡：

- 用户消息右对齐，保留与 Agent 回复的方向区分。
- 用户消息不渲染“你”标签；辅助技术通过 `aria-label` 保留“用户消息”语义。
- 气泡宽度随内容自然增长，短文本保持横向舒展，长文本限制在消息区宽度的约 82%。
- 圆角为克制的软矩形，右下角略小，形成轻微的说话方向感。
- 不使用黄色、蓝色等主题强调色作为用户气泡底色，避免切换配色后消息历史整体变色。

## 主题规范

### 深色模式

- 背景使用中性石墨灰半透明层。
- 正文使用柔和浅灰而非纯白。
- 使用低对比浅色描边和轻微内高光，不能出现明显发光或重阴影。

### 浅色模式

- 背景使用偏暖的浅灰白，与页面纯白背景形成稳定层级。
- 正文使用深石墨色。
- 使用低对比灰色描边和轻微下投影，不能像表单输入框或按钮。

## Agent 回复

本次不重构 Agent 回复布局。保留 Agent 标签与左对齐内容卡片，只微调用户气泡所需的共享选择器，避免影响工具步骤、确认卡片和等待动画。

## 交互与无障碍

- 消息内容、恢复按钮和对话持久化逻辑保持不变。
- 删除可见“你”标签后，在用户消息元素上设置 `aria-label="用户消息"`。
- 文本对比度应在浅色和深色主题下清晰可读。
- 不增加 JavaScript 动画，不影响画布拖动、缩放和消息滚动性能。

## 验收标准

- 用户消息中不再出现可见的“你”。
- 深色模式下不再出现黄色底白字气泡。
- 浅色模式下用户气泡与背景有清晰但克制的层级。
- 短消息不会收缩成过窄的竖向色块。
- 用户消息仍右对齐，等待动画和 Agent 回复仍位于左侧。
- 静态检查、Playwright 深浅主题视觉检查和全量回归通过。
