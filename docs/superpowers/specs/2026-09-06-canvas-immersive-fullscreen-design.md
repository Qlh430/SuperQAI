# 无限画布沉浸式全屏设计

## 目标

用户从项目首页打开某张画布时，AI OS 自动进入画布沉浸模式：隐藏系统顶栏、底部 Dock、应用窗口标题栏和其他桌面窗口，让画布从页面顶端铺到最底端。画布左上角提供两个明确动作：退出全屏但留在当前画布，以及保存后返回项目首页。

## 交互规则

- 项目首页保持普通应用窗口，不进入沉浸模式。
- 点击画布卡片、新建画布或通过共享资源直达画布时，进入编辑器并自动进入沉浸模式。
- 沉浸模式中隐藏 AI OS 顶栏、Dock、当前应用标题栏、窗口边框和其他应用窗口。
- 当前 Canvas 窗口不修改持久化尺寸与坐标，只通过临时桌面状态覆盖整个逻辑视口；退出时恢复进入前的窗口状态。
- 左上角第一个按钮为全屏切换：沉浸时显示“退出全屏”，退出后显示“进入全屏”。退出只恢复桌面框架，不离开当前画布。
- 左上角第二个按钮为“返回项目”：先退出沉浸模式，保存当前画布，再显示原项目首页，并保留范围、项目与搜索上下文。
- 编辑器右上角继续保留 Agent、资产库、新建画布、复位和清空等已有工具。
- 关闭、最小化、登出或会话失效时必须清除沉浸模式，避免桌面顶栏和 Dock 残留隐藏。

## 架构

Canvas 页面只负责表达内部页面状态，通过 `ai-os-app-immersive` 自定义事件向桌面 Shell 请求进入或退出沉浸模式。桌面 Shell 是窗口与桌面元素的唯一所有者，记录 `immersiveWindowId`，给目标窗口添加 `is-immersive`，并在根元素同步 `data-ai-immersive-app="canvas"`。

CSS 根据这一临时状态隐藏系统顶栏、Dock、其他窗口与当前标题栏，同时把窗口层和 Canvas 窗口扩展到 `inset: 0`。该方案不调用浏览器 Fullscreen API，不依赖权限提示，也不改变窗口管理器保存的几何尺寸。

Canvas 编辑器左侧增加独立的 `.canvas-editor-navigation`，与右侧 `.canvas-actions` 分离，避免资产库动态插入按钮后改变返回按钮位置。画布状态提示下移到导航栏下方，避免遮挡。

## 错误与恢复

- 请求进入沉浸模式但 Canvas 窗口尚不存在或已最小化时，桌面 Shell 忽略请求并保持普通桌面。
- 画布打开失败时，现有失败路径返回项目首页，同时退出沉浸模式。
- 关闭或最小化沉浸窗口时，桌面 Shell主动清除根状态；再次恢复不会错误保留全屏，重新进入画布可再次触发。

## 验收标准

1. 点击画布卡片后，根元素为 `data-ai-immersive-app="canvas"`。
2. AI OS 顶栏和 Dock 的计算样式不可见且不可交互。
3. Canvas 窗口边界覆盖整个逻辑视口，标题栏、边框、圆角和调整尺寸手柄隐藏。
4. 无限画布可视区域上边界和下边界分别贴合视口顶部与底部。
5. 左上角全屏按钮位于返回项目按钮左侧；两者均可键盘聚焦并有明确文本。
6. 退出全屏后仍在当前编辑器，系统顶栏、Dock 和原窗口几何恢复。
7. 返回项目后项目首页可见、编辑器隐藏、沉浸状态清除。
8. 浅色、深色及 75%、100%、125%、150%、175% 缩放均不破坏边界和按钮可用性。

## 非目标

- 不调用浏览器或 Electron 原生 Fullscreen API。
- 不修改数据库、画布持久化、共享权限或资产库数据。
- 不重做 Canvas 右侧工具栏。
- 不修改 `.git` 或执行提交。
