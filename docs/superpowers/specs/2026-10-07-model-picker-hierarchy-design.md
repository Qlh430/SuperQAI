# 画布模型列表层级

依据用户要求区分当前选中模型、平台与模型，沿用现有Neon/Flora浮层。

- 当前选项使用primary文字和primary低透明度表面，自动选择同样处理；仍无说明或选中勾标。
- 平台标题12px muted字，模型14px普通文字；模型内容相对平台缩进8px，平台组间使用现有border细线与8px间距。
- 沿用44px目标、8px行圆角、焦点环与分组折叠。仅改Flora浮层的规范源CSS，不影响其他列表、选择ID或服务商同步。
- 使用既有生成节点浏览器专项检查四宽度、缩放、选择切换、键盘、折叠、全屏及移动状态；构建后deploy.mjs备份部署，部署后执行acceptance.cjs。

这是用户已明确授权的视觉修整，实施中的颜色和层级取自现有设计系统。
