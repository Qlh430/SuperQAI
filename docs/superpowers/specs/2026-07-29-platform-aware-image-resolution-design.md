# 平台感知的图片分辨率交互设计

日期：2026-07-29
状态：交互方向已确认，等待规格复核

## 1. 目标

让“API 接入设置中的模型能力”和“画布节点当前组合是否可生成”同时清晰可见：

- 设置页的 `1K / 2K / 4K` 表示该接入实例声明支持的全局输出档位。
- 节点中的可选状态由接入实例、平台、模型族、画幅和输出档位共同决定。
- 不再通过隐藏选项表达限制。
- 不再把不支持的标准档位静默替换成另一个尺寸。
- OpenAI image 与 Google nano-banana 使用各自的官方规则。

## 2. 非目标

- 不改变用户已保存的 API 接入、平台选择和分辨率标签。
- 不自动探测第三方中转站未公开的私有限制。
- 不把 Google 的 `image_size` 规则转换成 OpenAI 的像素规则，反之亦然。
- 不在本次改动中新增价格计算或批量任务策略。

## 3. 官方规则基线

### 3.1 OpenAI image / `gpt-image-2`

OpenAI 接受满足以下约束的任意 `size`：

- 最长边不超过 `3840px`。
- 两条边都是 `16px` 的倍数。
- 长短边比例不超过 `3:1`。
- 总像素在 `655,360` 至 `8,294,400` 之间。

官方常用尺寸包括 `2048×2048`、`2048×1152`、`3840×2160` 和 `2160×3840`。因此：

- `1:1 + 4K` 若解释为 `3840×3840`，超过总像素上限，不能请求。
- OpenAI 限制内最大的正方形是 `2880×2880`，但它必须明确显示为精确尺寸，不能继续标成标准 `4K`。

来源：[OpenAI Image generation — Size and quality options](https://developers.openai.com/api/docs/guides/image-generation#size-and-quality-options)

### 3.2 Google nano-banana

Google 使用 `aspect_ratio` 与 `image_size` 两个独立字段，且 `image_size` 必须使用大写 `K`。

- Gemini 3.1 Flash Image：支持 `512 / 1K / 2K / 4K`，并支持包含 `1:1` 在内的官方画幅矩阵；`1:1 + 4K` 为 `4096×4096`。
- Gemini 3 Pro Image：支持 `1K / 2K / 4K`；`1:1 + 4K` 为 `4096×4096`。
- Gemini 2.5 Flash Image：只有官方表格列出的约 1K 输出，不提供 `2K / 4K` 档位。
- Gemini 3.1 Flash Lite Image：只支持 `1K`。

来源：[Google Gemini 图片生成 — 宽高比和图片大小](https://ai.google.dev/gemini-api/docs/image-generation?hl=zh-cn#aspect-ratios-and-image-size)

## 4. 核心设计决策

采用“保留、灰置、解释、显式替代”的交互：

1. 只展示该 API 接入实例在设置中勾选的分辨率档位。
2. 当前平台/模型族/画幅不支持的档位仍然显示，但灰色不可选。
3. 灰色项在名称中直接说明原因，例如：
   - `4K（1:1 不支持）`
   - `2K（该模型仅支持 1K）`
4. 控件下方显示可见的辅助说明，不能只依赖原生下拉项的悬停提示。
5. OpenAI 存在合法的接近尺寸时，增加一个独立的精确尺寸选项：
   - `最大方图 2880×2880`
   - 其他画幅按原画幅比例计算满足全部 OpenAI 约束的最大尺寸，并在标签中显示实际宽高。
6. 精确尺寸是用户主动选择的请求，不是对 `4K` 的静默降级。
7. Google 官方支持 `1:1 + 4K` 时保持正常可选，不显示 OpenAI 的限制提示。

## 5. 节点交互

### 5.1 正常状态

示例：Google Gemini 3.1 Flash Image，接入设置勾选 `1K / 2K / 4K`，画幅为 `1:1`：

- `1K`
- `2K`
- `4K`

三个选项都可选，4K 请求使用 `aspect_ratio: "1:1"` 与 `image_size: "4K"`。

### 5.2 OpenAI 不兼容状态

示例：OpenAI `gpt-image-2`，接入设置勾选 `1K / 2K / 4K`，画幅为 `1:1`：

- `1K`
- `2K`
- `4K（1:1 不支持）`，灰色
- `最大方图 2880×2880`，可选

辅助说明：

> OpenAI 1:1 无法生成标准 4K；可使用最大方图 2880×2880，或切换到 16:9 / 9:16。

### 5.3 已选组合变为无效

当用户先选 `4K`，随后把画幅改成不兼容比例时：

- 保留一个明确的“当前组合无效”状态。
- 禁用生成按钮，直到用户选择合法档位、精确替代尺寸或兼容画幅。
- 不自动切换为 `2K`。
- 不自动发送 `auto`。
- 提示提供两个直接行动：选择推荐精确尺寸，或切换到兼容画幅。

### 5.4 接入实例隔离

同一个上游模型 ID 出现在多个 API 接入时，每个节点选项继续使用带 provider ID 的 client ID。能力、平台、模型族和分辨率配置均按接入实例读取，不能按裸模型名合并。

## 6. 兼容性规则层

新增单一纯规则入口，概念接口如下：

```js
getImageOutputCompatibility({
  platform,
  family,
  model,
  ratio,
  resolution,
  configuredResolutions,
})
```

返回：

```js
{
  supported: true,
  requestedSize: "3840x2160",
  reason: "",
  alternative: null,
}
```

或：

```js
{
  supported: false,
  requestedSize: null,
  reason: "OpenAI 总像素不能超过 8,294,400",
  alternative: {
    value: "2880x2880",
    label: "最大方图 2880×2880",
  },
}
```

规则按平台分派：

- `openai`：计算目标宽高并校验边长、16 倍数、比例和总像素。
- OpenAI 替代尺寸保持用户选择的画幅比例，在最长边和总像素上限内等比缩小，最后向下取整为 `16px` 的倍数；若取整后仍不合法，则不提供替代选项。
- `google`：根据识别出的 Gemini 图片模型族查询官方画幅/档位矩阵。
- 未识别平台：只使用接入配置的档位，不假定 OpenAI 或 Google 的专属限制；服务端仍保留上游错误。

前端和服务端应共享等价的规则与测试用例：

- 前端负责展示、灰置和阻止明显无效的操作。
- 服务端负责最终校验，防止旧画布数据或手工请求绕过限制。

## 7. 请求映射

### OpenAI image

- 标准合法尺寸：发送精确 `size`。
- 精确替代尺寸：发送用户明确选中的精确 `size`。
- 非法组合：本地阻止，不发送请求。
- 不再把非法 `4K` 自动缩小后仍按 `4K` 处理。

### Google nano-banana

- 发送官方 `aspect_ratio`。
- 发送大写 `image_size`：`512`、`1K`、`2K` 或 `4K`。
- 不套用 OpenAI 的 `3840px` 边长和总像素上限。
- 模型族不支持的档位在前端灰置，并在服务端拒绝。

## 8. 错误处理

- 前端提示使用用户可理解的原因，不直接暴露内部函数名。
- 第三方中转站若拒绝官方合法组合，保留其原始错误摘要，并提示检查该接入服务商的额外限制。
- 服务端校验错误返回结构化字段：

```json
{
  "error": "当前画幅不支持所选分辨率",
  "code": "IMAGE_SIZE_NOT_SUPPORTED",
  "alternative": "2880x2880"
}
```

## 9. 测试要求

### 接入隔离

- 两个 provider 使用相同裸模型 ID，但分辨率标签不同，节点结果必须互不污染。

### OpenAI

- `1:1 + 4K`：标准 4K 灰置，提供 `2880×2880`。
- `16:9 + 4K`：可选并映射为 `3840×2160`。
- 比例超过 `3:1`、非 16 倍数、像素超限：服务端拒绝。
- 无效组合不得回退为 `auto`。

### Google

- Gemini 3.1 Flash：`1:1 + 4K` 可选，映射为 Google 的 `1:1 / 4K`。
- Gemini 3.1 Flash：`512` 可选。
- Gemini 3 Pro：不显示 `512`。
- Gemini 2.5 Flash：只有 `1K` 可选。
- Google 请求使用大写 `K`。

### 交互

- 灰置项仍可见。
- 辅助说明随模型、平台、画幅变化。
- 旧画布载入无效组合时生成按钮被禁用。
- 切换 provider 后选项按该 provider 的配置刷新。

## 10. 迁移

前一版把不合法的 OpenAI 方形 4K 自动按像素上限缩放为 `2880×2880`。本设计将该行为改为：

- `4K` 保持不可选并解释原因。
- `2880×2880` 成为单独、显式、可选择的精确尺寸。
- 已保存的旧节点若包含 `1:1 + 4K`，载入后显示无效状态，不自动改写保存数据。
