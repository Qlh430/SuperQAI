# 可用模型批量移除

用户已要求给 API 服务编辑器中的可用模型增加多选、全选和批量删除；沿用已确认的草稿编辑结构和 Neon/Flora 规范。

- 每个可用模型卡片标题前增加44px勾选控件，勾选不展开模型配置。
- 列表上方增加全选、已选数量和移除所选；未选择时移除按钮禁用。全选包括当前草稿中的全部模型，不仅是屏幕内可见项；部分选择显示中间态，全选后再点击清空选择。
- 使用稳定模型ID选择，排序和配置不会改变选中项。新增模型默认不选，单项移除同步清理该ID的选择，批量移除清理展开状态及参数错误。
- 移除仅更改当前草稿，不触发保存、目录同步或上游请求。取消关闭放弃移除，保存连接后使用既有模型目录事件同步工作台与画布。
- 复用官方Button、Card、语义令牌及lucide图标，简体中文，可键盘操作，窄屏换行，不引入新视觉体系。
- 隔离模拟验证347个模型的全选、多选、排序保留、单项移除清理、取消与保存、失败保留草稿、四宽度布局；构建通过后由deploy.mjs备份部署，再执行acceptance.cjs。
