# 画布图片悬停信息

用户要求参考截图：图片上方左侧名称、右侧像素尺寸，悬停显示、离开隐藏。沿用用户此前直接执行的要求，不重复确认。

选择单个视口级信息栏，覆盖上传图、生成结果、图集成员。相比每张图添加标题条，单浮层不改变节点尺寸或虚拟化布局；相比浏览器 title，位置、主题和尺寸格式可控。沿用系统字体、灰阶、细线图标，不遮挡图片主体，长名称省略。选中图片操作条存在时把信息栏放在其上方；视口上边缘空间不足时放在图片可见区域。

只读名称、原图元数据或已解码原图尺寸；不得展示缩略图自然宽高、节点宽高作为原图尺寸。未知显示“尺寸未知”，元数据到达后更新，不额外下载原图或写入画布。鼠标拖动、连线、弹窗时隐藏；键盘聚焦图集预览也显示。不拦截点击、双击、拖动；画布缩放时保持文字屏幕大小。

测试真实模块的命名/尺寸规则、浏览器悬停/移开/主题/截断/拖动/删除/缩放，复用隔离 LAN 测试验证真实画布原图尺寸和图片操作。截图验收，不启动用户服务或生成任务。
